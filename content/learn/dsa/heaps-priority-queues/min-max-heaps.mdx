# Theory & Concepts
A **Heap** is a specialized tree-based data structure that satisfies the **Heap Property**. It is typically implemented as a binary tree. Heaps are primarily used to efficiently find the minimum or maximum element in a dataset.

There are two main types of heaps:
1. **Min-Heap**: The value of each node is greater than or equal to the value of its parent, with the minimum value at the root.
2. **Max-Heap**: The value of each node is less than or equal to the value of its parent, with the maximum value at the root.

Heaps are most commonly used to implement **Priority Queues**, where elements are pulled based on priority rather than the order they were inserted. They are complete binary trees, which means all levels are fully filled except possibly the last level, and the last level is filled from left to right. This completeness allows heaps to be efficiently represented as arrays.

# Common Pitfalls
<Warning>
- Confusing a heap with a Binary Search Tree (BST). In a BST, the left child is smaller and the right child is larger. In a heap, there is no inherent ordering between the left and right children.
- Attempting to search for an arbitrary element in a heap. Searching takes O(N) time because heaps are not designed for general search operations.
</Warning>
