# Theory & Concepts
The **Find Median from Data Stream** problem asks us to design a data structure that supports adding integer numbers from a data stream and instantly finding the median of all elements so far.

### The Two Heaps Intuition
The median is the middle value of an ordered dataset. If the dataset has an even number of elements, it's the average of the two middle values.
Instead of maintaining a fully sorted array (which takes `O(N)` to insert), we can split the ordered dataset into two halves:
1. **Lower Half**: Represented by a **Max-Heap**. It holds the smaller half of the numbers. The root is the largest of these smaller numbers.
2. **Upper Half**: Represented by a **Min-Heap**. It holds the larger half of the numbers. The root is the smallest of these larger numbers.

By enforcing two rules, we can find the median in `O(1)`:
- **Rule 1**: The Max-Heap always has size equal to or 1 greater than the Min-Heap.
- **Rule 2**: The largest element in the Max-Heap must be less than or equal to the smallest element in the Min-Heap.

If total elements are odd, the median is `Max-Heap.top()`. If even, it is `(Max-Heap.top() + Min-Heap.top()) / 2.0`.

    priority_queue<int> maxHeap; // Lower half
    priority_queue<int, vector<int>, greater<int>> minHeap; // Upper half

public:
    MedianFinder() {}
    
    void addNum(int num) {
        maxHeap.push(num);
        minHeap.push(maxHeap.top());
        maxHeap.pop();
        
        if (maxHeap.size() < minHeap.size()) {
            maxHeap.push(minHeap.top());
            minHeap.pop();
        }
    }
    
    double findMedian() {
        if (maxHeap.size() > minHeap.size()) {
            return maxHeap.top();
        }
        return (maxHeap.top() + minHeap.top()) / 2.0;
    }
};"
  java="class MedianFinder {
    PriorityQueue<Integer> maxHeap;
    PriorityQueue<Integer> minHeap;

    public MedianFinder() {
        maxHeap = new PriorityQueue<>(Collections.reverseOrder());
        minHeap = new PriorityQueue<>();
    }
    
    public void addNum(int num) {
        maxHeap.add(num);
        minHeap.add(maxHeap.poll());
        
        if (maxHeap.size() < minHeap.size()) {
            maxHeap.add(minHeap.poll());
        }
    }
    
    public double findMedian() {
        if (maxHeap.size() > minHeap.size()) {
            return maxHeap.peek();
        }
        return (maxHeap.peek() + minHeap.peek()) / 2.0;
    }

    def __init__(self):
        self.max_heap = [] # Negated values
        self.min_heap = []

    def addNum(self, num: int) -> None:
        heapq.heappush(self.max_heap, -num)
        heapq.heappush(self.min_heap, -heapq.heappop(self.max_heap))
        
        if len(self.max_heap) < len(self.min_heap):
            heapq.heappush(self.max_heap, -heapq.heappop(self.min_heap))

    def findMedian(self) -> float:
        if len(self.max_heap) > len(self.min_heap):
            return -self.max_heap[0]
        return (-self.max_heap[0] + self.min_heap[0]) / 2.0"

# Common Pitfalls
<Warning>
- Forgetting to cast to `double` or float when returning the average of the two middle elements. Integer division will yield incorrect results.
- Over-complicating the balancing logic. The 4-line snippet in the code blocks above elegantly handles both ordering and sizing automatically!
</Warning>
