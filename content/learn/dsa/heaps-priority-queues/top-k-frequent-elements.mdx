# Theory & Concepts
In the **Top K Frequent Elements** problem, we are given an integer array and an integer `k`, and we need to return the `k` most frequent elements.

### The Heap Approach
1. First, we need to count the frequencies of each element. We can do this efficiently using a Hash Map, which gives us `O(N)` time complexity.
2. Next, we use the Top K pattern. Since we want the "Most" frequent elements, we maintain a **Min-Heap of size K**. 
3. The heap will store pairs (or nodes) of `(frequency, value)`. We compare elements based strictly on their frequency.

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    vector<int> topKFrequent(vector<int>& nums, int k) {
        unordered_map<int, int> count;
        for (int num : nums) count[num]++;
        
        // Min-Heap storing pair<frequency, value>
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> minHeap;
        
        for (auto& entry : count) {
            minHeap.push({entry.second, entry.first});
            if (minHeap.size() > k) {
                minHeap.pop();
            }
        }
        
        vector<int> res;
        while (!minHeap.empty()) {
            res.push_back(minHeap.top().second);
            minHeap.pop();
        }
        return res;
    }
};"
  java="class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        for (int num : nums) {
            count.put(num, count.getOrDefault(num, 0) + 1);
        }
        
        // Min-Heap based on frequency
        PriorityQueue<Map.Entry<Integer, Integer>> minHeap = 
            new PriorityQueue<>((a, b) -> a.getValue() - b.getValue());
            
        for (Map.Entry<Integer, Integer> entry : count.entrySet()) {
            minHeap.add(entry);
            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }
        
        int[] res = new int[k];
        int i = 0;
        while (!minHeap.isEmpty()) {
            res[i++] = minHeap.poll().getKey();
        }
        return res;
    }
}"

# Common Pitfalls
<Warning>
- Pushing just the values into the heap without attaching the frequency, leading to incorrect comparisons.
- Returning the frequencies instead of the original values. Ensure you extract the value part from the heap elements when building your final result.
</Warning>
