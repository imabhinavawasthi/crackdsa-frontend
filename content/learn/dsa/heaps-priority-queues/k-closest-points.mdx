# Theory & Concepts
The **K Closest Points to Origin** problem asks us to find the `k` points closest to the origin `(0, 0)` on a 2D plane. 

### Mathematical Distance
The Euclidean distance between a point `(x, y)` and the origin is `sqrt(x^2 + y^2)`. Since the square root function is monotonic, comparing `x^2 + y^2` gives the exact same relative order as comparing `sqrt(x^2 + y^2)`. We can skip calculating the square root to avoid precision issues and save computation time.

### The Max-Heap Strategy
Because we want the "K Closest" (Smallest) distances, we must use a **Max-Heap of size K**. 
The Max-Heap will keep the largest distance seen so far at its root. When we process a new point, if its distance is smaller than the root's distance, we pop the root and push the new point.

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    vector<vector<int>> kClosest(vector<vector<int>>& points, int k) {
        // Max-Heap: pair<distance, vector<int>>
        priority_queue<pair<int, vector<int>>> maxHeap;
        
        for (auto& point : points) {
            int dist = point[0] * point[0] + point[1] * point[1];
            maxHeap.push({dist, point});
            if (maxHeap.size() > k) {
                maxHeap.pop();
            }
        }
        
        vector<vector<int>> res;
        while (!maxHeap.empty()) {
            res.push_back(maxHeap.top().second);
            maxHeap.pop();
        }
        return res;
    }
};"
  java="class Solution {
    public int[][] kClosest(int[][] points, int k) {
        // Max-Heap based on distance
        PriorityQueue<int[]> maxHeap = new PriorityQueue<>(
            (a, b) -> (b[0] * b[0] + b[1] * b[1]) - (a[0] * a[0] + a[1] * a[1])
        );
        
        for (int[] point : points) {
            maxHeap.add(point);
            if (maxHeap.size() > k) {
                maxHeap.poll();
            }
        }
        
        int[][] res = new int[k][2];
        int i = 0;
        while (!maxHeap.isEmpty()) {
            res[i++] = maxHeap.poll();
        }
        return res;
    }

# Common Pitfalls
<Warning>
- Calculating the exact Euclidean distance with `sqrt()`. Floating-point arithmetic can introduce subtle bugs and is slower. Always compare squared distances.
- Getting confused between Min-Heap and Max-Heap. Remember: To find K smallest, use a Max-Heap!
</Warning>
