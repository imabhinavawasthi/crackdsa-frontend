# Theory & Concepts
Heaps are typically implemented using a plain array rather than a node-based tree structure. Because a heap is a **complete binary tree**, we can map it to an array mathematically without any gaps.

For a node at index `i` (0-indexed):
- Its **Left Child** is at index `2i + 1`
- Its **Right Child** is at index `2i + 2`
- Its **Parent** is at index `(i - 1) / 2` (integer division)

### Core Operations
1. **Insert (Push)**: Add the new element at the end of the array. Then, repeatedly swap it with its parent until the heap property is restored. This is called **sift-up** or **bubble-up**.
2. **Extract Min/Max (Pop)**: Remove the root element. Replace it with the last element in the array. Then, repeatedly swap it with its smallest/largest child until the heap property is restored. This is called **sift-down** or **bubble-down**.

Modern languages provide built-in Priority Queues, so you rarely need to implement a heap from scratch in an interview, but knowing the underlying mechanics is essential.

# Common Pitfalls
<Warning>
- In Java, `PriorityQueue` is a Min-Heap by default. In C++, `priority_queue` is a Max-Heap by default. Be careful not to mix them up!
- When maintaining a size-K heap, always check the size *after* insertion before popping, to avoid removing the element you just inserted if it should stay.
</Warning>
