# Theory & Concepts
The **Power Set** of a set is the set of all its subsets, including the empty set and the set itself. For an array of size $N$, there are exactly $2^N$ possible subsets.

There are two primary ways to conceptualize subset generation:
1. **The Include/Exclude Pick Strategy:** At every element, you make a binary choice: either include the element in the current subset, or exclude it.
2. **The Backtracking Loop Strategy:** You build subsets incrementally. At every node in the recursion tree, you push the current subset to the result, and then loop over the remaining elements to branch out further. 

Both methods are standard and perfectly acceptable in interviews, but the Backtracking Loop strategy is often easier to adapt to related problems like Combination Sum.

# Code Implementation
Here we use the standard Backtracking Loop strategy.

<CodeBlock
  cpp="class Solution {\npublic:\n    vector<vector<int>> subsets(vector<int>& nums) {\n        vector<vector<int>> res;\n        vector<int> path;\n        backtrack(nums, 0, path, res);\n        return res;\n    }\n    \nprivate:\n    void backtrack(vector<int>& nums, int start, vector<int>& path, vector<vector<int>>& res) {\n        // Add the current subset to the result\n        res.push_back(path);\n        \n        // Explore all possible next elements\n        for (int i = start; i < nums.size(); i++) {\n            path.push_back(nums[i]);       // Choose\n            backtrack(nums, i + 1, path, res); // Explore\n            path.pop_back();               // Un-choose\n        }\n    }\n};"
  java="class Solution {\n    public List<List<Integer>> subsets(int[] nums) {\n        List<List<Integer>> res = new ArrayList<>();\n        backtrack(nums, 0, new ArrayList<>(), res);\n        return res;\n    }\n    \n    private void backtrack(int[] nums, int start, List<Integer> path, List<List<Integer>> res) {\n        // Add the current subset (must make a copy!)\n        res.add(new ArrayList<>(path));\n        \n        for (int i = start; i < nums.length; i++) {\n            path.add(nums[i]);             // Choose\n            backtrack(nums, i + 1, path, res); // Explore\n            path.remove(path.size() - 1);  // Un-choose\n        }\n    }\n}"

# Common Pitfalls
<Warning>
- **Passing by reference without copying:** If you push `path` directly into `res` without duplicating it (`path[:]` or `new ArrayList<>(path)`), your final list will just contain references to the same empty array.
- Forgetting that the base case is implicit in the `for` loop condition (`i < nums.size()`).
</Warning>
