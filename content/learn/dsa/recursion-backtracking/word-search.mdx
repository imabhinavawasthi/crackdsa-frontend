# Theory & Concepts
**Word Search** is a staple 2D grid backtracking problem. Given an $M \times N$ grid of characters and a target `word`, you must determine if the word exists in the grid. The word can be constructed from letters of sequentially adjacent cells (horizontal or vertical), but the same cell may not be used more than once.

### The Backtracking Strategy
1. Iterate through every cell in the grid.
2. If the cell matches the first character of the word, launch a Depth-First Search (DFS) / backtracking process from that cell.
3. During DFS, check if the current cell is out of bounds, already visited, or doesn't match the current character of the word. If so, return `false`.
4. If we have matched the entire length of the word, return `true`.
5. **Crucial Step:** Temporarily mark the current cell as visited (e.g., change it to `#`) to prevent reusing it.
6. Recursively search in all 4 directions (up, down, left, right).
7. Un-mark the cell (backtrack) so it can be used by other potential paths.

# Common Pitfalls
<Warning>
- Using a separate `visited` matrix. While correct, it uses $O(M \times N)$ extra space. It's much better to modify the board in-place with a special character like `#` and restore it afterward.
- Messing up the bounds check. The order of checks is critical: verify `index == word.length()` *before* checking if `r` and `c` are out of bounds.
</Warning>
