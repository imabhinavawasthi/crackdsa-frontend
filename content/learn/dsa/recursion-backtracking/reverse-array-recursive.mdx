# Theory & Concepts
Reversing an array using recursion involves swapping the elements at the extreme ends (the first and the last), and then recursively doing the same for the remaining inner subarray. 

We can define our problem using two pointers: `left` and `right`.
- **Base Case:** If `left >= right`, it means we have reached or crossed the middle of the array, so we stop.
- **Recursive Step:** Swap `array[left]` and `array[right]`, then recursively call the function with `left + 1` and `right - 1`.

Alternatively, this can be done with a single pointer `i` by utilizing the property that `right = N - i - 1`.

# Code Implementation
Here is the implementation using the two-pointer recursive approach.

<CodeBlock
  cpp="class Solution {\npublic:\n    void reverseArray(vector<int>& arr, int left, int right) {\n        // Base case\n        if (left >= right) return;\n        \n        // Swap elements at the current boundaries\n        swap(arr[left], arr[right]);\n        \n        // Recursive call for the inner subarray\n        reverseArray(arr, left + 1, right - 1);\n    }\n};"
  java="class Solution {\n    public void reverseArray(int[] arr, int left, int right) {\n        // Base case\n        if (left >= right) return;\n        \n        // Swap\n        int temp = arr[left];\n        arr[left] = arr[right];\n        arr[right] = temp;\n        \n        // Recursive call\n        reverseArray(arr, left + 1, right - 1);\n    }\n}"
  python="class Solution:\n    def reverse_array(self, arr: list[int], left: int, right: int) -> None:\n        # Base case\n        if left >= right:\n            return\n            \n        # Swap\n        arr[left], arr[right] = arr[right], arr[left]\n        \n        # Recursive call\n        self.reverse_array(arr, left + 1, right - 1)"
/>

# Common Pitfalls
<Warning>
- Using `<` instead of `<=` or `>=` in the base case could lead to off-by-one errors depending on whether the array length is odd or even.
- Forgetting that the recursive space complexity makes this strictly worse than the iterative O(1) space two-pointer approach.
</Warning>
