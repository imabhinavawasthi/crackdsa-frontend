# Theory & Concepts
A string is a **palindrome** if it reads the same forwards and backwards (e.g., "racecar", "madam"). Checking if a string is a palindrome recursively builds directly upon the logic used to reverse an array.

Using a two-pointer approach (`left` and `right`):
- **Base Case:** If `left >= right`, all pairs of characters have matched, so the string is a palindrome (return `true`).
- **Recursive Step:** Check if the character at `left` matches the character at `right`. If they don't, return `false`. If they do, recurse on the substring by incrementing `left` and decrementing `right`.

# Code Implementation
Here is the standard recursive implementation for checking a palindrome.

<CodeBlock
  cpp="class Solution {\npublic:\n    bool isPalindrome(string& s, int left, int right) {\n        // Base case: crossed the middle\n        if (left >= right) return true;\n        \n        // If mismatch found, not a palindrome\n        if (s[left] != s[right]) return false;\n        \n        // Recurse for the inner substring\n        return isPalindrome(s, left + 1, right - 1);\n    }\n};"

# Common Pitfalls
<Warning>
- Creating new substrings at each recursive step (e.g., `s.substring(1, s.length() - 1)`). This changes the time complexity to O(N^2) due to string copying! Always pass the original string by reference and use pointer indices.
- Not accounting for case sensitivity or non-alphanumeric characters if the problem requires it (like LeetCode's 'Valid Palindrome').
</Warning>
