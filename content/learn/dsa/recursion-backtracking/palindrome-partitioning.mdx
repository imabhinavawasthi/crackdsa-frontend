# Theory & Concepts
**Palindrome Partitioning** is a classic problem that perfectly illustrates how backtracking can be applied to string segmentation. The goal is to partition a given string such that every substring in the partition is a palindrome.

### How it works:
1. We start at index `0`.
2. We try to form a substring from index `0` to `i` (where `i` goes from `0` to `n-1`).
3. If the substring `s[0...i]` is a palindrome, we "choose" it (add it to our current path) and recursively ask: "Can we partition the rest of the string `s[i+1...n-1]` into palindromes?"
4. After exploring, we backtrack by removing `s[0...i]` from our path and trying the next `i`.

This "Choose, Explore, Un-choose" strategy guarantees that we explore all valid segmentations. The base case is reached when our starting index reaches the end of the string, meaning we successfully partitioned the entire string.

# Common Pitfalls
<Warning>
- Using `s.substr()` or `s.substring()` inside the `isPalindrome` check. This creates unnecessary string copies and balloons the time complexity. Always pass index pointers!
- Messing up the substring length parameters when extracting the chosen palindrome.
</Warning>
