# Theory & Concepts
The **Combination Sum** series is a classic test of your backtracking skills. It introduces a target constraint: instead of generating all combinations, you only want combinations that sum up to a specific `target`.

### Combination Sum I
You are given an array of **distinct** integers and a target. You can use the same element an **unlimited** number of times. Because elements can be reused, when we make our recursive call to explore further, we pass `i` instead of `i + 1`.

### Combination Sum II
You are given an array with **duplicates**. Each element can be used **only once**. We handle this by:
1. Sorting the array.
2. Skipping duplicates in the `for` loop (`if (i > start && nums[i] == nums[i-1]) continue;`).
3. Passing `i + 1` to the recursive call so elements aren't reused.

### Combination Sum III
Find all valid combinations of `k` numbers that sum up to `n`, using numbers from `1` to `9` only once. This is a mix of the Subsets template with two constraints: path size must equal `k` and current sum must equal `n`.

# Code Implementation
Here is the implementation for **Combination Sum I** (unlimited reuse).

  cpp="class Solution {\npublic:\n    vector<vector<int>> combinationSum(vector<int>& candidates, int target) {\n        vector<vector<int>> res;\n        vector<int> path;\n        backtrack(candidates, target, 0, path, res);\n        return res;\n    }\n    \nprivate:\n    void backtrack(vector<int>& candidates, int target, int start, vector<int>& path, vector<vector<int>>& res) {\n        if (target < 0) return; // Base case: exceeded target\n        if (target == 0) {\n            res.push_back(path); // Base case: found valid combination\n            return;\n        }\n        \n        for (int i = start; i < candidates.size(); i++) {\n            path.push_back(candidates[i]);\n            // Pass 'i' instead of 'i+1' because we can reuse the same element\n            backtrack(candidates, target - candidates[i], i, path, res);\n            path.pop_back();\n        }\n    }\n};"
  java="class Solution {\n    public List<List<Integer>> combinationSum(int[] candidates, int target) {\n        List<List<Integer>> res = new ArrayList<>();\n        backtrack(candidates, target, 0, new ArrayList<>(), res);\n        return res;\n    }\n    \n    private void backtrack(int[] candidates, int target, int start, List<Integer> path, List<List<Integer>> res) {\n        if (target < 0) return;\n        if (target == 0) {\n            res.add(new ArrayList<>(path));\n            return;\n        }\n        \n        for (int i = start; i < candidates.length; i++) {\n            path.add(candidates[i]);\n            backtrack(candidates, target - candidates[i], i, path, res);\n            path.remove(path.size() - 1);\n        }\n    }\n}"
  python="class Solution:\n    def combinationSum(self, candidates: list[int], target: int) -> list[list[int]]:\n        res = []\n        \n        def backtrack(start, current_target, path):\n            if current_target < 0:\n                return\n            if current_target == 0:\n                res.append(path[:])\n                return\n                \n            for i in range(start, len(candidates)):\n                path.append(candidates[i])\n                # Re-use the same element by passing i\n                backtrack(i, current_target - candidates[i], path)\n                path.pop()\n                \n        backtrack(0, target, [])\n        return res"

# Common Pitfalls
<Warning>
- Forgetting the `target < 0` base case. Without it, your function will infinitely subtract numbers until it crashes.
- Passing `i + 1` instead of `i` in Combination Sum I.
- Forgetting to sort the array in Combination Sum II before trying to skip duplicates.
</Warning>
