# Theory & Concepts
The **Sudoku Solver** is the ultimate boss of backtracking algorithms. The rules of Sudoku are simple: fill a $9 \times 9$ grid such that every row, every column, and every $3 \times 3$ subgrid contains the digits `1` through `9` exactly once.

### The Algorithm:
1. Scan the board to find an empty cell `'.'`.
2. Try placing digits `1` through `9` in that cell.
3. For each digit, check if it's **valid** (doesn't exist in the same row, column, or $3 \times 3$ block).
4. If valid, place the digit and recursively call the solver to fill the rest of the board.
5. If the recursive call returns `true`, we are done! 
6. If it returns `false`, backtrack (reset the cell to `'.'`) and try the next digit.
7. If no digit from `1` to `9` works, return `false` to trigger backtracking in the parent call.

Unlike generating combinations where we want *all* answers, here we only want *one* valid answer. Therefore, our recursive function should return a `boolean` to immediately stop searching once a solution is found.

# Common Pitfalls
<Warning>
- Miscalculating the $3 \times 3$ subgrid formula. The row index is `3 * (row / 3) + i / 3` and the column index is `3 * (col / 3) + i % 3`. Memorize this!
- Forgetting to `return false` after the 1-9 loop. If no digit works, the current state is invalid and you *must* backtrack.
</Warning>
