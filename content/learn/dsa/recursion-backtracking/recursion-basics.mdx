# Theory & Concepts
Recursion is a programming technique where a function calls itself to solve a smaller instance of the same problem. Think of it as a set of Russian nesting dolls. To solve the larger problem, you break it down into identical, but smaller, problems until you reach a state that is simple enough to be solved directly (the base case).

### The Call Stack
Every time a function is called, the system sets aside space in memory for it to run. This space is called a **stack frame**, and it stores local variables and the execution context. When a function calls itself, a new stack frame is placed on top of the old one in a structure known as the **Call Stack**. The Call Stack operates on a Last-In, First-Out (LIFO) principle.

Once the base case is reached, the function stops calling itself and returns a value to the caller. The top stack frame is popped off, and execution resumes in the previous frame.

### Key Components of Recursion
1. **Base Case:** The condition that stops the recursion. Without it, you'll encounter a Stack Overflow.
2. **Recursive Step:** The part of the function where the problem is reduced and the function calls itself.

# Code Implementation
Let's see a simple example of recursion: printing numbers from $N$ down to $1$.

<CodeBlock
  cpp="void printNumbers(int n) {\n    // Base case\n    if (n == 0) return;\n    \n    // Do work\n    cout << n << \" \";\n    \n    // Recursive call\n    printNumbers(n - 1);\n}"
  java="public void printNumbers(int n) {\n    // Base case\n    if (n == 0) return;\n    \n    // Do work\n    System.out.print(n + \" \");\n    \n    // Recursive call\n    printNumbers(n - 1);\n}"
  python="def print_numbers(n):\n    # Base case\n    if n == 0:\n        return\n    \n    # Do work\n    print(n, end=' ')\n    \n    # Recursive call\n    print_numbers(n - 1)"
/>

# Common Pitfalls
<Warning>
- Missing or incorrect base cases leading to infinite recursion (`StackOverflowError`).
- Performing the recursive call without actually reducing the input size.
- Not returning the result of the recursive call in functions that are supposed to return a value.
</Warning>
