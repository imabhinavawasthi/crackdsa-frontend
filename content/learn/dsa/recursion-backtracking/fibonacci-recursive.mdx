# Theory & Concepts
The **Fibonacci Sequence** is a classic mathematical sequence where each number is the sum of the two preceding ones, usually starting with $0$ and $1$. The sequence goes: $0, 1, 1, 2, 3, 5, 8, 13 \dots$

Recursively defining the $N^{th}$ Fibonacci number is straightforward because the mathematical definition is itself recursive:
$F(N) = F(N-1) + F(N-2)$ with base cases $F(0) = 0$ and $F(1) = 1$.

While beautiful, the naive recursive approach is highly inefficient due to **overlapping subproblems**. It recalculates the same Fibonacci numbers over and over, resulting in an exponential time complexity. It is primarily taught to illustrate recursion trees and motivate Dynamic Programming (memoization).

# Common Pitfalls
<Warning>
- Using the naive recursive approach in an interview without acknowledging its terrible time complexity.
- Forgetting to handle edge cases like negative numbers if the constraints allow them.
</Warning>
