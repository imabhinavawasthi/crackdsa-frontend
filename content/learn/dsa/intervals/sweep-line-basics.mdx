# Theory & Concepts
The **Sweep Line Algorithm** (often called Line Sweep) is a conceptual framework for solving complex interval, scheduling, and computational geometry problems.

Imagine drawing a vertical line at the start of your timeline (x-axis) and sweeping it from left to right. As the line moves, it "encounters" events. An event is typically the *start* of an interval or the *end* of an interval.

### Core Intuition
Instead of treating an interval `[start, end]` as a single object, we tear it apart into two distinct events:
1. A **Start Event** at time `start`, which adds to our running total (`+1`).
2. An **End Event** at time `end`, which subtracts from our running total (`-1`).

By sorting all these individual events purely by time, we can iterate through them and maintain a running sum of "active" intervals.

**The Golden Rule of Sweep Line:** If a Start Event and an End Event happen at the exact same time, which one should you process first?
- If the problem says `[1, 2]` and `[2, 3]` **DO NOT overlap**, process the **End Event first**. (Subtract before adding).
- If the problem says they **DO overlap**, process the **Start Event first**. (Add before subtracting).

# Code Implementation
Here is a generalized template for the Sweep Line algorithm to find the maximum number of overlapping intervals.

using namespace std;

class SweepLineTemplate {
public:
    int maxOverlaps(vector<vector<int>>& intervals) {
        // Pair structure: {time, type} where type is +1 (start) or -1 (end)
        vector<pair<int, int>> events;
        
        for (const auto& interval : intervals) {
            events.push_back({interval[0], 1});
            // Using -1 for end event. 
            // In C++ sort, {2, -1} comes before {2, 1}, naturally prioritizing ends!
            events.push_back({interval[1], -1}); 
        }
        
        // Sort events primarily by time. 
        sort(events.begin(), events.end());
        
        int currentActive = 0;
        int maxActive = 0;
        
        for (const auto& event : events) {
            currentActive += event.second;
            maxActive = max(maxActive, currentActive);
        }
        
        return maxActive;
    }
};"
  java="import java.util.*;

class SweepLineTemplate {
    public int maxOverlaps(int[][] intervals) {
        // int[] represents: {time, type}
        List<int[]> events = new ArrayList<>();
        
        for (int[] interval : intervals) {
            events.add(new int[]{interval[0], 1});
            events.add(new int[]{interval[1], -1});
        }
        
        // Sort by time. If times are equal, process end events (-1) before start events (1)
        Collections.sort(events, (a, b) -> {
            if (a[0] == b[0]) {
                return Integer.compare(a[1], b[1]);
            }
            return Integer.compare(a[0], b[0]);
        });
        
        int currentActive = 0;
        int maxActive = 0;
        
        for (int[] event : events) {
            currentActive += event[1];
            maxActive = Math.max(maxActive, currentActive);
        }
        
        return maxActive;
    }

# Common Pitfalls
<Warning>
- Getting the tie-breaker wrong. If a meeting ends at 10 and another starts at 10, does the room count hit 2 or stay at 1? Usually, meetings don't overlap on exact boundaries, so process the `-1` before the `+1`.
- Forgetting to separate the interval into two distinct events. You cannot just sort the original interval objects to achieve a sweep line.
</Warning>
