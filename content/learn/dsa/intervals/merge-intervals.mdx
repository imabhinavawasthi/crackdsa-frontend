# Theory & Concepts
The **Merge Intervals** problem is a classic and foundational challenge. Given an array of intervals where `intervals[i] = [starti, endi]`, merge all overlapping intervals, and return an array of the non-overlapping intervals that cover all the intervals in the input.

### Core Intuition
The brute-force way would involve comparing every interval with every other interval, resulting in an $O(N^2)$ runtime. To optimize this, we rely on the fundamental principle of interval problems: **Sorting**.

1. **Sort the Intervals**: Sort the list of intervals by their starting times. This ensures that if intervals overlap, they must be adjacent in the sorted array.
2. **Iterate and Merge**: Create an empty list to hold the merged intervals. Iterate through the sorted intervals:
   - If the merged list is empty, or if the current interval does not overlap with the last interval in the merged list, append it.
   - If it does overlap, merge them by updating the `end` of the last interval in the merged list to be the maximum `end` of the two overlapping intervals.

This approach guarantees that we effectively merge all overlapping clusters in a single pass.

class Solution {

    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        if (intervals.empty()) return {};

        // Sort intervals by start time
        sort(intervals.begin(), intervals.end());

        vector<vector<int>> merged;
        merged.push_back(intervals[0]);

        for (int i = 1; i < intervals.size(); i++) {
            // Get the last inserted interval
            vector<int>& lastInterval = merged.back();

            // If the current interval overlaps with the last interval
            if (intervals[i][0] <= lastInterval[1]) {
                // Merge them by taking the maximum end time
                lastInterval[1] = max(lastInterval[1], intervals[i][1]);
            } else {
                // Otherwise, add the current interval to the result
                merged.push_back(intervals[i]);
            }
        }

        return merged;
    }

class Solution {
    public int[][] merge(int[][] intervals) {
        if (intervals.length <= 1) return intervals;

        // Sort by ascending starting point
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> merged = new ArrayList<>();
        int[] currentInterval = intervals[0];
        merged.add(currentInterval);

        for (int[] interval : intervals) {
            int currentEnd = currentInterval[1];
            int nextBegin = interval[0];
            int nextEnd = interval[1];

            if (currentEnd >= nextBegin) {
                // Overlapping intervals, update the end if needed
                currentInterval[1] = Math.max(currentEnd, nextEnd);
            } else {
                // Disjoint intervals, add the new interval to the list
                currentInterval = interval;
                merged.add(currentInterval);
            }
        }

        return merged.toArray(new int[merged.size()][]);
    }

# Common Pitfalls
<Warning>
- Neglecting to sort the intervals first. Attempting to merge an unsorted list in a single pass will fail for inputs like `[[1,4], [0,2], [3,5]]`.
- Comparing the end of the previous interval with the end of the current one instead of the start. Overlap condition is `previous.end >= current.start`.
- Assuming the current interval's end is always greater. You must use `max(previous.end, current.end)` because an interval could be completely swallowed by another, e.g., merging `[1, 5]` and `[2, 3]` yields `[1, 5]`.
</Warning>
