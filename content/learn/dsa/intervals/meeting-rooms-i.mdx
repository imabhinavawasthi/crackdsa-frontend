# Theory & Concepts
The **Meeting Rooms** problem is the gateway to understanding scheduling problems. The premise is simple: Given an array of meeting time intervals where `intervals[i] = [starti, endi]`, determine if a person could attend *all* meetings.

In simpler terms, you are checking if there are **any overlaps** in the provided list of intervals. If even a single overlap exists, the person cannot attend all meetings.

### Core Intuition
If you don't sort the intervals, you would have to compare every meeting to every other meeting to check for overlaps, which takes $O(N^2)$ time. 

By **sorting the intervals by their start time**, you guarantee that any potential overlap will happen between adjacent elements in the sorted array. You only need to check if the current meeting starts *before* the previous meeting finishes.

#include <algorithm>

using namespace std;

class Solution {
public:
    bool canAttendMeetings(vector<vector<int>>& intervals) {
        if (intervals.empty()) return true;

        // Sort by starting time
        sort(intervals.begin(), intervals.end());

        // Check for any overlap between adjacent meetings
        for (int i = 1; i < intervals.size(); i++) {
            if (intervals[i][0] < intervals[i - 1][1]) {
                // The current meeting starts before the previous one ends
                return false;
            }
        }

        return true;
    }
};"

# Common Pitfalls
<Warning>
- Misunderstanding the overlap condition: If one meeting ends at 10:00 and the next begins at 10:00, this is *not* an overlap. You should use `<` rather than `<=` when comparing start and end times.
- Not handling the empty array edge case. If there are no meetings, a person can technically attend all 0 of them.
</Warning>
