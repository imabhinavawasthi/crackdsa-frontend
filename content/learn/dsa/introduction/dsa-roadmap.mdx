# Theory & Concepts
To conquer DSA, you must treat learning as a scaffolded process. Rushing into complex topics like Dynamic Programming (DP) or Graphs before mastering Arrays and Recursion will only lead to confusion. A structured, progressive roadmap is essential for building a deep, intuitive understanding.

### 1. Phase 1: The Basics (Week 1 - 3)
Before writing computational logic, you must understand the basic tools:
*   **Language Syntax & STL:** Master one language (C++, Java, or Python) deeply. Know how to use standard collections (Vector, ArrayList, Stack, Queue, HashSet, HashMap).
*   **Mathematical Foundations:** Understand basic number theory (GCD, Prime Numbers, Fibonacci) and basic modular arithmetic.
*   **Asymptotic Analysis:** Learn how to calculate Time and Space complexity. Never write a line of code without knowing its Big-O footprint.

### 2. Phase 2: Linear Data Structures (Week 4 - 8)
These structures store data in a sequential manner, making them easy to visualize:
*   **Arrays & Strings:** Master basic traversals, prefix sums, two pointers, sliding windows, and binary search.
*   **Linked Lists:** Understand memory allocations, pointers, node references, structural reversals, and slow/fast pointer techniques.
*   **Stacks & Queues:** Master LIFO (Last In First Out) and FIFO (First In First Out) concepts. Solve problems like Next Greater Element, Valid Parentheses, and Sliding Window Maximum.

### 3. Phase 3: Non-Linear & Advanced Concepts (Week 9 - 16)
These structures organize parameters hierarchically or in networks, which are crucial for complex system modeling:
*   **Recursion & Backtracking:** Learn how to split problems into smaller subproblems. Solve classic puzzles like N-Queens and Sudoku Solver.
*   **Trees (Binary Trees & BSTs):** Master recursive traversals (Pre-order, In-order, Post-order), Level-order search, tree heights, and path computations.
*   **Graphs:** Model nodes and relationships. Master BFS, DFS, Dijkstra's algorithm, Minimum Spanning Trees, and Topological Sorting.
*   **Dynamic Programming (DP):** The ultimate optimization technique. Master memoization (top-down) and tabulation (bottom-up) to optimize exponential calculations into polynomial time.

# Common Pitfalls
<Warning>
- **The LeetCode Grind Trap:** Solving random hard problems before mastering medium and easy ones. Focus on topical mastery first!
- **Skipping Recursion:** Trying to learn Trees, Graphs, and DP without fully grasping recursion. Recursion is the mathematical foundation for all three.
- **Inconsistency:** Studying for 10 hours on Sunday and doing nothing for the rest of the week. Aim for 1-2 hours of daily study instead.
</Warning>
