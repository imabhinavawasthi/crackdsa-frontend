# Theory & Concepts
The **Longest Substring Without Repeating Characters** problem asks us to find the length of the longest substring in a given string without any repeating characters. This is a classic variable-size sliding window problem.

### The Intuition
We want to check substrings, but recalculating characters from scratch for every substring is extremely inefficient ($O(N^3)$ or $O(N^2)$). Instead, we can maintain a "window" of characters and slide it across the string. 
- We expand the window to the right by adding one character at a time.
- If we encounter a character that is already inside the window, our condition (no repeating characters) is violated.
- We must shrink the window from the left until the duplicate character is completely removed from our current window.

### Optimization with a Hash Map / Set
We use a Set to keep track of characters in the current window. When expanding, if the new character exists in the Set, we increment `left` and remove characters from the Set until the duplicate is gone.
A further optimization uses a HashMap to store the most recent index of each character, allowing us to instantly jump the `left` pointer to `map[char] + 1` instead of manually deleting characters one by one.

    int lengthOfLongestSubstring(string s) {
        vector<int> char_index(128, -1);

        int left = 0;
        
        for (int right = 0; right < s.length(); right++) {
            char current_char = s[right];
            
            // If character has been seen and is inside the current window
            if (char_index[current_char] >= left) {
                left = char_index[current_char] + 1;
            }
            
            char_index[current_char] = right;
            max_len = max(max_len, right - left + 1);
        }
        
        return max_len;
    }
};"

# Common Pitfalls
<Warning>
- **Jumping the left pointer backwards:** A common mistake is updating `left = map[char] + 1` blindly. If the duplicate character's last seen index is *before* `left`, jumping there expands the window invalidly. Always ensure `map[char] >= left`.
- **String indexing:** Ensure you handle empty string cases immediately to prevent index out-of-bounds errors.
</Warning>
