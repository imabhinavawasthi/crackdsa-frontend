# Theory & Concepts
The **Count Occurrences of Anagrams** problem asks us to find all starting indices of substrings in `s` that are anagrams of a given pattern `p`. An anagram means the substring has the exact same characters as `p` with the exact same frequencies, regardless of order.

### The Intuition
Because an anagram must be the exact same length as `p`, this is a **Fixed Size Sliding Window** problem where the window size `K` is `p.length()`.
Instead of sorting every substring of length `K` to compare it against `p` (which would be $O(N \times K \log K)$), we can use character frequency maps.

### The Sliding Window with Frequency Map
1. Create a frequency map (or a fixed-size array of 26 integers) for string `p`.
2. Keep a running frequency map for our sliding window of size `K` over string `s`.
3. Slide the window:
   - Add the new character entering the window on the right.
   - Remove the old character leaving the window from the left.
4. Instead of comparing the entire frequency map at every step ($O(26)$), we can optimize it by tracking a `match_count` variable that tells us how many unique characters have met their target frequencies.
5. If `match_count` equals the total number of unique characters in `p`, we found an anagram!

            window_count[s[i] - 'a']++;

# Common Pitfalls
<Warning>
- **Handling smaller strings:** Always add an early exit condition `if (s.length() < p.length()) return []` to avoid index out of bounds exceptions and unnecessary processing.
- **Incorrect removal index:** Ensure that when removing the element left behind by the window, you remove the element exactly at `i - p.length()`.
</Warning>
