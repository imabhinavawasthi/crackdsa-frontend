# Theory & Concepts
The **Fixed Size Sliding Window** is a fundamental technique used when we need to find a subarray or substring of a specific, constant length `K` that satisfies a certain condition. The most classic example is finding the maximum sum of any contiguous subarray of size `K`.

### The Brute Force Approach
A naive approach would be to iterate through all possible subarrays of size `K` and compute their sums from scratch. For an array of size $N$, there are $N - K + 1$ such subarrays, each taking $O(K)$ to compute. This yields an $O(N \times K)$ time complexity.

### The Sliding Window Optimization
Instead of recalculating the entire sum for each window, we can reuse the sum of the previous window.
1. Compute the sum of the first `K` elements. This is our initial window.
2. Slide the window one step to the right.
3. The new sum is just the previous sum minus the element that left the window, plus the new element that entered the window.
4. Update the maximum sum found so far.

This reduces the time complexity to strictly $O(N)$ since each element is added and removed at most once.

    int maxSumSubarray(vector<int>& arr, int k) {
        if (arr.size() < k) return 0;
        
        int current_sum = 0;

        // Compute the sum of the first window
        for (int i = 0; i < k; i++) {
            current_sum += arr[i];
        }

        // Slide the window
        for (int i = k; i < arr.size(); i++) {
            current_sum = current_sum - arr[i - k] + arr[i];
            max_sum = max(max_sum, current_sum);
        }
        
        return max_sum;
    }
};"

# Common Pitfalls
<Warning>
- **Off-by-One Errors:** Ensuring the element removed is `arr[i - k]`. If you use two pointers `left` and `right`, ensure they properly encapsulate `K` elements.
- **Handling Arrays Smaller than K:** Always check if the array size is less than `K` before processing. In such cases, returning 0 or an appropriate default value is essential.
</Warning>
