# Theory & Concepts
The **Trapping Rain Water** problem requires us to calculate how much water can be trapped between elevation maps (blocks) after raining. Given an array representing the height of each bar, we need to compute the total trapped water.

### The Intuition
The amount of water trapped above any given bar `i` is determined by the maximum height of the bars to its left and right. Specifically:
`Water[i] = max(0, min(max_left, max_right) - height[i])`

### The Two Pointers Approach
While we could precompute the `max_left` and `max_right` arrays in $O(N)$ time and $O(N)$ space, the Two Pointers technique allows us to achieve $O(1)$ space.
1. Use `left` and `right` pointers initialized to the ends of the array.
2. Maintain `left_max` and `right_max` variables.
3. Because the water level is bounded by the smaller of the two maximums, we only need to care about the securely known smaller bound.
4. If `left_max < right_max`, we know the water at `left` is securely bounded by `left_max` (regardless of what's further right). We calculate the trapped water for `left` and advance `left`.
5. Conversely, if `right_max <= left_max`, we process `right` and decrement `right`.

    int trap(vector<int>& height) {
        if (height.empty()) return 0;
        
        int left = 0, right = height.size() - 1;
        int left_max = 0, right_max = 0;
        int trapped_water = 0;
        
        while (left < right) {
            if (height[left] < height[right]) {
                if (height[left] >= left_max) {
                    left_max = height[left];
                } else {
                    trapped_water += left_max - height[left];
                }
                left++;
            } else {
                if (height[right] >= right_max) {
                    right_max = height[right];
                } else {
                    trapped_water += right_max - height[right];
                }
                right--;
            }
        }
        
        return trapped_water;
    }
};"

# Common Pitfalls
<Warning>
- **Confusing pointers and max values:** Ensure you update `left_max` and `right_max` correctly before attempting to calculate trapped water.
- **Empty Array:** Failing to check if the input array is empty can lead to out-of-bounds exceptions when initializing the `right` pointer.
</Warning>
