# Theory & Concepts
The **Container With Most Water** problem asks us to find two lines that, together with the x-axis, form a container that holds the most water. Given an array `height` where each element represents the height of a vertical line on a graph, we need to maximize the area.

### The Brute Force Approach
The naive approach is to check every possible pair of lines. The area formed by lines at indices `i` and `j` is `min(height[i], height[j]) * (j - i)`. This requires an $O(N^2)$ nested loop, which is too slow for large inputs.

### The Two Pointers Approach
We can optimize this to $O(N)$ using the **Two Pointers** technique.
1. Place one pointer `left` at the beginning (index 0) and one pointer `right` at the end (index $N - 1$).
2. Calculate the area and update the maximum area found so far.
3. The height of the water is constrained by the shorter line. Moving the pointer at the taller line cannot increase the height, and the width is decreasing anyway, so the area would only decrease.
4. Therefore, to potentially find a larger area, we must move the pointer pointing to the **shorter line** inward.
5. Repeat this process until `left` and `right` meet.

This greedy strategy guarantees that we don't miss the optimal solution because any container skipped by moving the shorter line would inherently be smaller or equal in height, with a strictly smaller width.

    int maxArea(vector<int>& height) {

        while (left < right) {
            int current_height = min(height[left], height[right]);

                left++;
            } else {
                right--;
            }
        }
        
        return max_water;
    }
};"

# Common Pitfalls
<Warning>
- **Moving the wrong pointer:** A common mistake is moving the pointer for the taller line. Remember, the area is bottlenecked by the shorter line, so you must move the shorter one to seek a potentially taller line.
- **Calculating width incorrectly:** The width is just `right - left`. Do not add 1. If pointers are at indices 0 and 1, the width is 1.
</Warning>
