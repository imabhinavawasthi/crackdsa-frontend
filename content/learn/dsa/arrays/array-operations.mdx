# Theory & Concepts
Because arrays store elements in a contiguous block of memory, operations like inserting, deleting, and searching behave very specifically, dictating when you should and shouldn't use arrays.

### Search (Linear vs Binary)
To find an element in an unsorted array, you must check every element one by one (**Linear Search**, $O(N)$). If the array is sorted, you can drastically speed this up to $O(\log N)$ using **Binary Search**.

### Insertion & Deletion
Inserting or deleting at the **end** of an array is extremely fast ($O(1)$) because no other elements are affected.
However, inserting or deleting at the **beginning or middle** of an array is expensive ($O(N)$). Why? Because memory is contiguous. If you insert an element at index `0`, you must physically shift every single existing element one position to the right to make room. If you delete an element, you must shift everything to the left to close the gap.

# Code Implementation
<CodeBlock
  cpp={`// C++ code demonstrating basic operations
#include <vector>
using namespace std;

class ArrayOps {
public:
    void deleteAtIndex(vector<int>& arr, int index) {
        // Shift elements left to overwrite the target index
        for (int i = index; i < arr.size() - 1; i++) {
            arr[i] = arr[i + 1];
        }
        arr.pop_back(); // Remove the now-duplicate last element
    }
    
    int linearSearch(vector<int>& arr, int target) {
        for (int i = 0; i < arr.size(); i++) {
            if (arr[i] == target) return i;
        }
        return -1;
    }
};`}
  java={`// Java code demonstrating basic operations
class ArrayOps {
    public int[] deleteAtIndex(int[] arr, int index) {
        int[] newArr = new int[arr.length - 1];
        for (int i = 0, j = 0; i < arr.length; i++) {
            if (i == index) continue;
            newArr[j++] = arr[i];
        }
        return newArr;
    }
    
    public int linearSearch(int[] arr, int target) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == target) return i;
        }
        return -1;
    }
}`}

# Common Pitfalls
<Warning>
- **Hidden O(N) Operations:** In Python, calling arr.insert(0, val) or arr.pop(0) is an O(N) operation. Doing this inside a loop creates an accidental O(N^2) time complexity. If you need fast front insertions/deletions, use collections.deque.
- **Modifying Iterators:** Erasing an element from a C++ vector while iterating over it via a for loop will invalidate your indices or iterators.
</Warning>
