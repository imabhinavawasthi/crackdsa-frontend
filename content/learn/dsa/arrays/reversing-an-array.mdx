# Theory & Concepts
Reversing an array is a classic foundational problem that introduces the powerful **Two-Pointer Technique**. 

The naive way to reverse an array is to create a new array, iterate backward through the original array, and append elements to the new array. While this takes $O(N)$ time, it also takes **$O(N)$ extra space**.

### The Two-Pointer Approach (In-Place)
To achieve true optimization, we must reverse the array **in-place** (without allocating a new array), bringing our space complexity down to $O(1)$. 
1. Place a `left` pointer at the beginning (index `0`).
2. Place a `right` pointer at the end (index `size - 1`).
3. Swap the elements at `left` and `right`.
4. Increment `left` and decrement `right`.
5. Repeat until `left >= right`.

This simple, symmetric property forms the basis for many advanced palindrome and sorting algorithms.

# Code Implementation
<CodeBlock
  cpp={`// C++ Two-Pointer Array Reversal
#include <vector>
#include <algorithm> // for std::swap
using namespace std;

class Solution {
public:
    void reverseArray(vector<int>& arr) {
        int left = 0;
        int right = arr.size() - 1;
        
        while (left < right) {
            swap(arr[left], arr[right]);
            left++;
            right--;
        }
    }
};`}
  java={`// Java Two-Pointer Array Reversal
class Solution {
    public void reverseArray(int[] arr) {
        int left = 0;
        int right = arr.length - 1;
        
        while (left < right) {
            // Standard swap logic
            int temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;
            
            left++;
            right--;
        }
    }
}`}
  python={`# Python Two-Pointer Array Reversal
class Solution:
    def reverse_array(self, arr: list[int]) -> None:
        left, right = 0, len(arr) - 1
        
        while left < right:
            # Python allows elegant tuple swapping
            arr[left], arr[right] = arr[right], arr[left]
            left += 1
            right -= 1`}

# Common Pitfalls
<Warning>
- **Loop Condition:** The condition must be `left < right`. If you use `left <= right`, it will unnecessarily swap the middle element with itself (harmless but inefficient). If you loop through the entire array instead of stopping at the middle, you will reverse it and then un-reverse it back to its original state!
- **Library Reliance:** While languages offer built-in functions (std::reverse in C++, Collections.reverse in Java, arr[::-1] in Python), interviewers usually want to see the underlying logic implemented from scratch.
</Warning>
