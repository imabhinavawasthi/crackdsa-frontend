# Theory & Concepts
**Kadane's Algorithm** is an elegant dynamic programming technique used to solve the **Maximum Subarray Problem**: finding a contiguous subarray with the largest sum within an array of numbers.

The brute force solution involves calculating the sum of every possible subarray, taking $O(N^2)$ time. Kadane's algorithm solves this in an optimal $O(N)$ time with $O(1)$ space.

The core intuition is simple: as we iterate through the array, we maintain a `current_sum`. For each element, we decide whether to add it to the existing `current_sum`, or to *start a fresh subarray* beginning with the current element.

We make this choice by checking if the existing `current_sum` is positive or negative. If `current_sum` drops below zero, it becomes a liability—it will only decrease the sum of future subarrays. Thus, we reset `current_sum` to `0` (or the current element itself). We continuously update our `max_sum` to record the highest value seen so far.

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int max_sum = nums[0];
        int current_sum = 0;
        for (int num : nums) {
            if (current_sum < 0) {
                current_sum = 0;
            }
            current_sum += num;
            max_sum = max(max_sum, current_sum);
        }
        return max_sum;
    }
};"

# Common Pitfalls
<Warning>
- **Array with All Negative Numbers:** If you initialize `max_sum` to `0` and the array contains only negative numbers, your algorithm will incorrectly return `0`. Always initialize `max_sum` to `nums[0]` or the smallest possible integer.
- **Incorrect Reset Logic:** Resetting `current_sum` *after* adding the current element instead of *before* can lead to missing the single largest negative element if the array is entirely negative.
</Warning>
