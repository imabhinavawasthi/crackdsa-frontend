# Theory & Concepts
Prefix Sum is a powerful array precomputation pattern. It involves creating an auxiliary array `prefix` where `prefix[i]` stores the sum of all elements from index `0` to index `i` of the original array.

### The Subarray Range Query Problem
Imagine you are given an array `A` of size `N`, and you need to answer `Q` queries of the form: *'What is the sum of elements from index L to R?'*

- **Brute Force**: For each query, we loop from `L` to `R` adding values. Each query takes O(N) time, making the total query operations O(Q * N).
- **Prefix Sum**: We precompute the prefix array in O(N) time. The sum of any subarray from `L` to `R` can then be retrieved in O(1) time using the mathematical subtraction formula:
  $$\text{Sum}(L, R) = \text{prefix}[R] - \text{prefix}[L-1]\quad(\text{with } \text{prefix}[-1] = 0)$$
  This reduces total query operations to O(N + Q), which scales incredibly well for massive databases!

# Visual Representation
```
Original Array A:
Index:      0     1     2     3     4
Value:    [ 3,    2,    8,    1,    5 ]

Prefix Sum Array Prefix:
Index:      0     1     2     3     4
Value:    [ 3,    5,   13,   14,   19 ]

Calculation:
Prefix[0] = 3
Prefix[1] = 3 + 2 = 5
Prefix[2] = 5 + 8 = 13
Range Sum [1, 3] = Prefix[3] - Prefix[0] = 14 - 3 = 11 (2 + 8 + 1 = 11)
```

#include <iostream>
#include <vector>

class RangeQuery {
private:
    std::vector<int> prefix;
public:
    RangeQuery(std::vector<int>& arr) {
        int n = arr.size();
        prefix.resize(n, 0);
        prefix[0] = arr[0];
        for (int i = 1; i < n; i++) {
            prefix[i] = prefix[i-1] + arr[i];
        }
    }
    
    int getSum(int L, int R) {
        if (L == 0) return prefix[R];
        return prefix[R] - prefix[L-1];
    }
};"

def prefix_sum_queries(arr, queries):
    prefix = [0] * len(arr)
    prefix[0] = arr[0]
    for i in range(1, len(arr)):
        prefix[i] = prefix[i-1] + arr[i]
        
    results = []
    for L, R in queries:
        if L == 0:
            results.append(prefix[R])
        else:
            results.append(prefix[R] - prefix[L-1])
    return results

# Common Pitfalls
<Warning>
- Accessing `prefix[L-1]` when `L = 0`, causing an Array Index Out Of Bounds exception. Always wrap this check in a boundary handler.
- Utilizing Prefix Sum on an array that receives frequent dynamic updates. For dynamic range updates, use Segment Trees or Fenwick Trees instead!
</Warning>
