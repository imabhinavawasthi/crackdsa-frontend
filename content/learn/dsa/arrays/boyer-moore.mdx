# Theory & Concepts
The **Boyer-Moore Majority Vote Algorithm** is an ingenious algorithm used to find the "majority element" in an array. A majority element is defined as an element that appears **strictly more than $\lfloor N/2 \rfloor$ times** in an array of size $N$. 

While you can easily solve this problem using a Hash Map in $O(N)$ time and $O(N)$ space, or by sorting the array in $O(N \log N)$ time and picking the middle element, Boyer-Moore does it in **$O(N)$ time and strictly $O(1)$ auxiliary space**.

### The Core Intuition
Imagine the array elements as delegates from different political parties. You want to find the party that holds an absolute majority (more than 50% of the delegates). 
If a delegate meets someone from their own party, they pair up and their presence gets stronger. If they meet someone from a *different* party, they cancel each other out.

Because the majority party has more than 50% of the delegates, even if all other parties gang up and mutually destruct with the majority party, the majority party will *still* have at least one delegate remaining at the end.

The algorithm runs in two phases (though phase 2 is optional if the problem guarantees a majority element exists):
1. **Candidate Phase:** Find a potential candidate for the majority element.
2. **Verification Phase:** Count the occurrences of the candidate to verify it actually appears more than $\lfloor N/2 \rfloor$ times.

# Common Pitfalls
<Warning>
- **Assuming a majority always exists:** The candidate phase *always* returns an element. If the input is `[1, 2, 3]`, it might return `3` as the candidate. But `3` is not a majority element. Always implement the verification phase unless the problem explicitly states that a majority element *always* exists.
- **Applying to $> N/3$ incorrectly:** There is a variant of this algorithm for finding elements appearing more than $\lfloor N/3 \rfloor$ times. It requires tracking *two* candidates and *two* counts. Don't try to use the basic single-candidate logic for $> N/3$ problems.
</Warning>
