# Theory & Concepts
The **Sliding Window** is an algorithmic technique used for finding subarrays or substrings that satisfy a specific condition. It significantly optimizes brute-force nested loop approaches ($O(N^2)$) by converting them into single-pass linear time operations ($O(N)$).

Imagine a window positioned over an array. The window represents our current subarray. We expand the window by moving the right edge (`right` pointer) to include new elements. If the window violates the target condition, we shrink it from the left by moving the left edge (`left` pointer) until the condition is met again.

Sliding Window is ideal for:
1. **Fixed Size Windows:** e.g., "Find the maximum sum of a subarray of size K".
2. **Dynamic Size Windows:** e.g., "Find the smallest subarray with sum $\geq S$".

class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int left = 0, current_sum = 0;
        int min_length = INT_MAX;
        
        for (int right = 0; right < nums.size(); right++) {
            current_sum += nums[right];
            
            while (current_sum >= target) {
                min_length = min(min_length, right - left + 1);
                current_sum -= nums[left];
                left++;
            }
        }
        return min_length == INT_MAX ? 0 : min_length;
    }
};"

# Common Pitfalls
<Warning>
- **Off-by-One Window Sizing:** Calculating the window length dynamically as `right - left` instead of `right - left + 1`. Always remember that indices are 0-based and inclusive.
- **Negative Numbers in Dynamic Windows:** Standard Sliding Window depends on monotonic growth. If the array contains negative numbers, expanding the window does *not* guarantee the sum will increase. In those cases, you must use a Deque or Prefix Sum with a Hash Map.
</Warning>
