# Theory & Concepts
The **Difference Array** technique is a powerful optimization used when we need to apply multiple range update operations (e.g., adding a value $V$ to all elements from index $L$ to $R$) to an array, and only query the final array after all updates are done.

Normally, updating a range $[L, R]$ takes $O(N)$ time. If we have $Q$ updates, the total time is $O(Q \times N)$.
A Difference Array, `diff`, stores the difference between adjacent elements: `diff[i] = A[i] - A[i-1]`.

To add $V$ to the range $[L, R]$, we simply perform two $O(1)$ operations:
1. `diff[L] += V` (This adds $V$ to $A[L]$ and all subsequent elements when we rebuild the array).
2. `diff[R + 1] -= V` (This cancels out the addition for elements starting from $R+1$).

After applying all $Q$ operations in $O(Q)$ time, we rebuild the final array by computing the **Prefix Sum** of the `diff` array in $O(N)$ time. Total time: $O(Q + N)$.

# Common Pitfalls
<Warning>
- Forgetting to allocate `N + 1` size for the difference array. When an update covers up to the last element (`R = N - 1`), you must access `diff[R + 1]`, which will cause an index out of bounds error if the array size is exactly `N`.
- Trying to query individual array elements *during* the update phase. The Difference Array is strictly an offline algorithm—you cannot accurately read the array's state until you reconstruct it with a prefix sum pass.
</Warning>
