# Theory & Concepts
Finding duplicates in an array where elements are in the range `[1, N]` (or `[0, N-1]`) and the array size is `N` (or `N+1`) is a classic problem. The brute force approach takes $O(N^2)$ time by comparing every pair, and sorting takes $O(N \log N)$. However, utilizing the properties of array indices allows us to find duplicates in $O(N)$ time.

The key insight is treating the array values as **indices**. Since elements are within the range of array indices, we can iterate through the array and mutate the element at the index corresponding to the current value. If we encounter a value, say `x`, we go to index `|x|` and make the value there negative. If we encounter a value whose corresponding index is already negative, we know `x` is a duplicate.

public:
    vector<int> findDuplicates(vector<int>& nums) {
        vector<int> result;
        for(int i = 0; i < nums.size(); i++) {
            int index = abs(nums[i]) - 1;
            if(nums[index] < 0) {
                result.push_back(index + 1);
            } else {
                nums[index] = -nums[index];
            }
        }
        return result;
    }

# Common Pitfalls
<Warning>
- Forgetting to use the absolute value `abs(nums[i])` when accessing the array can lead to out-of-bounds exceptions, as previous iterations might have turned the value negative.
- The technique of using values as indices strictly requires the range of values to fit within the array length bounds (e.g., values from 1 to N for an array of size N).
</Warning>
