# Theory & Concepts
The **2D Prefix Sum** is an extension of the 1D Prefix Sum, applied to a 2D matrix or grid. It allows us to answer 2D range sum queries (sum of elements inside a specific rectangular subgrid) in **constant $O(1)$ time** after an initial $O(M \times N)$ precomputation step, where $M$ is the number of rows and $N$ is the number of columns.

The 2D prefix sum array `prefix` is defined such that `prefix[r][c]` contains the sum of all elements in the rectangle bounded by the top-left corner `(0, 0)` and the bottom-right corner `(r, c)`.

To build this, we use the Inclusion-Exclusion Principle:
`prefix[r][c] = matrix[r][c] + prefix[r-1][c] + prefix[r][c-1] - prefix[r-1][c-1]`

To query the sum of a rectangle from top-left `(r1, c1)` to bottom-right `(r2, c2)`, we again use Inclusion-Exclusion:
`Sum = prefix[r2][c2] - prefix[r1-1][c2] - prefix[r2][c1-1] + prefix[r1-1][c1-1]`

# Common Pitfalls
<Warning>
- **Index Off-by-One Errors:** It is highly recommended to pad the prefix matrix with an extra row and column of zeros. This 1-indexed approach completely eliminates nasty bounds checking when subtracting `prefix[r1-1]` or `prefix[c1-1]`.
- **Double Counting / Double Subtracting:** The Inclusion-Exclusion formula is prone to typos. Ensure you subtract the two overlapping rectangles correctly and *add back* the doubly subtracted corner region!
</Warning>
