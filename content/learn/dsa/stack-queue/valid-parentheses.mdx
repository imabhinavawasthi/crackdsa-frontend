# Theory & Concepts

The **Valid Parentheses** problem is one of the most frequently asked questions in coding interviews and is the quintessential stack problem. Given a string containing just the characters `'('`, `')'`, `'{'`, `'}'`, `'['` and `']'`, you need to determine if the input string is valid.

An input string is valid if:
1. Open brackets must be closed by the same type of brackets.
2. Open brackets must be closed in the correct order.
3. Every close bracket has a corresponding open bracket of the same type.

**Intuition**
Since brackets must be closed in the reverse order of how they were opened, a LIFO data structure—a Stack—is perfect. As we iterate through the string, if we see an open bracket, we push it onto the stack. If we see a close bracket, we check the top of the stack. If it matches the corresponding open bracket, we pop it. If not, the string is invalid. Finally, if the stack is empty after full traversal, the string is valid.

                }
                st.pop();
            }
        }
        return st.empty();
    }

# Common Pitfalls

<Warning>
- **Forgetting to check if the stack is empty:** If the string starts with a closing bracket like `)]}`, attempting to pop an empty stack will throw an error or cause unexpected behavior.
- **Returning true immediately instead of checking if stack is empty at the end:** A string like `((()` will finish iterating without returning false, but it's invalid. You must `return stack.isEmpty()` at the end, not just `return true`.
</Warning>
