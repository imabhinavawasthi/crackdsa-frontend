# Theory & Concepts

**Sliding Window Maximum** is the hallmark problem for the Monotonic Deque. You are given an array `nums` and a sliding window of size `k` moving from left to right. You need to return the maximum value in the window at every step.

**Intuition**
A brute-force approach finds the max for every window, taking O(N * K) time. We can optimize this to O(N) using a **Monotonic Decreasing Deque**.
As the window slides right:
1. **Maintain Window Size:** Check the front of the deque. If the index stored there is out of the bounds of our current window `(i - k)`, pop it from the front.
2. **Maintain Monotonicity:** We want the maximum element at the front. Therefore, before adding a new element `nums[i]`, pop all elements from the back of the deque that are smaller than `nums[i]`. They are smaller and older, so they will never be the maximum!
3. **Record Answer:** Once the window has reached size `k` (when `i >= k - 1`), the maximum element for the current window is simply the value at the index stored at the front of the deque.

# Code Implementation

public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        vector<int> result;
        deque<int> dq; // stores indices
        
        for (int i = 0; i < nums.size(); i++) {
            // 1. Remove elements out of the window
            if (!dq.empty() && dq.front() == i - k) {
                dq.pop_front();
            }
            
            // 2. Remove elements from back that are smaller than current
            while (!dq.empty() && nums[dq.back()] < nums[i]) {
                dq.pop_back();
            }
            
            // 3. Add current element's index
            dq.push_back(i);
            
            // 4. If window has reached size k, record the max
            if (i >= k - 1) {
                result.push_back(nums[dq.front()]);
            }
        }
        return result;
    }
};"
  java="class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        int n = nums.length;
        int[] result = new int[n - k + 1];
        int resIndex = 0;
        Deque<Integer> dq = new LinkedList<>(); // stores indices
        
        for (int i = 0; i < n; i++) {
            // 1. Remove elements out of the window
            if (!dq.isEmpty() && dq.peekFirst() == i - k) {
                dq.pollFirst();
            }
            
            // 2. Remove elements from back that are smaller than current
            while (!dq.isEmpty() && nums[dq.peekLast()] < nums[i]) {
                dq.pollLast();
            }
            
            // 3. Add current element's index
            dq.offerLast(i);
            
            // 4. If window has reached size k, record the max
            if (i >= k - 1) {
                result[resIndex++] = nums[dq.peekFirst()];
            }
        }
        return result;
    }

class Solution:

# Common Pitfalls

<Warning>
- **Using `<` vs `<=`:** When popping from the back, `nums[dq.back()] < nums[i]` is usually sufficient, but `<=` is mathematically safer and slightly more optimal to clear out duplicates.
- **Recording Output Too Early:** Remember that you should only start adding the maximum to your result array once the loop index `i` has reached `k - 1`. Don't record partial windows.
</Warning>
