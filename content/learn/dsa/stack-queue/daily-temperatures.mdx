# Theory & Concepts

**Daily Temperatures** is the classic introduction to the **Monotonic Stack** pattern. Given an array of integers representing daily temperatures, you must return an array answering: "How many days do you have to wait after the `i-th` day to get a warmer temperature?" If there is no future day that is warmer, the answer is 0.

**Intuition**
The naive brute force approach is to run a nested loop, looking forward for the first warmer day. But that's O(N²).
Instead, we can use a stack to remember the days (indices) we haven't found a warmer day for yet. Because we want the *next greater element*, we keep the stack strictly decreasing (a Monotonic Decreasing Stack). 

As we iterate through the array:
1. If the current temperature is hotter than the temperature at the top of the stack, we've found our answer for the day at the top of the stack! We pop it, calculate the day difference, and repeat.
2. We then push the current day's index onto the stack, so it can wait for a future warmer day.

# Code Implementation

  cpp="class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> ans(n, 0);
        stack<int> st; // Stores indices
        
        for (int i = 0; i < n; i++) {
            while (!st.empty() && temperatures[i] > temperatures[st.top()]) {
                int prevIndex = st.top();
                st.pop();
                ans[prevIndex] = i - prevIndex;
            }
            st.push(i);
        }
        return ans;
    }
};"

# Common Pitfalls

<Warning>
- **Storing Values Instead of Indices:** You need to calculate the *number of days* (the difference between indices). If you only push the temperature value onto the stack, you lose track of which day it was! Always store indices in a monotonic stack.
- **Forgetting to pop:** Once a warmer day is found for an element in the stack, it must be removed. Otherwise, it will cause an infinite loop or wrong answers.
</Warning>
