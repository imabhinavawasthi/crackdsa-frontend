# Theory & Concepts

A **Double Ended Queue**, commonly referred to as a **Deque** (pronounced "deck"), is a highly versatile data structure that combines the capabilities of both a Stack and a Queue. 

In a standard Queue, elements can only be added to the back and removed from the front (FIFO). In a standard Stack, elements are added and removed from the same end (LIFO). A Deque allows insertion and deletion from **both** ends (front and back) in O(1) time.

Deques are extremely powerful when you need sliding window algorithms, undo/redo functionalities, or when simulating real-world lines where people can leave from either the front or the back.

# Common Pitfalls

<Warning>
- **Using Arrays/Lists inappropriately:** In Python, never use a standard `list` to simulate a Deque if you need to pop from the front. `list.pop(0)` takes O(N) time. Always import `collections.deque`.
- **Memory Overhead:** While Deques provide O(1) operations, they often have a slightly higher memory footprint and cache miss rate compared to a raw array because they are usually implemented as doubly-linked lists or dynamic blocks of arrays under the hood.
</Warning>
