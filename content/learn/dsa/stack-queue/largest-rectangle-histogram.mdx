# Theory & Concepts

**Largest Rectangle in Histogram** is considered one of the hardest stack problems, but it boils down to finding the **Next Smaller Element** and **Previous Smaller Element** for every bar.

**Intuition**
For any given bar at index `i` with height `h`, the maximum rectangle that can be formed using this bar as the *minimum height* extends to the left until it hits a shorter bar, and extends to the right until it hits a shorter bar.

Therefore, for every bar, we need:
1. `left_smaller_index`
2. `right_smaller_index`
The area is then: `h * (right_smaller_index - left_smaller_index - 1)`.

Instead of calculating these arrays in three passes, we can use a **Monotonic Increasing Stack** to do it in one pass! If we encounter a bar that is shorter than the top of our stack, it means the current bar is the `right_smaller_index` for the stack's top. The `left_smaller_index` is simply the new top of the stack after we pop!

# Code Implementation

<CodeBlock
  cpp="class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        int maxArea = 0;
        stack<int> st; // stores indices
        int n = heights.size();
        
        for (int i = 0; i <= n; i++) {
            // We use a dummy height of 0 at the end to force all remaining bars to pop
            int currentHeight = (i == n) ? 0 : heights[i];
            
            while (!st.empty() && currentHeight < heights[st.top()]) {
                int height = heights[st.top()];
                st.pop();
                int width = st.empty() ? i : (i - st.top() - 1);
                maxArea = max(maxArea, height * width);
            }
            st.push(i);
        }
        return maxArea;
    }
};"
  java="class Solution {
    public int largestRectangleArea(int[] heights) {
        int maxArea = 0;
        Stack<Integer> stack = new Stack<>();
        int n = heights.length;
        
        for (int i = 0; i <= n; i++) {
            int currentHeight = (i == n) ? 0 : heights[i];
            
            while (!stack.isEmpty() && currentHeight < heights[stack.peek()]) {
                int height = heights[stack.pop()];
                int width = stack.isEmpty() ? i : (i - stack.peek() - 1);
                maxArea = Math.max(maxArea, height * width);
            }
            stack.push(i);
        }
        return maxArea;
    }
}"
  python="class Solution:
    def largestRectangleArea(self, heights: list[int]) -> int:
        max_area = 0
        stack = [] # stores indices
        heights.append(0) # Dummy bar to pop remaining elements
        
        for i, current_height in enumerate(heights):
            while stack and current_height < heights[stack[-1]]:
                height = heights[stack.pop()]
                width = i if not stack else (i - stack[-1] - 1)
                max_area = max(max_area, height * width)
            stack.append(i)
            
        heights.pop() # Clean up the dummy bar
        return max_area"

# Common Pitfalls

<Warning>
- **Remaining Elements in Stack:** After the loop, the stack might still contain elements (e.g., if the histogram was entirely increasing). A very elegant trick is appending a dummy `0` to the end of the array, which automatically forces all remaining bars to be popped and processed!
- **Width Calculation:** The width is `i - stack.top() - 1`, not `i - popped_index`. If the stack is empty, it means the popped bar was the smallest seen so far, so the width is simply `i`.
</Warning>
