# Theory & Concepts

**Reverse Polish Notation (RPN)**, also known as postfix notation, is a mathematical notation in which every operator follows all of its operands. For example, `3 4 +` means `3 + 4`. The expression `2 1 + 3 *` evaluates to `(2 + 1) * 3 = 9`.

RPN has a massive advantage: it completely removes the need for parentheses and operator precedence rules. Compilers often convert standard infix expressions (like `3 + 4`) into postfix notation before evaluating them.

**Intuition**
Evaluating an RPN expression naturally screams "Stack". We process the tokens one by one:
1. If the token is a number, we push it onto the stack.
2. If the token is an operator (`+`, `-`, `*`, `/`), we pop the top two numbers from the stack, apply the operator to them, and push the result back onto the stack.
3. At the end, the stack will contain exactly one element: the final result.

# Common Pitfalls

<Warning>
- **Order of Operands:** When popping two elements for subtraction or division, order matters! The first element popped is the *second* operand (`b`), and the second element popped is the *first* operand (`a`). So it is `a - b`, not `b - a`.
- **Integer Division Truncation:** In Python, `//` truncates toward negative infinity. But C++ and Java truncate toward zero. To mimic C++/Java in Python for negative numbers, use `int(a / b)` instead of `a // b`.
</Warning>
