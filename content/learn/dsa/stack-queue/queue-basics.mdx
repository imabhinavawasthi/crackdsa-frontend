# Theory & Concepts

A **Queue** is a linear data structure that operates on the **FIFO (First In First Out)** principle. This means that the first element added to the queue will be the first one to be removed. You can think of a queue like a line of people waiting for a bus—the person who arrives first gets on the bus first.

Queues are heavily used in scheduling algorithms, managing requests in web servers, breadth-first search (BFS) algorithms in graphs and trees, and handling asynchronous data streams.

The core operations for a queue are:
- **Enqueue (Push):** Adds an element to the rear (back) of the queue.
- **Dequeue (Pop):** Removes an element from the front of the queue.
- **Front / Peek:** Returns the front element without removing it.
- **isEmpty:** Checks whether the queue is empty.

class Queue:
    def __init__(self):
        # We use deque instead of a list for O(1) pops from the left
        self.elements = deque()
        
    def enqueue(self, x: int) -> None:
        self.elements.append(x)
        
    def dequeue(self) -> None:
        if self.elements:
            self.elements.popleft()

        if self.elements:
            return self.elements[0]
        return -1 # Or raise exception
        
    def is_empty(self) -> bool:
        return len(self.elements) == 0"

# Common Pitfalls

<Warning>
- **Using arrays/lists improperly:** Using a dynamic array and physically removing the 0th element takes O(N) time because all subsequent elements must be shifted. Always use double-ended queues (deque) or keep a front pointer.
- **Dequeuing an Empty Queue:** Make sure you verify `isEmpty()` before accessing the front element, or you'll run into index out-of-bound errors.
</Warning>
