# Theory & Concepts

In the **Decode String** problem, you are given an encoded string where a number `k` followed by `[encoded_string]` means the `encoded_string` is repeated exactly `k` times. For example, `"3[a]2[bc]"` decodes to `"aaabcbc"`, and `"3[a2[c]]"` decodes to `"accaccacc"`.

**Intuition**
The presence of nested structures—brackets inside brackets—is a massive neon sign pointing to a **Stack**. 
When we encounter an open bracket `[`, it means we are entering a new inner context. We must save our current state (the current string built so far and the current multiplier `k`) onto the stack. 
When we encounter a closing bracket `]`, we've finished the inner context. We pop the multiplier and the previous string state from the stack, multiply our inner string, append it to the previous string state, and continue.

# Common Pitfalls

<Warning>
- **Multi-digit Numbers:** A very common mistake is assuming the multiplier `k` is a single digit. You must construct the number iteratively: `k = k * 10 + int(char)`.
- **String Concatenation Overhead:** In Java, using immutable `String` for concatenation in a loop results in massive performance hits. Always use `StringBuilder`.
</Warning>
