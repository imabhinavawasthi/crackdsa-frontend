# Theory & Concepts

**Frequency Counting** is one of the most fundamental and heavily tested patterns in technical interviews. It involves using a Hash Map (or a fixed-size array if the key range is small and known, like lowercase English letters) to count the occurrences of each element in a dataset.

### Why is this Pattern Important?
Many brute-force solutions involve nested loops: one loop to pick an element, and an inner loop to count how many times it appears in the rest of the array. That's an $O(N^2)$ operation.

By using a Hash Map, we can iterate through the data *exactly once*, recording frequencies as we go. We can then do a second $O(N)$ pass over the Hash Map to find our answer. This brings our total time down to $O(N)$.

### Common Applications
1. **Anagrams:** Check if two strings have the exact same character frequencies.
2. **Top K Frequent Elements:** Count all frequencies, then use a Min-Heap or Bucket Sort to find the most frequent ones.
3. **Subarrays with Exact K Distinct Elements:** Used alongside the Sliding Window pattern.

# Code Implementation

Here is a simple implementation that finds the element with the highest frequency in an array.

<CodeBlock
  cpp="```cpp
#include <iostream>
#include <vector>
#include <unordered_map>

using namespace std;

class Solution {
public:
    int mostFrequent(vector<int>& nums) {
        unordered_map<int, int> freqMap;
        
        // Step 1: Count frequencies
        for (int num : nums) {
            freqMap[num]++;
        }
        
        // Step 2: Find the maximum
        int maxFreq = 0;
        int maxElement = -1;
        
        for (auto const& [key, count] : freqMap) {
            if (count > maxFreq) {
                maxFreq = count;
                maxElement = key;
            }
        }
        
        return maxElement;
    }
};

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int mostFrequent(int[] nums) {
        Map<Integer, Integer> freqMap = new HashMap<>();
        
        // Step 1: Count frequencies
        for (int num : nums) {
            freqMap.put(num, freqMap.getOrDefault(num, 0) + 1);
        }
        
        // Step 2: Find the maximum
        int maxFreq = 0;
        int maxElement = -1;
        
        for (Map.Entry<Integer, Integer> entry : freqMap.entrySet()) {
            if (entry.getValue() > maxFreq) {
                maxFreq = entry.getValue();
                maxElement = entry.getKey();
            }
        }
        
        return maxElement;
    }
}

# Common Pitfalls

<Warning>
- **Iterating over the array instead of the map:** If you need to find the max frequency, iterate over the keys of your Map! Iterating over the original array again might mean processing duplicate keys multiple times.
- **`getOrDefault` in Java:** Don't write `if-else` blocks to check if a key exists before incrementing. Use Java's `map.put(key, map.getOrDefault(key, 0) + 1)` for clean, professional code.
</Warning>
