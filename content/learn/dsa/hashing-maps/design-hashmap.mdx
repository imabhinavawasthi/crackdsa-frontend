# Theory & Concepts

"Design a HashMap" is a classic, high-frequency interview question that tests whether you understand how standard library data structures work underneath. You cannot use built-in Hash structures here.

### Approach: Array of Linked Lists (Separate Chaining)

The most standard and robust way to design a HashMap in an interview is using **Separate Chaining**. 
1. **Bucket Array:** We maintain an array of a fixed size (e.g., 1000 or 10000). 
2. **Nodes:** Each slot (bucket) in the array will hold a pointer to a Linked List node.
3. **Hash Function:** The hash function maps a `key` to an array index: `index = key % ARRAY_SIZE`.
4. **Operations:**
   - `put(key, value)`: Find the index. Traverse the linked list. If the key exists, update its value. If it doesn't exist, append a new Node.
   - `get(key)`: Find the index. Traverse the linked list. If found, return the value. If not, return -1.
   - `remove(key)`: Find the index. Traverse the linked list keeping track of a `prev` pointer to safely delete the target node.

### Why not Open Addressing?
While open addressing (linear probing) is valid, writing the deletion logic for linear probing in a 45-minute interview is notoriously difficult because you must implement "tombstones" (dummy deleted markers) to keep search chains intact. Separate chaining is vastly easier to code flawlessly.

#include <iostream>
#include <vector>

using namespace std;

struct Node {
    int key, val;
    Node* next;
    Node(int k, int v) : key(k), val(v), next(nullptr) {}
};

class MyHashMap {
private:
    vector<Node*> buckets;
    int size = 10000;
    
    int getHash(int key) {
        return key % size;
    }
    
public:
    MyHashMap() {
        buckets.resize(size, nullptr);
    }
    
    void put(int key, int value) {
        int idx = getHash(key);
        Node* head = buckets[idx];
        
        // Check if key already exists to update
        Node* curr = head;
        while (curr) {
            if (curr->key == key) {
                curr->val = value;
                return;
            }
            curr = curr->next;
        }
        
        // Insert new node at head
        Node* newNode = new Node(key, value);
        newNode->next = head;
        buckets[idx] = newNode;
    }
    
    int get(int key) {
        int idx = getHash(key);
        Node* curr = buckets[idx];
        
        while (curr) {
            if (curr->key == key) return curr->val;
            curr = curr->next;
        }
        return -1;
    }
    
    void remove(int key) {
        int idx = getHash(key);
        Node* curr = buckets[idx];
        Node* prev = nullptr;
        
        while (curr) {
            if (curr->key == key) {
                if (prev) prev->next = curr->next;
                else buckets[idx] = curr->next;
                delete curr;
                return;
            }
            prev = curr;
            curr = curr->next;
        }
    }
};

# Common Pitfalls

<Warning>
- **Forgetting to update existing keys:** When calling `put(key, val)`, you must first check if the key already exists in the chain. If it does, update the value. If you don't check, you will insert duplicate keys into the linked list, which breaks `get()`.
- **Messy Linked List Deletion:** Deleting from a linked list requires a `prev` pointer. Be very careful handling the case where the node to delete is the *head* of the bucket chain!
</Warning>
