# Theory & Concepts

The **Majority Element** problem asks you to find an element in an array of size $N$ that appears more than $\lfloor N/2 \rfloor$ times. You may assume that the majority element always exists in the array.

### Approaches

**1. The Hash Map Approach ($O(N)$ Space)**
The most intuitive solution is a direct application of the **Frequency Counting** pattern. We create a Hash Map, iterate through the array, and maintain a count of each element. The moment a count exceeds $\lfloor N/2 \rfloor$, we immediately return that element.

**2. Sorting Approach ($O(N \log N)$ Time, $O(1)$ Space)**
If an element appears more than $N/2$ times, then if you sort the array, the element at index $N/2$ will *always* be the majority element. 

**3. Boyer-Moore Voting Algorithm ($O(N)$ Time, $O(1)$ Space)**
While the Hash Map approach is perfectly valid and excellent to discuss, the optimal solution to this specific problem uses the Boyer-Moore Voting Algorithm. It maintains a `candidate` and a `count`. When `count` is $0$, we pick a new candidate. If the current number matches the candidate, we increment `count`, otherwise we decrement it.

*Note: We will focus on the Hash Map approach here as it generalizes easily to finding elements appearing more than $\lfloor N/3 \rfloor$ or $\lfloor N/K \rfloor$ times.*

#include <iostream>
#include <vector>
#include <unordered_map>

using namespace std;

class Solution {

    int majorityElement(vector<int>& nums) {

        int target = nums.size() / 2;
        
        for (int num : nums) {
            counts[num]++;
            if (counts[num] > target) {
                return num;

class Solution {

        }

}

# Common Pitfalls

<Warning>
- **Waiting until the end to check:** A common mistake is to count *all* frequencies first, and then do a second loop over the map to find the max. It's much faster to check `if count > n/2` *during* the initial iteration!
- **Not knowing the optimal $O(1)$ space solution:** Even if you write the HashMap code flawlessly, the interviewer will almost certainly ask: "Can you do this in $O(1)$ space without sorting?". You must know the Boyer-Moore Voting Algorithm.
</Warning>
