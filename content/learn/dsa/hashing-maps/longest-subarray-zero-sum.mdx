# Theory & Concepts
Finding the longest subarray with a sum of zero is a direct application of the Prefix Sum and Hashing technique. As we traverse the array, we maintain a running prefix sum. 

The key insight is that if the same prefix sum appears at two different indices, say $i$ and $j$ (where $i < j$), the sum of the elements between index $i+1$ and index $j$ must be exactly zero. To find the *longest* such subarray, we need to record the *first occurrence* of each prefix sum we encounter. When we see a prefix sum again, we calculate the length of the subarray as $j - i$, and update our maximum length if this new length is greater.

    int maxLen(vector<int>& arr) {

    }

# Common Pitfalls
<Warning>
- Updating the index of a previously seen prefix sum. We must only store its *first* occurrence to maximize the subarray length.
- Failing to handle the case where the prefix sum itself is zero. A subarray from index `0` to `i` with sum `0` has a length of `i + 1`.
- Not accounting for arrays consisting of only positive numbers (where no zero-sum subarray is possible). The logic handles this gracefully if implemented correctly.
</Warning>
