# Theory & Concepts

The **Contains Duplicate** series is a fantastic progression of problems that tests your ability to evolve a solution from a simple Hash Set to a Hash Map, and finally to a Sliding Window or Tree Map.

### 1. Contains Duplicate I
**Problem:** Given an array, return `true` if any value appears at least twice.
**Intuition:** This is a pure **Hash Set** problem. As we iterate, if the current element is already in the set, return `true`. Otherwise, add it.
*Time: O(N), Space: O(N)*

### 2. Contains Duplicate II
**Problem:** Given an array and an integer `k`, return `true` if there are two identical elements such that the absolute difference of their indices is `<= k`.
**Intuition:** A Set is no longer enough because we need to know *where* we last saw the element. We use a **Hash Map** to store `value -> last_seen_index`. If we see a number again, we check if `current_index - map.get(number) <= k`. If yes, return `true`. Otherwise, update the index in the map to the current index.
*Time: O(N), Space: O(N)*

### 3. Contains Duplicate III
**Problem:** Find two distinct indices `i` and `j` such that `abs(nums[i] - nums[j]) <= t` and `abs(i - j) <= k`.
**Intuition:** Hash Maps only allow exact matches ($O(1)$). To find values *within a range*, we need a data structure that keeps elements sorted, like a Balanced Binary Search Tree (`std::set` in C++, `TreeSet` in Java). Combined with a Sliding Window of size $k$, we can do an $O(\log k)$ lookup for each element.
*Time: O(N log K), Space: O(K)*

# Code Implementation

Here we will implement the **Contains Duplicate II** solution, as it perfectly demonstrates the power of mapping values to their indices.

<CodeBlock

#include <iostream>
#include <vector>
#include <unordered_map>

using namespace std;

class Solution {
public:
    bool containsNearbyDuplicate(vector<int>& nums, int k) {
        // Map to store: Element -> Last seen index
        unordered_map<int, int> seenMap;
        
        for (int i = 0; i < nums.size(); i++) {
            int num = nums[i];
            
            // If the element was seen before, check index difference
            if (seenMap.count(num)) {
                if (i - seenMap[num] <= k) {
                    return true;
                }
            }
            // Update the last seen index to the most recent one!
            seenMap[num] = i;
        }
        
        return false;
    }
};

# Common Pitfalls

<Warning>
- **Failing to update the index:** If you see a duplicate but the distance is $> k$, you MUST update the map with the *new* current index! Why? Because this new index might be $\le k$ away from the *next* occurrence of the number.
- **Using $O(N^2)$ sliding window:** Don't use a nested loop to check the previous $k$ elements. That degrades to $O(N \cdot K)$, which will Time Out for large $K$.
</Warning>
