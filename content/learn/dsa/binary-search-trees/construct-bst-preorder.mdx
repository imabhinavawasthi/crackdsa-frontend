# Theory & Concepts
Given an array representing the **Preorder Traversal** of a Binary Search Tree (BST), your task is to reconstruct the original tree. This is a classic deserialization problem that beautifully tests your understanding of BST bounds.

### Core Intuition
In a Preorder traversal (`Root -> Left -> Right`), the first element of the array is always the root of the tree. 
We can rebuild the tree efficiently by passing an **Upper Bound**. 
Since we process elements from left to right:
1. We keep a global pointer/index for our position in the array.
2. If the current element exceeds our allowed upper bound, it means we have finished building the left subtree and must return to construct the right subtree!
3. If it's valid, we create a node, then recursively build its left child (updating the bound to the current node's value) and its right child (keeping the previous upper bound).

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    TreeNode* bstFromPreorder(vector<int>& preorder) {
        int index = 0;
        return build(preorder, index, INT_MAX);
    }
    
private:
    TreeNode* build(const vector<int>& preorder, int& index, int upperBound) {
        if (index == preorder.size() || preorder[index] > upperBound) {
            return nullptr;
        }
        
        TreeNode* root = new TreeNode(preorder[index++]);
        root->left = build(preorder, index, root->val);
        root->right = build(preorder, index, upperBound);
        
        return root;
    }
};"
  java="class Solution {
    private int index = 0;
    
    public TreeNode bstFromPreorder(int[] preorder) {
        return build(preorder, Integer.MAX_VALUE);
    }
    
    private TreeNode build(int[] preorder, int upperBound) {
        if (index == preorder.length || preorder[index] > upperBound) {
            return null;
        }
        
        TreeNode root = new TreeNode(preorder[index++]);
        root.left = build(preorder, root.val);
        root.right = build(preorder, upperBound);
        
        return root;
    }
}"
  python="class Solution:
    def bstFromPreorder(self, preorder: list[int]) -> TreeNode:
        self.index = 0
        
        def build(upper_bound):
            if self.index == len(preorder) or preorder[self.index] > upper_bound:
                return None
                
            val = preorder[self.index]
            self.index += 1
            root = TreeNode(val)
            
            root.left = build(val)
            root.right = build(upper_bound)
            
            return root

# Common Pitfalls
<Warning>
- Using an $O(N^2)$ approach where you iterate through the remaining array to find the first element strictly greater than the root to divide the left and right subtrees. The $O(N)$ upper bound approach is much better.
- Sorting the preorder array to get the inorder array, and then building the BST using both traversals in $O(N \log N)$ time. While technically correct, it's suboptimal.
</Warning>
