# Theory & Concepts
The foundational operations of a **Binary Search Tree (BST)** are **Searching** for a value and **Inserting** a new value. Both operations take advantage of the BST property to eliminate half of the tree at each step.

### Core Intuition
- **Searching**: Start at the root. If the target is equal to the root, return the root. If the target is smaller, search the left subtree. If it's larger, search the right subtree. This mirrors the logic of Binary Search on an array.
- **Inserting**: Finding where to insert a node is exactly like searching for it. We traverse down the tree until we hit a `null` pointer, and that is precisely where the new node should be attached!

# Common Pitfalls
<Warning>
- Using recursion for basic Search and Insert is valid, but an iterative approach saves O(H) call stack space and is extremely easy to write.
- Forgetting to link the newly inserted node to its parent when doing an iterative insertion.
</Warning>
