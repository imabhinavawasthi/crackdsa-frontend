# Theory & Concepts
While the basic definition of a **Binary Search Tree (BST)** focuses on the `Left < Root < Right` rule, there are several advanced properties that are indispensable for coding interviews.

### Core Properties & Deductions
1. **Sorted Sequence Equivalency**: Any operation you can do on a sorted array can theoretically be done on a BST (like Binary Search).
2. **Successor and Predecessor**: 
   - **Inorder Successor**: The smallest node in the right subtree (go right, then all the way left).
   - **Inorder Predecessor**: The largest node in the left subtree (go left, then all the way right).
3. **Subtree Bounds**: Every subtree in a BST operates within a strict `[min, max]` bound inherited from its ancestors. When you go left, the current node's value becomes the new `max`. When you go right, the current node's value becomes the new `min`.

  java="class Solution {
    public TreeNode getSuccessor(TreeNode root) {
        if (root == null || root.right == null) return null;
        TreeNode curr = root.right;
        while (curr.left != null) {
            curr = curr.left;
        }
        return curr;
    }
}"

# Common Pitfalls
<Warning>
- Forgetting that the successor could be an ancestor if the right subtree is empty (though the code above assumes finding successor of a node with a right subtree).
- Assuming duplicates are handled consistently. In some BST definitions, duplicates go left, in others right. Always clarify this with your interviewer.
</Warning>
