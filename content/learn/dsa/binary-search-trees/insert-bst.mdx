# Theory & Concepts
Inserting a new node into a **Binary Search Tree (BST)** is beautifully simple: new nodes are *always* added as leaf nodes. You never need to restructure the existing tree (unless you are implementing an auto-balancing tree like an AVL tree, which is rarely asked in standard interviews).

### Core Intuition
To insert a value:
1. Perform a standard BST search for the value.
2. Since the value doesn't exist (assuming all values are unique), your search will eventually hit a `null` pointer.
3. This `null` position is exactly where the new node belongs! Just attach it to the parent.

# Common Pitfalls
<Warning>
- Forgetting the edge case where the tree is initially empty (`root == null`).
- Not linking the newly created node back to its parent. In an iterative approach, you must check if the child is null *before* moving the pointer.
</Warning>
