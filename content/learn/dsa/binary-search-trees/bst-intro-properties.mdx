# Theory & Concepts
A **Binary Search Tree (BST)** is a powerful node-based binary tree data structure with the following critical properties:
1. The left subtree of a node contains only nodes with keys **strictly lesser** than the node's key.
2. The right subtree of a node contains only nodes with keys **strictly greater** than the node's key.
3. Both the left and right subtrees must also be binary search trees.

This structure allows for extremely fast lookups, additions, and deletions of items, typically taking $O(\log N)$ time for balanced trees. 

### Core Intuition
Because of its strict ordering, performing an **Inorder Traversal** (Left -> Root -> Right) on a valid BST guarantees that you will visit the nodes in strictly increasing (sorted) order. This property is frequently exploited in interview questions to solve problems optimally without needing extra sorts!

# Common Pitfalls
<Warning>
- Assuming a binary tree is a BST just because `node.left.val < node.val < node.right.val`. The BST property must hold for all descendants, meaning every node in the right subtree must be greater than the root!
- Over-complicating search problems. Many tree problems become trivial when you realize the input is a BST and you can just discard half the tree at each step.
</Warning>
