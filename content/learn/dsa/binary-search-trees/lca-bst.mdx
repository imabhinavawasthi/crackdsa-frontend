# Theory & Concepts
Finding the **Lowest Common Ancestor (LCA)** of two nodes in a Binary Tree usually requires a complex post-order traversal. However, if the tree is a **Binary Search Tree (BST)**, the problem becomes incredibly simple and efficient!

The LCA of two nodes `p` and `q` is the lowest (deepest) node `T` that has both `p` and `q` as descendants. A node is allowed to be a descendant of itself.

### Core Intuition
By utilizing the BST property (`Left < Root < Right`), we can find the split point where `p` and `q` diverge:
1. If both `p` and `q` are **less than** the root, then the LCA must be in the **left subtree**.
2. If both `p` and `q` are **greater than** the root, then the LCA must be in the **right subtree**.
3. If `p` and `q` are on **opposite sides** of the root, or if one of them *is* the root, then the current root is the LCA!

# Common Pitfalls
<Warning>
- Using the standard Binary Tree LCA algorithm (O(N) time). While it works, it completely ignores the BST property and is vastly inefficient compared to the O(H) solution.
- Assuming `p.val < q.val`. The problem rarely guarantees the order of the two nodes. Your condition must check if *both* are less than or *both* are greater than the root.
</Warning>
