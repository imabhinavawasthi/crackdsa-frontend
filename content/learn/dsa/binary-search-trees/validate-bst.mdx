# Theory & Concepts
Validating whether a given binary tree is a valid **Binary Search Tree (BST)** is one of the most frequently asked interview questions. It tests your fundamental understanding of the strict BST property.

### Core Intuition
A common beginner mistake is simply checking if `left.val < root.val < right.val` for every node. **This is incorrect!** The BST property states that *all* nodes in the left subtree must be less than the root, and *all* nodes in the right subtree must be greater. A node deep in the right subtree could erroneously be smaller than the main root.

**The Solution:** Top-Down Range Validation.
As we traverse down the tree, we pass down a valid `[min, max]` range. 
- When we branch left, the current node's value becomes the new strict upper bound (`max`).
- When we branch right, the current node's value becomes the new strict lower bound (`min`).

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    bool isValidBST(TreeNode* root) {
        return validate(root, nullptr, nullptr);
    }
    
private:
    bool validate(TreeNode* node, TreeNode* minNode, TreeNode* maxNode) {
        if (!node) return true;
        
        if (minNode && node->val <= minNode->val) return false;
        if (maxNode && node->val >= maxNode->val) return false;
        
        return validate(node->left, minNode, node) && 
               validate(node->right, node, maxNode);
    }
};"
  java="class Solution {
    public boolean isValidBST(TreeNode root) {
        return validate(root, null, null);
    }
    
    private boolean validate(TreeNode node, Integer min, Integer max) {
        if (node == null) return true;
        
        if (min != null && node.val <= min) return false;
        if (max != null && node.val >= max) return false;
        
        return validate(node.left, min, node.val) && 
               validate(node.right, node.val, max);
    }
}"
  python="class Solution:
    def isValidBST(self, root: TreeNode) -> bool:
        def validate(node, min_val, max_val):
            if not node:
                return True
            
            if node.val <= min_val or node.val >= max_val:
                return False
                
            return validate(node.left, min_val, node.val) and \
                   validate(node.right, node.val, max_val)

# Common Pitfalls
<Warning>
- Using integer minimum/maximum values (like `INT_MIN`) for bounds, which fails if the tree actually contains `INT_MIN`. Use pointers in C++, `Integer` objects in Java (for null checks), or `float('-inf')` in Python to handle absolute bounds safely.
- Forgetting that the BST property strictly requires `<` and `>`, not `<=` and `>=`. Duplicates usually invalidate a strict BST.
</Warning>
