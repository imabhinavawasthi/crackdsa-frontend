# Theory & Concepts
Deleting a node from a **Binary Search Tree (BST)** is the most complex of the fundamental operations because we must maintain the strict BST property after the node is removed. 

### Core Intuition
When deleting a node, we encounter three possible cases:
1. **The node is a leaf (no children):** Simply remove it by returning `null` to its parent.
2. **The node has one child:** Remove the node and directly connect its parent to its only child.
3. **The node has two children (The Hard Case):** We cannot simply delete it because it holds two subtrees together. Instead, we:
   - Find its **Inorder Successor** (the smallest node in its right subtree).
   - Replace the value of the node we want to delete with the successor's value.
   - Recursively delete the successor node from the right subtree (which is guaranteed to fall into Case 1 or Case 2, as a successor cannot have a left child!).

    TreeNode* deleteNode(TreeNode* root, int key) {
        if (!root) return nullptr;
        
        if (key < root->val) {
            root->left = deleteNode(root->left, key);
        } else if (key > root->val) {
            root->right = deleteNode(root->right, key);
        } else {
            // Node found
            if (!root->left) return root->right;
            if (!root->right) return root->left;
            
            // Case 3: Two children
            TreeNode* minNode = findMin(root->right);
            root->val = minNode->val;
            root->right = deleteNode(root->right, minNode->val);
        }
        return root;
    }
    
private:
    TreeNode* findMin(TreeNode* node) {
        while (node->left) node = node->left;
        return node;
    }
};"

# Common Pitfalls
<Warning>
- Forgetting to reassign the pointers `root.left = ...` and `root.right = ...` when unwinding the recursion.
- In Case 3, blindly trying to rewire pointers instead of swapping values. Swapping values and delegating the deletion of the leaf/single-child successor is vastly simpler and less error-prone.
</Warning>
