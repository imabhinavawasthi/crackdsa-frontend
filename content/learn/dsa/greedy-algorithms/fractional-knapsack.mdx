# Theory & Concepts
The **Fractional Knapsack Problem** is a classic algorithmic problem where the goal is to maximize the total value of items placed in a knapsack of a given capacity `W`. Unlike the 0/1 Knapsack problem where you must take an item entirely or leave it, here you can break items into fractions to maximize your profit.

Because you can take fractions of an item, a Greedy approach works perfectly. 

### The Greedy Strategy
To maximize the value in the knapsack, you should always pick the item that offers the highest value for the lowest weight.
1. Calculate the **value-to-weight ratio** for each item.
2. Sort all items in descending order of this ratio.
3. Iterate through the sorted items:
   - If the entire item fits in the remaining capacity, take it entirely.
   - If it doesn't fit entirely, take the maximum possible fraction of it that fills the knapsack to its exact limit, and break the loop since the knapsack is now full.

# Common Pitfalls
<Warning>
- Using integer division instead of floating-point division when calculating the value-to-weight ratio. `5/2` evaluates to `2` in many languages, which will ruin the sort order!
- Confusing this with the 0/1 Knapsack problem. 0/1 Knapsack CANNOT be solved optimally using a Greedy approach and requires Dynamic Programming.
</Warning>
