# Theory & Concepts
The **Jump Game** is a classic problem pattern that elegantly demonstrates how a greedy approach can outperform dynamic programming. You are given an array of non-negative integers where each element represents your maximum jump length at that position. You start at the first index, and the goal is to determine if you can reach the last index.

### The Greedy Strategy
While a DP solution would recursively check all possible jump combinations, a Greedy solution tracks only the **maximum reachable index**.
1. Initialize a variable `maxReach = 0`.
2. Iterate through the array. For each index `i`:
   - If `i > maxReach`, it means you cannot even reach the current index, so you definitely cannot reach the end. Return `false`.
   - Otherwise, update `maxReach = max(maxReach, i + nums[i])`.
   - If `maxReach` becomes greater than or equal to the last index, return `true`.

This is a beautiful example of the Greedy Choice Property: your only concern at each step is expanding your boundary of reachability as far right as possible.

# Code Implementation
<CodeBlock
  cpp="#include <vector>
#include <algorithm>
using namespace std;

class Solution {
public:
    bool canJump(vector<int>& nums) {
        int maxReach = 0;
        int n = nums.size();
        
        for (int i = 0; i < n; i++) {
            // If the current index is beyond our maximum reach, we're stuck
            if (i > maxReach) {
                return false;
            }
            // Update the maximum reach we can achieve from this index or prior
            maxReach = max(maxReach, i + nums[i]);
            
            // Early exit if we can already reach the end
            if (maxReach >= n - 1) {
                return true;
            }
        }
        return true;
    }
};"

# Common Pitfalls
<Warning>
- Misunderstanding the array values. `nums[i]` is the *maximum* jump length, not the *exact* jump length. You can jump any distance from `1` to `nums[i]`.
- Overcomplicating the solution with DFS/BFS or Dynamic Programming, leading to O(N^2) time complexity or O(N) space complexity.
</Warning>
