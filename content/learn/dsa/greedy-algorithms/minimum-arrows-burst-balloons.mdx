# Theory & Concepts
The **Minimum Number of Arrows to Burst Balloons** problem is a classic interval overlapping problem. You are given a 2D array representing balloons plotted on a wall, where each balloon occupies a horizontal interval `[Xstart, Xend]`. An arrow shot at coordinate `X` bursts all balloons where `Xstart <= X <= Xend`. You need to find the minimum arrows required to burst all balloons.

This is fundamentally identical to the **Activity Selection** or **Non-Overlapping Intervals** problem.

### The Greedy Strategy
To minimize the number of arrows, you want each arrow to burst as many overlapping balloons as possible. The optimal place to shoot an arrow is at the very end of a balloon's interval, because that maximizes the chance of hitting other balloons that start later.

1. **Sort the balloons** by their ending coordinates (`Xend`) in ascending order.
2. Initialize the number of arrows to `1`, and set the `currentArrowPos` to the end coordinate of the first balloon.
3. Iterate through the sorted balloons:
   - If the next balloon's start coordinate is greater than `currentArrowPos`, it means this balloon cannot be burst by the current arrow.
   - You must shoot a new arrow! Increment the arrow count and update `currentArrowPos` to the end coordinate of this new balloon.

# Common Pitfalls
<Warning>
- **Integer Overflow in Sorting:** In Java and C++, using `a[1] - b[1]` in the comparator will cause integer overflow if the coordinates are large negative and positive integers (e.g., `-2147483648` and `2147483647`). Always use `Integer.compare(a[1], b[1])` or `<`.
- Sorting by start coordinate instead of end coordinate. While solvable by sorting by start time, the logic becomes significantly more convoluted as you must maintain a running minimum of end times.
</Warning>
