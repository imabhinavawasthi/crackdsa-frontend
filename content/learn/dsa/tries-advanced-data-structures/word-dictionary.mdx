# Theory & Concepts
The **Word Dictionary** is an extension of the classic Trie data structure, typically designed to handle search operations with wildcard matchings (like the `.` character matching any single lowercase letter). 

### Core Intuition
While a standard hash set gives `O(1)` lookups for exact words, it completely fails when you need wildcard matching. If you have "bad", "dad", and "mad" in a set, searching for ".ad" requires checking every word. 

By utilizing a **Trie (Prefix Tree)**, we group words by their common prefixes. When a wildcard `.` is encountered, we simply use DFS (Depth-First Search) to recursively branch out and search *every possible child node* from our current position. If any of those branches return a successful match, our search succeeds.

# Common Pitfalls
<Warning>
- Implementing wildcard search using string slicing (`word.substring()`) inside recursion, which severely degrades performance via memory allocation overhead. Always use an integer index.
- Not returning `false` after the wildcard loop completes without any matches.
</Warning>
