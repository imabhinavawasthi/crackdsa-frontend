# Theory & Concepts
Here we fully implement a **Fenwick Tree (Binary Indexed Tree)** for a dynamic array.

### Core Intuition
The Fenwick tree array `BIT` holds partial sums.
If we want to update the original array at `index = 3`, we add the delta to `BIT[3]`. Then we add the LSB to `3` to get the next node responsible for this range: `3 + (3 & -3) = 3 + 1 = 4`. So we update `BIT[4]`. Then `4 + (4 & -4) = 4 + 4 = 8`. So we update `BIT[8]`. This cascades up to `N` in O(log N) steps.

If we want the sum of elements up to index 7:
`BIT[7]` stores the sum of length 1 (just index 7). Next node is `7 - (7 & -7) = 6`.
`BIT[6]` stores the sum of length 2 (indices 5,6). Next node is `6 - (6 & -6) = 4`.
`BIT[4]` stores the sum of length 4 (indices 1,2,3,4). Next node is 0 (stop).
Summing these gives the exact prefix sum of 1 through 7!

    def __init__(self, nums: list[int]):
        self.n = len(nums)
        self.bit = [0] * (self.n + 1)

    def _lsb(self, x: int) -> int:
        return x & (-x)

        index += 1 # 1-based indexing
        while index <= self.n:
            self.bit[index] += delta
            index += self._lsb(index)

# Common Pitfalls
<Warning>
- Mixing up 0-indexed problem statements with the strictly 1-indexed BIT array. Always do `index++` immediately in your helper functions.
- Forgetting to maintain a copy of the original array. When updating, you need to add the `delta (new_val - old_val)`, which requires knowing what `old_val` was!
</Warning>
