# Theory & Concepts
Now we construct a fully functional **Segment Tree** to support dynamic point updates and range sum queries.

### Core Intuition
We represent the tree using a flat array of size `4 * N`.
1. **Build (`O(N)`)**: Use divide-and-conquer. Recursively split the array `[L, R]` into two halves until `L == R`. Set the leaf node to the array value, then backtrack, setting parent nodes to the sum of their children.
2. **Update (`O(log N)`)**: To update index `idx`, traverse down to the leaf representing `idx`. Change it, and then update all parent nodes along the path back up.
3. **Query (`O(log N)`)**: If the current node's range is completely inside the query range, return the node's value immediately. If it's completely outside, return 0. If it partially overlaps, recursively split and query both children.

# Common Pitfalls
<Warning>
- Off-by-one errors in splitting intervals. Always use `mid` and `mid + 1` for the two child boundaries.
- Forgetting to recalculate the parent node value (`tree[node] = tree[left] + tree[right]`) after updating a leaf!
</Warning>
