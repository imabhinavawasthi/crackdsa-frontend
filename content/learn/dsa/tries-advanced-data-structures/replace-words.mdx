# Theory & Concepts
**Replace Words** introduces a practical application of a Trie in NLP (Natural Language Processing) and text processing. The goal is to replace words in a sentence with their shortest matching "root" dictionary word.

### Core Intuition
Imagine a dictionary: `["cat", "bat", "rat"]` and a sentence: `"the cattle was rattled by the battery"`. We want to replace "cattle" with "cat", "rattled" with "rat", and "battery" with "bat".

Using a brute-force `startsWith()` comparison against every word in the dictionary would be slow, taking O(M * N * L) where M is the number of words in the sentence and N is the dictionary size.

Instead, we put all dictionary roots into a **Trie**. Then, for each word in the sentence, we simply walk down the Trie character by character. 
- The *very first* time we hit a node where `isEndOfWord == true`, we have found the **shortest** prefix. We immediately stop and replace the word.
- If we hit a null pointer before finding a word, the prefix doesn't exist, and we keep the original word.

    private TrieNode root;

    private void insert(String word) {
        TrieNode curr = root;
        for (char ch : word.toCharArray()) {
            int idx = ch - 'a';
            if (curr.children[idx] == null) {
                curr.children[idx] = new TrieNode();
            }
            curr = curr.children[idx];
        }
        curr.isEndOfWord = true;
    }

    private String findShortestPrefix(String word) {
        TrieNode curr = root;
        StringBuilder prefix = new StringBuilder();
        
        for (char ch : word.toCharArray()) {
            int idx = ch - 'a';
            if (curr.children[idx] == null) break;
            
            prefix.append(ch);
            curr = curr.children[idx];
            if (curr.isEndOfWord) return prefix.toString();
        }
        return word;
    }

        root = new TrieNode();
        for (String word : dictionary) {
            insert(word);
        }

        StringBuilder result = new StringBuilder();
        String[] words = sentence.split(\" \");
        
        for (int i = 0; i < words.length; i++) {
            if (i > 0) result.append(\" \");
            result.append(findShortestPrefix(words[i]));
        }
        
        return result.toString();
    }

# Common Pitfalls
<Warning>
- Splitting strings inefficiently. String split functions allocate extra memory. If memory is tight, iterate character by character.
- Finding the *longest* root instead of the *shortest*. Make sure your loop returns immediately when `isEndOfWord` is true.
</Warning>
