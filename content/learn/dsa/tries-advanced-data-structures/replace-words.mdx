# Theory & Concepts
Welcome to the lesson on **Replace Words (Prefix matching)**. This topic is a cornerstone of the Tries & Advanced Data Structures module. When HashMaps and binary searches aren't enough to handle complex prefix matching or dynamic range updates, we turn to specialized trees.

### Core Intuition
- **Tries (Prefix Trees):** A tree where each node represents a single character. Words are formed by traversing down the branches. This makes searching for a string of length `L` take exactly O(L) time, regardless of how many millions of words are stored!
- **Segment/Fenwick Trees:** Trees built over an array to allow both point/range *updates* and range *queries* in O(log N) time simultaneously.

# Common Pitfalls
<Warning>
- **Memory Leaks:** Tries consume a massive amount of memory because every node often allocates an array of 26 pointers. Be careful about space constraints.
- **Forgetting End of Word Flag:** It is critical to mark `isEndOfWord = true` at the last node of an insertion. Otherwise, a search might falsely report a prefix as a complete word!
</Warning>
