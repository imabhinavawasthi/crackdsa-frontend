# Theory & Concepts
Welcome to the lesson on **Heap Sort**. Heap Sort is a comparison-based sorting algorithm that marries the excellent $O(N \log N)$ worst-case time guarantee of Merge Sort with the strictly $O(1)$ space requirement of Selection Sort. 

### Core Intuition
Heap Sort is heavily reliant on the **Binary Heap** data structure, which can be elegantly represented using a flat array. In a 0-indexed array, the left child of node `i` is at `2*i + 1` and the right child is at `2*i + 2`.

The sorting process works in two distinct phases:
1. **Build a Max-Heap:** First, we transform the unsorted array into a valid Max-Heap. In a Max-Heap, every parent node is greater than or equal to its children. This guarantees that the absolute largest element in the entire array is at the root (index `0`).
2. **Extract and Shrink:** We swap the root element (the maximum) with the very last element in the array. We then reduce the conceptual "size" of the heap by 1, leaving the max element safely stored at the end. Finally, we call `heapify` on the new root to restore the Max-Heap property. We repeat this until the heap is empty, resulting in a sorted array.

private:
    void heapify(vector<int>& arr, int n, int i) {
        int largest = i; // Initialize largest as root
        int left = 2 * i + 1; // left child index
        int right = 2 * i + 2; // right child index

        // If left child is larger than root
        if (left < n && arr[left] > arr[largest])
            largest = left;

        // If right child is larger than largest so far
        if (right < n && arr[right] > arr[largest])
            largest = right;

        // If largest is not root
        if (largest != i) {
            swap(arr[i], arr[largest]);
            // Recursively heapify the affected sub-tree
            heapify(arr, n, largest);
        }
    }

public:
    void heapSort(vector<int>& arr) {
        int n = arr.size();

        // Step 1: Build max heap
        // Start from the last non-leaf node and heapify down
        for (int i = n / 2 - 1; i >= 0; i--) {
            heapify(arr, n, i);
        }

        // Step 2: Extract elements from heap one by one
        for (int i = n - 1; i > 0; i--) {
            // Move current root to end
            swap(arr[0], arr[i]);
            // call max heapify on the reduced heap
            heapify(arr, i, 0);
        }
    }
};"

            arr[largest] = swap;

            heapify(arr, n, i);

        // Extract elements
        for (int i = n - 1; i > 0; i--) {

            arr[0] = arr[i];
            arr[i] = temp;

        }
    }

# Common Pitfalls
<Warning>
- **Using a Min-Heap for Ascending Sort:** A common mistake is thinking you need a Min-Heap to sort in ascending order. You actually need a **Max-Heap**, because you move the extracted max elements to the *back* of the array.
- **Off-by-One Errors:** Miscalculating the last non-leaf node index `(n/2 - 1)` or misidentifying left/right children `(2*i + 1, 2*i + 2)`.
- **Assuming Stability:** Heap Sort is NOT stable. The process of heavily swapping nodes across the tree structure inherently scrambles the relative order of equal elements.
</Warning>
