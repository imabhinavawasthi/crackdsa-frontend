# Theory & Concepts
Welcome to the lesson on **Bubble Sort**. Often the very first algorithmic concept taught in computer science, Bubble Sort provides an excellent, intuitive introduction to sorting algorithms. 

### Core Intuition
The algorithm repeatedly steps through the list, compares adjacent elements, and swaps them if they are in the wrong order. The pass through the list is repeated until the list is sorted. 

It gets its name because smaller elements "bubble" to the top of the list (or larger elements sink to the bottom) much like bubbles rising to the surface of a glass of soda. Every time we complete a full pass, we can guarantee that the largest unsorted element has been placed in its final, correct position at the end of the array.

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    void bubbleSort(vector<int>& arr) {
        int n = arr.size();
        bool swapped;
        for (int i = 0; i < n - 1; i++) {
            swapped = false;
            // The last i elements are already in place
            for (int j = 0; j < n - i - 1; j++) {
                if (arr[j] > arr[j + 1]) {
                    swap(arr[j], arr[j + 1]);
                    swapped = true;
                }
            }
            // If no two elements were swapped by inner loop, then break
            if (!swapped) break;
        }
    }
};"

        int n = arr.length;
        boolean swapped;
        for (int i = 0; i < n - 1; i++) {
            swapped = false;

                if (arr[j] > arr[j + 1]) {
                    // Swap arr[j] and arr[j+1]
                    int temp = arr[j];

                    arr[j + 1] = temp;

# Common Pitfalls
<Warning>
- **Forgetting the Optimization:** Implementing the unoptimized version of Bubble Sort that always takes O(N^2) time even on sorted arrays. Always include the early-exit `swapped` flag.
- **Redundant Comparisons:** Failing to decrease the inner loop bound (`n - i - 1`). The largest `i` elements are already sorted at the end, so comparing them again is a waste of time.
- **Using it in Production:** Bubble Sort is notoriously inefficient for large datasets. It is almost exclusively an educational tool rather than a practical solution.
</Warning>
