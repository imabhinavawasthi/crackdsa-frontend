# Theory & Concepts
Welcome to the lesson on **Cycle Sort (1 to N Patterns)**. This topic is a cornerstone of the Sorting & Custom Comparators module. While standard library sorting functions exist, understanding how these algorithms work under the hood is critical for recognizing when an interview problem is actually a masked sorting algorithm.

### Core Intuition
The primary goal of sorting is to order elements either ascending or descending. Depending on the algorithm, this is achieved by swapping adjacent elements, repeatedly selecting the minimum, or dividing the array recursively.

# Common Pitfalls
<Warning>
- **Stability Issues:** Using an unstable sort (like Quick Sort) when the relative order of equal elements must be preserved. (Use Merge Sort or Insertion Sort instead).
- **Stack Overflow:** Deep recursion in Merge Sort or Quick Sort on massive arrays can cause Call Stack limits to trigger.
</Warning>
