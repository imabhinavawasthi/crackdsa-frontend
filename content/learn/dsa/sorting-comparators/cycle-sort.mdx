# Theory & Concepts
Welcome to the lesson on **Cycle Sort**, specifically tailored for the **$1$ to $N$ Pattern**. While general Cycle Sort is academically known for minimizing memory writes, in the context of coding interviews, it almost exclusively refers to a brilliant trick used when elements belong to a strict, continuous sequence (like $1, 2, 3 \dots N$).

### Core Intuition
If you have an array of size $N$, and the numbers inside it are exactly in the range $1$ to $N$, then ideally, **number $1$ should be at index $0$, number $2$ should be at index $1$, and number $x$ should be at index $x - 1$.**

The algorithm iterates through the array. If the current number is not at its correct index, we **swap it** with the number that is currently residing at its correct index. We keep swapping the element at our current index until the correct number finally lands there, or we encounter a duplicate. Then we move to the next index.

Because every number is placed in its correct position in at most one swap, the algorithm runs in strictly linear $O(N)$ time.

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    void cycleSort(vector<int>& arr) {
        int i = 0;
        int n = arr.size();
        
        while (i < n) {
            // The correct index for the value arr[i] should be arr[i] - 1
            int correctIdx = arr[i] - 1;
            
            // Check if it's within bounds AND not already at the correct index
            if (arr[i] > 0 && arr[i] <= n && arr[i] != arr[correctIdx]) {
                // Swap the elements to send arr[i] to its correct position
                swap(arr[i], arr[correctIdx]);
            } else {
                // Move to the next index only when the current element is correct 
                // or cannot be placed (like out of bounds or duplicate)
                i++;
            }
        }
    }
};"
  java="class Solution {
    public void cycleSort(int[] arr) {
        int i = 0;
        int n = arr.length;
        
        while (i < n) {
            int correctIdx = arr[i] - 1;
            
            if (arr[i] > 0 && arr[i] <= n && arr[i] != arr[correctIdx]) {
                // Swap arr[i] and arr[correctIdx]
                int temp = arr[i];
                arr[i] = arr[correctIdx];
                arr[correctIdx] = temp;
            } else {
                i++;
            }
        }
    }
}"

        n = len(arr)

            if 0 < arr[i] <= n and arr[i] != arr[correct_idx]:
                arr[i], arr[correct_idx] = arr[correct_idx], arr[i]

# Common Pitfalls
<Warning>
- **Infinite Loops:** If you don't check `arr[i] != arr[correctIdx]`, an array with duplicate numbers will get stuck in an infinite swap cycle.
- **Out of Bounds Errors:** Interview problems (like 'First Missing Positive') often mix negative numbers or numbers $> N$ into the array. You must verify `arr[i] > 0 && arr[i] <= n` before calculating and accessing `correctIdx`.
- **Assuming $0$ to $N$ vs $1$ to $N$:** Read the prompt carefully! If the range is $0$ to $N$, the correct index is just `arr[i]`, not `arr[i] - 1`.
</Warning>
