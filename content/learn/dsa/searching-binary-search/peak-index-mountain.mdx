# Theory & Concepts
A mountain array is an array that strictly increases to a maximum value (the peak) and then strictly decreases. For example: `[0, 2, 4, 10, 5, 2]`. The peak here is `10` at index `3`.
We need to find the index of this peak element in `O(log N)` time.

### Core Intuition
Even though the array isn't uniformly sorted, it is comprised of two monotonic sequences: an ascending part and a descending part. This guarantees we can use binary search.

To decide whether to go left or right, we just look at the slope at the middle element.
We compare `arr[mid]` with its right neighbor `arr[mid + 1]`:
1. **If `arr[mid] < arr[mid + 1]`**: The slope is upwards. We are currently on the ascending side of the mountain. The peak must be to the right. We discard the left part by setting `left = mid + 1`.
2. **If `arr[mid] > arr[mid + 1]`**: The slope is downwards. We are on the descending side (or exactly at the peak). The peak must be to the left, or it might be `mid` itself. We discard the right part by setting `right = mid`.

By repeating this, `left` and `right` will eventually converge exactly on the peak.

    int peakIndexInMountainArray(vector<int>& arr) {
        int left = 0, right = arr.size() - 1;
        
        while (left < right) {

            // Check the slope
            if (arr[mid] < arr[mid + 1]) {

            } else {
                // Descending slope, peak is mid or to the left
                right = mid; 
            }
        }

        return left;

# Common Pitfalls
<Warning>
- Using `while(left <= right)` and returning `mid` when found. In a mountain array, we don't know we are at the peak until `left` converges with `right`. Using `<=` with `right = mid` will cause an infinite loop. Always use `while(left < right)`.
- Index Out of Bounds: Checking `arr[mid] < arr[mid - 1]` can cause an out-of-bounds error if `mid` is 0. Comparing with `mid + 1` is safer because integer division `(left + right) / 2` biases towards the left, meaning `mid` will never be the last index while `left < right`.
</Warning>
