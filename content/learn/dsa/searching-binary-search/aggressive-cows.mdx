# Theory & Concepts
"Aggressive Cows" is one of the most famous problems illustrating the "Maximize the Minimum" pattern using Binary Search. 
You are given an array of stall coordinates and `C` aggressive cows. You need to place all `C` cows in the stalls such that the **minimum distance between any two of them is as large as possible**.

### The Monotonic Property
If we can place all cows with a minimum distance of `d`, we can certainly place them with any minimum distance `< d`. 
If we cannot place them with a minimum distance of `d`, we definitely cannot place them with any distance `> d`.
This monotonic behavior allows us to binary search for the optimal distance `d`.

### Search Space
First, we **must sort the stalls** to simulate placing cows sequentially from left to right.
- **Minimum possible distance (`low`)**: `1`. The closest two cows can be placed is in adjacent stalls separated by a distance of 1.
- **Maximum possible distance (`high`)**: `stalls[n-1] - stalls[0]`. This happens when there are exactly 2 cows, and we place them at the two extreme ends.

### The Validation Function
For a guessed distance `mid`, we try to place the cows greedily.
We place the first cow in the first stall. Then, we iterate through the stalls. If we find a stall that is at least `mid` distance away from the last placed cow, we place the next cow there. If we successfully place all `C` cows, `mid` is a valid answer!

public:
    int aggressiveCows(vector<int>& stalls, int k) {
        // Step 1: Sort the stalls
        sort(stalls.begin(), stalls.end());
        
        int n = stalls.size();
        int left = 1; // Minimum possible distance
        int right = stalls[n - 1] - stalls[0]; // Maximum possible distance
        int ans = -1;
        
        // Step 2: Binary Search on Answer
        while (left <= right) {
            int mid = left + (right - left) / 2;
            
            if (canPlaceCows(stalls, k, mid)) {
                ans = mid;       // Valid distance, let's try for a LARGER one
                left = mid + 1;  
            } else {
                right = mid - 1; // Not valid, we must decrease the distance
            }
        }
        
        return ans;
    }
    
private:

                lastPlacedPosition = stalls[i];

                if (cowsPlaced >= cowsRequired) return true;

# Common Pitfalls
<Warning>
- **Forgetting to sort the array:** The greedy placement logic strictly relies on the array being sorted so that we always jump to the absolute next valid stall.
- **Incorrectly updating `ans`:** Remember, this is a "Maximize" problem. When `isValid` is true, we want to try pushing the limit higher, so we do `left = mid + 1`. Many students mistakenly do `right = mid - 1` out of habit.
</Warning>
