# Theory & Concepts
Linear Search is the most fundamental search algorithm. It sequentially checks each element of the list until a match is found or the whole list has been searched. While not the most efficient algorithm for large datasets, its simplicity makes it a crucial building block, and it's the only option when searching through unordered data.

The algorithm works by iterating through an array from the first index to the last. At each step, it compares the current element with the target value. If they match, it returns the current index. If the loop completes without finding a match, it indicates that the target is not in the array (usually by returning `-1`).

### When to use Linear Search
- The dataset is small.
- The dataset is unsorted or unordered.
- You need to find all occurrences of an element, not just the first one.
- You are searching through a linked list where random access is not possible.

# Common Pitfalls
<Warning>
- Confusing the element's value with its index when returning the result.
- Causing an `IndexOutOfBounds` exception by using `<= length` instead of `< length` in the loop condition.
- Prematurely returning `-1` inside the loop instead of outside after the loop finishes.
</Warning>
