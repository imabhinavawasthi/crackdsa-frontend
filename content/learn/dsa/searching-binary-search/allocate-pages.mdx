# Theory & Concepts
The "Allocate Minimum Number of Pages" problem is one of the most famous algorithmic challenges. You are given an array of books where `arr[i]` represents the number of pages in the `i-th` book. You need to allocate these books to `M` students such that:
1. Every student gets at least one book.
2. The allocation is contiguous (a student gets a continuous sub-segment of the array).
3. The **maximum number of pages assigned to a student is minimized**.

This is identical in logic to the "Split Array Largest Sum" problem. It's a "Minimize the Maximum" optimization, heavily pointing toward Binary Search on the Answer.

### Search Space
- **Minimum possible pages (`low`)**: The largest single book in the array. If `M == N` (students equals books), every student gets exactly one book, and the maximum pages a student reads will be the largest book.
- **Maximum possible pages (`high`)**: The sum of all pages in the array. If `M == 1` (only 1 student), that poor student reads all the books.

### The Validation Function
For a guessed maximum page limit `mid`, we simulate the allocation. We hand books to a student one by one until the sum exceeds `mid`. When it does, we move to the next student.
- If we require more than `M` students to distribute the books, our `mid` was too strict (too small).
- If we require `<= M` students, our `mid` is valid, but we try to find a smaller valid `mid`.

        // Base case: If students are more than books, allocation is impossible

        long long totalPages = 0;

            maxBook = max(maxBook, pages);

        long long right = totalPages;
        long long ans = -1;

                ans = mid;       // Valid allocation, try to minimize the max pages
                right = mid - 1; 
            } else {
                left = mid + 1;  // Not possible, we need to allow more pages
            }
        }

                currentPages = pages;

# Common Pitfalls
<Warning>
- **Missing the `M > N` edge case:** If there are more students than books, it's impossible to assign at least one book to every student. Returning an empty or default response here without checking leads to WA.
- **Incorrect search bounds:** Setting `low = 0` or `low = min(arr)` is a fatal error. The max pages a student reads can never be less than the single largest book in the array.
</Warning>
