# Theory & Concepts
Binary Search is a highly efficient search algorithm that finds the position of a target value within a sorted array. It's one of the most frequently asked concepts in technical interviews and forms the foundation for many complex algorithms.

### Core Intuition
The core idea is "Divide and Conquer." Instead of checking each element one by one, Binary Search compares the target value to the middle element of the array.
- If they are equal, the search is successful.
- If the target is less than the middle element, the target must lie in the lower half. The upper half is entirely discarded.
- If the target is greater, it must lie in the upper half. The lower half is discarded.

By eliminating half of the remaining search space at every step, the algorithm rapidly converges on the target, resulting in logarithmic time complexity.

### The Monotonic Property
A crucial requirement for Binary Search is that the search space must be monotonic (strictly non-decreasing or non-increasing). While typically applied to sorted arrays, this concept extends to mathematical functions or any sequence where a definite "go left" or "go right" decision can be made.

# Common Pitfalls
<Warning>
- Forgetting to handle the base case: `left <= right`. Using `<` instead of `<=` can fail when the array size is 1 or when the target is at the final calculated `mid`.
- Integer Overflow: `mid = (left + right) / 2` can overflow in C++ and Java if `left + right` exceeds the maximum integer limit. Always use `mid = left + (right - left) / 2`.
- Infinite Loops: Failing to strictly increase `left` (`left = mid + 1`) or decrease `right` (`right = mid - 1`) will cause infinite loops.
</Warning>
