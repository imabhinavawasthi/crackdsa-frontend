# Theory & Concepts

By default, a computer program executes sequentially, line by line. However, algorithms require logic to make decisions and repeat tasks. This is where **Control Flow** comes into play. Control flow dictates the order in which statements are executed.

### 1. Conditional Statements (If / Else)

Conditional statements evaluate a boolean expression and execute a block of code only if the expression evaluates to `true`.
- `if`: The primary conditional block.
- `else if` (or `elif` in Python): Checked sequentially if the preceding conditions were `false`.
- `else`: The fallback block executed if all conditions fail.

### 2. Loops (Iteration)

Loops allow you to execute a block of code multiple times. In DSA, loops are used to traverse arrays, strings, trees, and graphs.

1. **`for` loop**: Used when the number of iterations is known in advance (e.g., iterating over an array of size $N$).
2. **`while` loop**: Used when the number of iterations is unknown and depends on a dynamic condition (e.g., repeatedly dividing a number by 2 until it reaches 1).
3. **`do-while` loop**: Similar to the `while` loop, but guarantees the code block will execute *at least once* before checking the condition.

### 3. Loop Control Statements

- **`break`**: Immediately exits the loop, bypassing any remaining iterations.
- **`continue`**: Skips the rest of the current iteration and jumps to the next iteration of the loop.

# Code Implementation

Let's look at how to implement basic control flow constructs across different languages. We will implement a function that loops from 1 to $N$, skipping even numbers, and stopping early if it reaches 7.

        } else {

        }
    }

    int count = 3;

    }

# Common Pitfalls

<Warning>
- **Infinite Loops**: Always ensure that the condition of your `while` loop will eventually become `false`. Forgetting to increment or decrement the loop variable is the #1 cause of infinite loops.
- **Off-by-One Errors**: Be careful with boundary conditions (`i < N` vs `i <= N`). In 0-indexed arrays, you usually want `i < N`.
- **Misplaced `break` / `continue`**: A `break` statement only breaks out of the *innermost* loop. If you have nested loops and want to break out of all of them, you may need a flag variable or a labeled break (in Java).
</Warning>
