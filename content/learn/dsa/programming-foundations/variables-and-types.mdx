# Theory & Concepts

Before you can build complex algorithms and scale systems, you must understand the most fundamental building block of programming: **Variables and Data Types**. 

In the context of Data Structures and Algorithms (DSA), a variable is simply a named storage location in your computer's RAM. However, not all data takes up the same amount of space. A data type tells the compiler or interpreter exactly *how much* memory to allocate for a variable and *how to interpret* the binary sequence stored in that memory.

### Primitive Data Types

Primitive data types are the most basic data types built directly into the language. While languages differ slightly, almost all share these core primitives:

1. **Integer (`int`)**: Stores whole numbers (e.g., `5`, `-42`).
2. **Floating-Point (`float` / `double`)**: Stores fractional or decimal numbers (e.g., `3.14`, `-0.001`).
3. **Character (`char`)**: Stores a single alphanumeric character (e.g., `'a'`, `'Z'`).
4. **Boolean (`bool`)**: Stores a truth value (`true` or `false`, `1` or `0`).

### Memory Allocation & Size Limitations

In statically typed languages like C++ and Java, the amount of memory allocated for an integer is fixed. This is crucial for DSA because if you try to store a number larger than what the memory can hold, it will "overflow".

| Data Type | Memory Size | Range (Approximate) |
| :--- | :--- | :--- |
| `int` | 4 bytes (32 bits) | -2×10⁹ to +2×10⁹ |
| `long` / `long long` | 8 bytes (64 bits) | -9×10¹⁸ to +9×10¹⁸ |
| `char` | 1 byte (8 bits) | -128 to 127 (or 0 to 255) |
| `bool` | 1 byte (8 bits) | `true` (1) or `false` (0) |

*(Note: Python dynamically handles large integers, so you generally do not need to worry about integer overflow in Python.)*

# Code Implementation

Let's look at how variables are declared across different languages. Notice the difference between **Statically Typed** languages (C++, Java) where you must declare the type, and **Dynamically Typed** languages (Python) where the runtime determines it.

# Common Pitfalls

<Warning>
- **Integer Overflow**: In C++ and Java, multiplying two large `int` values (e.g., $10^5 \times 10^5 = 10^{10}$) will exceed the 32-bit integer limit ($2 \times 10^9$) and result in negative garbage values. Always use `long long` (C++) or `long` (Java) when dealing with large products.
- **Floating Point Precision**: Floats and doubles cannot represent all decimal fractions exactly. Never use `==` to compare two floating-point numbers. Instead, check if their difference is less than a tiny threshold (e.g., `abs(a - b) < 1e-9`).
- **Python's Immutability**: In Python, primitive types like integers and strings are immutable. Reassigning a variable actually creates a new object in memory rather than altering the existing one.
</Warning>
