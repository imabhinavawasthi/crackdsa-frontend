# Theory & Concepts

The **Lowest Common Ancestor (LCA)** of two nodes `p` and `q` in a tree is the lowest (i.e., deepest) node that has both `p` and `q` as descendants. A node is allowed to be a descendant of itself!

### Binary Search Tree (BST) LCA
If the tree is a Binary Search Tree, finding the LCA is trivial and can be done in **O(H)** time without traversing the whole tree. We use the BST property:
- If both `p` and `q` are smaller than the root, the LCA must be in the left subtree.
- If both `p` and `q` are larger than the root, the LCA must be in the right subtree.
- If they split (one is smaller, one is larger) or if one of them *is* the root, the current root *is* the LCA!

### Standard Binary Tree LCA
If the tree is just a normal binary tree, we cannot rely on values. We must use a **Postorder Traversal**:
- Search the left and right subtrees for `p` or `q`.
- If a node is `p` or `q`, return it.
- If the left subtree returns a non-null node, and the right subtree returns a non-null node, the current node is the LCA!
- If only one subtree returns a non-null node, we pass that node up.

# Code Implementation

<CodeBlock
  cpp="class Solution {
public:
    // Standard Binary Tree LCA
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (!root || root == p || root == q) return root;
        
        TreeNode* left = lowestCommonAncestor(root->left, p, q);
        TreeNode* right = lowestCommonAncestor(root->right, p, q);
        
        if (left && right) return root; // p and q are in different subtrees
        
        return left ? left : right; // pass up the non-null result
    }
};"
  java="class Solution {
    // Binary Search Tree LCA (Optimized)
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null) return null;
        
        if (p.val < root.val && q.val < root.val) {
            return lowestCommonAncestor(root.left, p, q);
        } else if (p.val > root.val && q.val > root.val) {
            return lowestCommonAncestor(root.right, p, q);
        } else {
            return root; // Split occurs here
        }
    }
}"

# Common Pitfalls

<Warning>
- **Confusing BST vs Binary Tree:** The most common mistake is applying the O(N) general binary tree solution to a BST. You will pass the test cases, but the interviewer will fail you for not utilizing the BST property!
- **Not Handling 'Node as Descendant':** The problem states a node can be an ancestor of itself. The base case `if (root == p || root == q) return root` handles this perfectly without further traversal.
</Warning>
