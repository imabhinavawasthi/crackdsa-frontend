# Theory & Concepts

**Zigzag Level Order Traversal** is a variation of standard Breadth-First Search (BFS). Instead of traversing every level from left to right, we alternate the direction at each level:
- Level 0: Left to Right
- Level 1: Right to Left
- Level 2: Left to Right
- ...and so on.

### The Flag Approach
The most intuitive way to solve this is to perform a standard Level Order Traversal, but introduce a boolean flag (e.g., `leftToRight`). 
- When the flag is true, append nodes normally.
- When the flag is false, insert nodes at the beginning of your level array or reverse the array before adding it to the final result.
- Flip the flag at the end of each level.

        boolean leftToRight = true;

            int size = queue.size();
            List<Integer> currentLevel = new LinkedList<>(); // Use LinkedList for fast insertions

                } else {
                    currentLevel.add(0, node.val); // Insert at beginning

                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            
            result.add(currentLevel);
            leftToRight = !leftToRight;
        }
        
        return result;
    }

# Common Pitfalls

<Warning>
- **Reversing the Queue Addition:** A common trap is trying to modify the order in which children are pushed into the queue (right then left). This completely scrambles the tree for subsequent levels. Always push children Left then Right, and only manipulate the *output* array!
- **Using Slow Insertions:** In languages like Python or Java, inserting at the 0th index of an array/ArrayList is O(K). Use a Deque or LinkedList for the `currentLevel` to ensure O(1) insertions.
</Warning>
