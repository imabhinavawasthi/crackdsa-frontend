# Theory & Concepts

**Same Tree** and **Symmetric Tree** are foundational problems that teach you how to traverse and compare multiple pointers simultaneously. 

### Same Tree
Two binary trees are considered the same if they are structurally identical, and the nodes have the same value.
- Traverse both trees at the exact same time (`p` and `q`).
- If `p.val != q.val`, return false.
- Recursively compare `p.left` with `q.left`, and `p.right` with `q.right`.

### Symmetric Tree
A tree is symmetric if it is a mirror of itself across its center.
- This is just "Same Tree" applied to the left and right subtrees of a single root, but with a twist!
- We compare the `left` child of tree 1 with the `right` child of tree 2.
- We compare the `right` child of tree 1 with the `left` child of tree 2.

            && isMirror(t1->left, t2->right)
            && isMirror(t1->right, t2->left);

  java="class Solution {
    // Same Tree implementation
    public boolean isSameTree(TreeNode p, TreeNode q) {
        // Both are null
        if (p == null && q == null) return true;
        
        // One is null, the other is not
        if (p == null || q == null) return false;
        
        // Values don't match
        if (p.val != q.val) return false;
        
        // Recursively check children
        return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);
    }
}"

# Common Pitfalls

<Warning>
- **Incomplete Null Checks:** Failing to check if only *one* of the nodes is null. If `t1` is null but `t2` is not, you will get a Null Reference Exception when checking `t1.val == t2.val`.
- **Symmetric Traversal Error:** Forgetting that symmetry means `t1.left` matches `t2.right`. It is very easy to accidentally write `t1.left` matching `t2.left` out of muscle memory from Same Tree.
</Warning>
