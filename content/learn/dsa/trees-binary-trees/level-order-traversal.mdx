# Theory & Concepts

**Level Order Traversal** is the tree equivalent of **Breadth-First Search (BFS)**. Instead of diving deep into the tree, Level Order Traversal explores the tree level by level, from top to bottom, and left to right within each level.

### The BFS Mechanism
To implement BFS iteratively, we use a **Queue** (First-In, First-Out) data structure.
1. Push the root node into the queue.
2. While the queue is not empty, pop the front node, process it, and push its children (left, then right) into the queue.
3. To process nodes level by level (often required in array-of-array outputs), capture the `size` of the queue at the start of the loop and iterate exactly `size` times.

# Common Pitfalls

<Warning>
- **Forgetting the Level Size:** If you need to group nodes by level, you must store `queue.size()` in a variable before entering the inner loop. Evaluating `queue.size()` directly in the loop condition will fail because the size changes dynamically as you push children!
- **Using arrays instead of deques in Python:** `list.pop(0)` is an O(N) operation. Always use `collections.deque` for O(1) pops from the front.
</Warning>
