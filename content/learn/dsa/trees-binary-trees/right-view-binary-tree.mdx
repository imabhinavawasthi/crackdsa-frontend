# Theory & Concepts

The **Right View of a Binary Tree** asks you to imagine looking at the tree from the right side and returning the values of the nodes you can see, ordered from top to bottom.

This essentially means we want the **last node at every depth level**.

There are two excellent ways to solve this:
### 1. BFS (Level Order Traversal)
Perform a standard Level Order Traversal using a Queue. At each level, capture the very last node processed in the loop and add it to the result array. This is the most intuitive approach.

### 2. DFS (Modified Preorder)
Perform a recursive DFS, but prioritize going **Right before Left** (Root -> Right -> Left). We keep track of the current depth. If the current depth is equal to the size of our result array, it means this is the first time we are visiting this depth, so we add the node's value. Because we go right first, this guarantees we capture the rightmost node at every level.

# Code Implementation

<CodeBlock
  cpp="class Solution {
public:
    // DFS Approach (Root -> Right -> Left)
    vector<int> rightSideView(TreeNode* root) {
        vector<int> result;
        dfs(root, 0, result);
        return result;
    }
    
private:
    void dfs(TreeNode* node, int depth, vector<int>& res) {
        if (!node) return;
        
        // If this is the first node we've seen at this depth
        if (depth == res.size()) {
            res.push_back(node->val);
        }
        
        // Prioritize right side
        dfs(node->right, depth + 1, res);
        dfs(node->left, depth + 1, res);
    }
};"
  java="class Solution {
    // BFS Approach
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> result = new ArrayList<>();
        if (root == null) return result;
        
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        
        while (!queue.isEmpty()) {
            int size = queue.size();
            
            for (int i = 0; i < size; i++) {
                TreeNode node = queue.poll();
                
                // If it's the last element in this level, add to result
                if (i == size - 1) {
                    result.add(node.val);
                }
                
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        
        return result;
    }
}"
  python="class Solution:
    # DFS Approach
    def rightSideView(self, root: Optional[TreeNode]) -> List[int]:
        result = []
        
        def dfs(node, depth):
            if not node:
                return
                
            # If we haven't added a node for this depth yet
            if depth == len(result):
                result.append(node.val)
                
            # Must go right first!
            dfs(node.right, depth + 1)
            dfs(node.left, depth + 1)
            
        dfs(root, 0)
        return result"

# Common Pitfalls

<Warning>
- **The Shadow Trap:** Assuming the right view is just the path starting from root and only following `node.right`. If the right child is short, but the left child is very deep, the left child's deep nodes will peek out and be visible!
- **DFS Left First:** If using the DFS method, accidentally traversing `left` before `right`. This would give you the Left View of the binary tree instead!
</Warning>
