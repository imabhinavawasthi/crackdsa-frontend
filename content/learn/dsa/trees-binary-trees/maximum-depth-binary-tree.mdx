# Theory & Concepts

Finding the **Maximum Depth of a Binary Tree** (also known as the height of the tree) is one of the most fundamental tree algorithms. It acts as a gateway to understanding Bottom-Up (Postorder) recursive problem-solving.

### The Core Idea
The maximum depth of a tree is simply:
`1 + MAX(depth of left subtree, depth of right subtree)`

This naturally lends itself to a recursive solution. For any given node, we ask its left child to calculate its depth, we ask its right child to calculate its depth, and we take the larger of the two, adding 1 to account for the current node itself.

### Alternative Approaches
While DFS (Recursion) is the most elegant, you can also solve this using BFS (Level Order Traversal) by simply counting how many levels you process before the queue becomes empty.

# Code Implementation

<CodeBlock
  cpp="class Solution {
public:
    int maxDepth(TreeNode* root) {
        // Base case: an empty tree has a depth of 0
        if (root == nullptr) {
            return 0;
        }
        
        // Recursively find the depth of left and right subtrees
        int leftDepth = maxDepth(root->left);
        int rightDepth = maxDepth(root->right);
        
        // Current node depth is 1 + max of children's depths
        return 1 + max(leftDepth, rightDepth);
    }
};"

# Common Pitfalls

<Warning>
- **Overcomplicating the Base Case:** Some beginners try to check `if (root.left == null && root.right == null) return 1`. While true, checking `if (root == null) return 0` is much cleaner and handles empty trees automatically.
- **Using Global Variables:** Instead of returning the height, some people try to maintain a global `max_depth` variable and update it during traversal. While it works, passing results up the recursion stack is a much stronger functional programming paradigm to demonstrate.
</Warning>
