# Theory & Concepts

**Depth-First Search (DFS)** is an algorithm for traversing or searching tree data structures. The algorithm starts at the root node and explores as far as possible along each branch before backtracking. 

Because trees are inherently recursive, DFS is naturally implemented using recursion. In binary trees, there are three primary ways to perform DFS, named based on when the current (root) node is processed relative to its children:

### 1. Preorder (Root -> Left -> Right)
In Preorder traversal, we visit the node itself first, then explore its left subtree, and finally its right subtree. It's often used when we want to clone a tree or serialize it.

### 2. Inorder (Left -> Root -> Right)
In Inorder traversal, we first explore the left subtree, then visit the node itself, and finally explore the right subtree. Crucially, in a Binary Search Tree (BST), an inorder traversal yields the elements in sorted (ascending) order.

### 3. Postorder (Left -> Right -> Root)
In Postorder traversal, we explore both the left and right subtrees first before visiting the node itself. This is exceptionally useful when you need to gather information from children before making a decision at the parent (e.g., calculating height or deleting a tree).

  java="class Solution {
    // Example: Preorder Traversal
    public void preorder(TreeNode root, List<Integer> res) {
        if (root == null) return;
        res.add(root.val);
        preorder(root.left, res);
        preorder(root.right, res);
    }
}"

    # Example: Postorder Traversal
    def postorder(self, root: TreeNode, res: List[int]):
        if not root:
            return
        self.postorder(root.left, res)
        self.postorder(root.right, res)
        res.append(root.val)"

# Common Pitfalls

<Warning>
- Attempting to use a global array/list to store traversal results. It's better practice to pass the collection as an argument.
- Forgetting to write the base case `if (root == null) return;`.
- Not understanding how to convert the recursive approach to an iterative approach using an explicit Stack.
</Warning>
