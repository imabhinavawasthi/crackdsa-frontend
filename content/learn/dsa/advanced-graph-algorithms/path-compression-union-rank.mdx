# Theory & Concepts
To make the Disjoint Set Union (DSU) operations nearly constant time, we implement two powerful optimizations: **Path Compression** and **Union by Rank/Size**.

### Path Compression
Path compression is an optimization for the `Find` operation. While traversing up the tree to find the root, we can attach every visited node directly to the root. Thus, subsequent calls to `Find` for these nodes or their descendants will execute much faster, in $O(1)$ time. 

### Union by Rank (or Size)
Union by rank optimizes the `Union` operation. When merging two trees, we always attach the root of the shorter/smaller tree to the root of the taller/larger tree. 
- **By Rank:** Uses tree height. The height of the merged tree only increases if both original trees had the exact same height.
- **By Size:** Uses the number of nodes. The size of the merged tree is the sum of the sizes of the two trees.

Together, these optimizations ensure that the tree depth remains extremely shallow, resulting in an amortized time complexity of $O(\alpha(V))$, where $\alpha$ is the incredibly slow-growing Inverse Ackermann function.

# Common Pitfalls
<Warning>
- **Modifying rank erroneously:** Remember that the rank of the merged tree only increases if both roots had the *exact same rank* prior to the merge.
- **Forgetting to update parent in `find`:** `return find(parent[i])` does NOT do path compression! You must assign it: `return parent[i] = find(parent[i])`.
</Warning>
