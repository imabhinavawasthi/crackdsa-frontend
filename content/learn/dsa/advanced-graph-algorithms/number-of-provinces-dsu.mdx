# Theory & Concepts
The **Number of Provinces** problem is a classic application of the Disjoint Set Union (DSU) data structure. We are given $n$ cities. Some of them are connected, while some are not. If city `a` is connected directly with city `b`, and city `b` is connected directly with city `c`, then city `a` is connected indirectly with city `c`. 

A **province** is a group of directly or indirectly connected cities and no other cities outside of the group. This directly maps to **Connected Components** in an undirected graph.

While Depth First Search (DFS) or Breadth First Search (BFS) can also count connected components, using DSU provides an elegant solution. Initially, we consider every city to be its own independent province (total $n$ provinces). Then, we iterate through the adjacency matrix. If two distinct cities are connected, we unite their sets and decrement our province count by 1.

# Common Pitfalls
<Warning>
- **Iterating full matrix:** Traversing all $i$ and $j$ from $0$ to $N-1$ does redundant work. Since the graph is undirected, the matrix is symmetric. Only process `j` from `i + 1` to `N - 1`.
- **Not maintaining a count variable:** Scanning the parent array at the end is an alternative, but keeping a `count` variable and decrementing on successful unions is much cleaner.
</Warning>
