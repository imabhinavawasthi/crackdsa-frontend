# Theory & Concepts
The **Redundant Connection** problem is a classic application of the Disjoint Set Union (DSU) pattern. You are given a graph that started as a tree with $n$ nodes but had exactly one extra edge added to it. Your goal is to find this extra edge that created a cycle, and return it.

A tree is a connected graph with $n$ nodes and $n-1$ edges (i.e., no cycles). Adding one edge inherently creates exactly one cycle. 

Using DSU, we can iterate over the edges one by one:
1. For each edge `[u, v]`, we check if `u` and `v` are already in the same set (have the same root).
2. If they are not in the same set, we union them.
3. If they **are** already in the same set, adding this edge creates a cycle! Since we are iterating over edges in order, the first edge we find that connects two already-connected nodes is our redundant connection.

# Common Pitfalls
<Warning>
- **1-based vs 0-based indexing:** Graph nodes in this specific problem are 1-indexed (from 1 to N). Ensure your parent and rank arrays are sized `N + 1`.
- **Finding ALL cycles vs ONE cycle:** As soon as `unite` returns false, you have found the redundant edge. Do not process the rest of the edges!
</Warning>
