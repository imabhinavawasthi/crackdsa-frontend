# Theory & Concepts
The **Bellman-Ford Algorithm** is a fundamental single-source shortest path algorithm. While Dijkstra's algorithm is faster, Bellman-Ford is more versatile because it handles graphs with **negative edge weights** and can detect **negative weight cycles**.

### Core Intuition
The core idea relies on the principle of *Edge Relaxation*. In a graph with `V` vertices, the shortest path between any two nodes can have at most `V - 1` edges. 
Therefore, if we relax all edges in the graph `V - 1` times, we guarantee that the shortest path distance to all reachable nodes is computed correctly.

If we relax all edges one more time (the `V`-th time) and any distance updates, it strictly implies the presence of a negative weight cycle!

# Common Pitfalls
<Warning>
- **Initial Distance Overflow:** Using `Integer.MAX_VALUE` or `INT_MAX` for infinity can cause integer overflow when adding `w` (`dist[u] + w`). Use a sufficiently large number like `1e8` instead.
- **Invalid Relaxations:** Forgetting to check if `dist[u] != infinity` before attempting to relax the edge `u -> v`. You cannot relax an edge from an unreachable node!
- **Not Checking for Cycles:** Sometimes interviewers specifically ask if shortest paths are even valid. Missing the V-th iteration check could fail test cases with negative cycles.
</Warning>
