# Theory & Concepts
A **Strongly Connected Component (SCC)** is a portion of a directed graph where every node can reach every other node within that component. In an undirected graph, connected components are trivial to find, but in directed graphs, a path from $A$ to $B$ does not guarantee a path from $B$ to $A$.

**Kosaraju's Algorithm** is an elegant two-pass Depth First Search (DFS) approach to finding all SCCs in $O(V+E)$ time:
1. **First Pass:** Perform DFS on the original graph. As recursive calls finish, push the nodes onto a stack. This effectively sorts the nodes by their "finish times" (similar to topological sorting).
2. **Reverse the Graph:** Transpose the graph by reversing the direction of all edges.
3. **Second Pass:** Pop nodes from the stack. For each unvisited node, perform a DFS on the transposed graph. All nodes reachable in this DFS form a single Strongly Connected Component.

            visited[node] = True
            for neighbor in adj[node]:

# Common Pitfalls
<Warning>
- **Resetting `visited` Array:** Do not forget to clear or reinitialize the `visited` array before starting the second DFS pass.
- **Pushing to Stack:** The node must be pushed to the stack *after* all its neighbors are visited (post-order traversal), not before.
</Warning>
