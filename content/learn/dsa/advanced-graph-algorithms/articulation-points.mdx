# Theory & Concepts
An **Articulation Point** (or cut vertex) is a node in a graph whose removal (along with all its incident edges) increases the number of connected components. Similar to bridges, articulation points represent single points of failure in a network.

Finding articulation points is highly analogous to Tarjan's bridge-finding algorithm. We maintain `tin` (Time In) and `low` (Lowest Time) arrays using a single DFS pass.

There are two conditions for a node $u$ to be an articulation point:
1. **Root of DFS tree:** If $u$ is the root of the DFS tree, it is an articulation point if and only if it has **more than one disconnected child** in the DFS tree.
2. **Non-root of DFS tree:** If $u$ is not the root, it is an articulation point if it has a child $v$ such that no back-edge from the subtree of $v$ reaches an ancestor of $u$. The mathematical condition is `low[v] >= tin[u]`.

private:
    int timer = 1;
    void dfs(int node, int parent, vector<int>& visited, vector<int> adj[], 
             vector<int>& tin, vector<int>& low, vector<int>& mark) {
        visited[node] = 1;
        tin[node] = low[node] = timer++;
        int childCount = 0;
        
        for (auto it : adj[node]) {
            if (it == parent) continue;
            
            if (!visited[it]) {
                dfs(it, node, visited, adj, tin, low, mark);
                low[node] = min(low[node], low[it]);
                
                // Condition for non-root
                if (low[it] >= tin[node] && parent != -1) {
                    mark[node] = 1;
                }
                childCount++;
            } else {
                // Back-edge
                low[node] = min(low[node], tin[it]);
            }
        }
        
        // Condition for root
        if (parent == -1 && childCount > 1) {
            mark[node] = 1;
        }
    }
public:
    vector<int> articulationPoints(int V, vector<int> adj[]) {
        vector<int> visited(V, 0);
        vector<int> tin(V);
        vector<int> low(V);
        vector<int> mark(V, 0); // using an array as a set

            }

# Common Pitfalls
<Warning>
- **Using arrays directly for results:** Since multiple subtrees could independently trigger `low[it] >= tin[node]` for the same node, adding to a list immediately could cause duplicate entries. Always use a boolean marking array or Set.
- **Bridges vs Articulation Condition:** Bridges check `low[it] > tin[node]`, while Articulation Points check `low[it] >= tin[node]`.
</Warning>
