# Theory & Concepts
Dijkstra's Algorithm is a greedy algorithm used to find the shortest path from a single source node to all other nodes in a graph with non-negative edge weights.

### Core Intuition
The algorithm maintains a set of unvisited nodes and calculates the tentative distance from the source to these nodes. It continuously selects the unvisited node with the smallest known distance, marks it as visited, and updates the distances to its adjacent nodes. We typically use a Min-Heap (Priority Queue) to efficiently fetch the node with the smallest distance.

### The Algorithm Steps
1. Initialize an array `dist` of size `V` with `infinity`, except `dist[source] = 0`.
2. Push `(0, source)` into a Min-Heap.
3. While the heap is not empty, extract the node `u` with the minimum distance `d`.
4. If `d > dist[u]`, it means we already found a shorter path to `u` earlier, so we skip it (lazy deletion).
5. For each neighbor `v` of `u` with edge weight `w`:
   - If `dist[u] + w < dist[v]`, update `dist[v] = dist[u] + w` and push `(dist[v], v)` into the heap.

# Common Pitfalls
<Warning>
- **Negative Weights:** Dijkstra's Algorithm fails or loops infinitely when graphs contain negative edge weights. Use Bellman-Ford instead.
- **Outdated Queue Elements:** A node might be inserted into the priority queue multiple times with different distances. Always check `if (d > dist[u]) continue;` to skip outdated pairs and avoid redundant work.
- **Disconnected Graphs:** If the graph is disconnected, nodes unreachable from the source will remain at `infinity`. Ensure your code handles this correctly.
</Warning>
