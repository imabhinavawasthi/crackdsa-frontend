# Theory & Concepts
**Prim's Algorithm** is a greedy algorithm used to find the Minimum Spanning Tree (MST) of a weighted, undirected graph. It starts from an arbitrary node and grows the MST one edge at a time.

### Core Intuition
We maintain a set of nodes currently included in the MST and a Priority Queue to pick the smallest edge connecting the MST set to a node outside it.
1. Start at any node, mark it as visited, and push its adjacent edges into a Min-Heap.
2. Extract the minimum edge from the heap.
3. If the edge leads to an unvisited node, add the edge weight to the total cost, mark the node as visited, and push all its edges to unvisited neighbors into the heap.
4. Repeat until all nodes are visited.

# Common Pitfalls
<Warning>
- **Visited Marking Delay:** Ensure you only mark a node as visited *after* it's popped from the priority queue, not when you push it. Marking it upon push can lead to suboptimal paths.
- **Handling Disconnected Components:** The standard Prim's starting from node `0` assumes the graph is connected. If it's a forest, you must iterate over all nodes and start a new Prim's process for unvisited nodes.
</Warning>
