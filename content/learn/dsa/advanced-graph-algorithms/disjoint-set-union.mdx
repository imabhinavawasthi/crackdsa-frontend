# Theory & Concepts
The **Disjoint Set Union (DSU)** framework answers whether two elements belong to the same set and merges different sets seamlessly. Think of it as keeping track of connected components in a dynamically growing graph.

At its core, DSU treats components as trees. The "representative" or "root" of the tree identifies the set.
If two elements share the same root, they are in the same set. If they have different roots, a Union operation attaches the root of one tree to the root of the other, effectively combining the components.

The actual power of DSU lies in two essential optimizations (discussed in later lessons): **Path Compression** and **Union by Rank/Size**. When implemented together, they drop the amortized time complexity of DSU operations to nearly constant time.

    vector<int> parent, size;
public:
    DSU(int n) {
        parent.resize(n);
        size.resize(n, 1);
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    
    int find(int x) {
        if (x == parent[x]) return x;
        return parent[x] = find(parent[x]);
    }
    
    bool unite(int x, int y) {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX == rootY) return false;
        
        if (size[rootX] < size[rootY]) swap(rootX, rootY);
        parent[rootY] = rootX;
        size[rootX] += size[rootY];
        return true;
    }
};`}

        self.parent = list(range(n))
        self.size = [1] * n

        if self.parent[x] == x:

# Common Pitfalls
<Warning>
- **Size update omission:** In the `unite` method, failing to update the `size` array when attaching the smaller tree to the larger one.
- **Returning wrong boolean:** Ensure `unite` returns `false` if nodes are already connected. This is extremely useful for cycle detection.
</Warning>
