# Theory & Concepts
**Dijkstra's Algorithm** is the go-to approach for finding the shortest paths from a starting node to all other nodes. Think of it as BFS but equipped to handle edge weights smoothly using a Priority Queue.

### Core Intuition
We continually explore the closest unvisited node. By doing so greedily, we guarantee that the first time we visit a node, we have found the absolute shortest path to it (provided no negative weights exist).

    vector<int> solve(int V, vector<vector<pair<int,int>>>& adj, int S) {

        vector<int> dist(V, 1e9);

            pq.pop();

                    dist[v] = dist[u] + w;
                    pq.push({dist[v], v});
                }
            }
        }
        return dist;
    }

# Common Pitfalls
<Warning>
- Forgetting to skip stale priority queue entries with `if (d > dist[u]) continue;`.
- Applying Dijkstra blindly on graphs with negative cycles causing infinite loops.
</Warning>
