# Theory & Concepts
**Kruskal's Algorithm** is an elegant, greedy approach for finding the Minimum Spanning Tree (MST) of a weighted, undirected graph. Instead of growing the tree from a single source like Prim's, it builds the MST by greedily picking the smallest edges from anywhere in the graph.

### Core Intuition
1. **Sort all edges** in the graph in non-decreasing order of their weight.
2. Iterate through the sorted edges and use a **Disjoint Set Union (DSU)** to check if adding the current edge forms a cycle.
3. If the edge's two endpoints belong to different disjoint sets, add the edge to the MST and union their sets.
4. If they belong to the same set, discard the edge to prevent a cycle.

# Common Pitfalls
<Warning>
- **Forgetting DSU Optimization:** Make sure to implement Path Compression and Union by Rank/Size in your DSU. Without them, the find operations can degrade to O(V).
- **Graph Representation:** Kruskal's algorithm requires a flat list of edges. If given an adjacency list, you must first convert it to an edge list.
</Warning>
