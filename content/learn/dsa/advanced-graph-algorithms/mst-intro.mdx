# Theory & Concepts
A **Spanning Tree** of an undirected, connected graph is a subgraph that includes all the vertices of the original graph but contains no cycles. A graph can have multiple spanning trees.

A **Minimum Spanning Tree (MST)** is a spanning tree whose sum of edge weights is as small as possible. 

### Core Intuition
The problem of finding an MST frequently appears in scenarios like designing networks (telecom, electrical, computer networks), where you want to connect all nodes with the minimum total cost.
The two most prominent algorithms used to find the Minimum Spanning Tree are **Prim's Algorithm** and **Kruskal's Algorithm**.

1. **Prim's Algorithm** builds the MST node by node, starting from an arbitrary node and always picking the smallest edge connecting the growing tree to a new unvisited node.
2. **Kruskal's Algorithm** builds the MST edge by edge. It sorts all edges by weight and continually adds the smallest edge that does not form a cycle.

# Common Pitfalls
<Warning>
- **Disconnected Graphs:** If the graph is not connected, an MST cannot exist. You can instead find a Minimum Spanning Forest.
- **Cycle Detection:** The primary challenge in MST algorithms is avoiding cycles, which requires tools like the Disjoint Set Union (DSU) or marking visited nodes.
</Warning>
