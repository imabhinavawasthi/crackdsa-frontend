# Theory & Concepts
The **Floyd-Warshall Algorithm** is a classic dynamic programming approach used to find the shortest paths between **all pairs** of vertices in an edge-weighted directed graph. It handles positive and negative edge weights but cannot deal with negative weight cycles (although it can detect them).

### Core Intuition
Instead of fixing a source vertex, the algorithm considers each vertex one by one and uses it as an intermediate point to see if a path between any two vertices `i` and `j` can be shortened by going through `k`.

The recurrence relation is:
`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`

By iterating `k` from `0` to `V-1`, we gradually build up the shortest paths allowing more and more intermediate nodes.

# Common Pitfalls
<Warning>
- **Loop Order Matters:** The outer loop must be the intermediate node `k`. If you place `k` in the innermost loop, the algorithm fails because it doesn't build paths progressively.
- **Integer Overflow:** If using `Integer.MAX_VALUE`, `dist[i][k] + dist[k][j]` can overflow to a negative value. Use a smaller infinity like `1e9`.
- **Self Loops:** Explicitly set `dist[i][i] = 0` before running the algorithm unless the problem specifies otherwise.
</Warning>
