# Theory & Concepts
**Kruskal's MST** is a popular greed-based pattern heavily reliant on the **Disjoint Set Union (DSU)** data structure. The core concept revolves around picking the smallest edges while ensuring no cycles are created.

### Core Intuition
If you view all vertices as isolated islands, the algorithm builds bridges (edges) starting from the cheapest ones. It only builds a bridge if it connects two islands that aren't already connected through other paths. This cycle avoidance is rapidly solved using DSU.

# Common Pitfalls
<Warning>
- **Ignoring Disconnected Vertices:** MST requires V-1 edges. If you run out of edges and haven't placed V-1 edges, the graph is disconnected.
- **Sorting Incorrectly:** Always sort based on the weights. A common mistake in Python or C++ is sorting tuples without specifying the index if weights are not the first element.
</Warning>
