# Theory & Concepts
Checking if a linked list is a palindrome tests your ability to combine multiple linked list techniques. A palindrome reads the same forwards and backwards. Since a singly linked list can only be traversed forward, this poses an interesting challenge.

### The Optimal Strategy
To achieve O(1) space complexity, follow these steps:
1. **Find the Middle:** Use the fast and slow pointer technique to find the middle of the linked list.
2. **Reverse the Second Half:** Reverse the second half of the linked list starting from the middle node.
3. **Compare Halves:** Iterate through the first half and the reversed second half, comparing their values.
4. **Restore the List (Optional but recommended):** Reverse the second half again to restore the list to its original state.

# Common Pitfalls
<Warning>
- **Failing to restore the list:** In a real-world scenario, modifying an input structure without restoring it can break other parts of a system.
- **Odd vs Even Lengths:** Be very careful with the middle pointer. When the list has an odd number of nodes, the actual middle node doesn't need to be compared.
</Warning>
