# Theory & Concepts
A **Singly Linked List** is a fundamental data structure consisting of nodes. Each node contains data and a reference (or pointer) to the next node in the sequence. Unlike arrays, elements in a linked list are not stored in contiguous memory locations, making insertion and deletion operations more efficient since no elements need to be shifted.

### Insertion
Inserting a new node into a singly linked list can happen at three distinct places:
1. **At the beginning (Head):** Create a new node, point its next reference to the current head, and update the head pointer.
2. **At the end (Tail):** Traverse to the last node and update its next reference to point to the new node.
3. **In the middle:** Traverse to the node just before the insertion point, update the new node's next reference to the current node's next, and then update the current node's next to the new node.

### Deletion
Deleting a node is similar:
1. **From the beginning:** Move the head pointer to the next node.
2. **From the end/middle:** Traverse to the node preceding the one you want to delete, and update its next pointer to skip the node being deleted.

# Common Pitfalls
<Warning>
- **Null Pointer Exceptions:** Always check if the current node or next node is null before accessing their properties.
- **Lost References:** Be careful with the order of operations when updating pointers. If you update the next pointer of the current node too early, you lose access to the remainder of the list.
</Warning>
