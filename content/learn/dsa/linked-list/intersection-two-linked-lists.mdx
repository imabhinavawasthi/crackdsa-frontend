# Theory & Concepts
Finding the intersection of two linked lists is a fantastic problem that tests your understanding of linked list structure. If two linked lists intersect, it means they share the exact same node in memory, and thus share all subsequent nodes until the end.

### Two Pointer Approach
To find the intersection in O(1) space, we can use two pointers. Let pointer `A` start at `headA` and pointer `B` start at `headB`. We traverse the lists. When a pointer reaches the end of its list, we redirect it to the head of the *other* list.

This guarantees that both pointers will traverse exactly the same number of nodes before meeting at the intersection. If list A has length L_A and list B has length L_B, and they intersect, pointer A travels L_A + L_B nodes and pointer B travels L_B + L_A nodes. They meet at the intersection perfectly. If they don't intersect, they will both reach `null` simultaneously.

# Common Pitfalls
<Warning>
- **Comparing Values vs Nodes:** An intersection means the exact same node object in memory. Don't just compare node values (`pA.val == pB.val`). Compare the references (`pA == pB`).
- **Infinite Loops:** If you don't advance the pointers to `null` before redirecting to the other list's head, you may create an infinite loop.
</Warning>
