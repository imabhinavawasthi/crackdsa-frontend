# Theory & Concepts
A **Doubly Linked List** builds upon the singly linked list by adding an extra pointer to each node: the prev pointer. This allows traversal in both directions—forwards and backwards.

While doubly linked lists require more memory per node (for the extra pointer) and involve more complex pointer updates during insertions and deletions, they offer significant advantages:
1. O(1) deletion if you are given a pointer to the exact node to be deleted.
2. Easy reverse traversal.
3. Convenient implementation of complex data structures like Deques and the LRU Cache.

### Key Operations
When adding or removing a node, you must update up to 4 pointers (the next and prev of the adjacent nodes). Missing any of these updates can lead to broken chains or memory leaks.

# Common Pitfalls
<Warning>
- **Forgetting the Prev Pointer:** It is very common to only update the next pointer and forget the prev pointer, resulting in an inconsistent list structure when iterating backwards.
- **Head Deletion Edge Cases:** Failing to update the new head's prev pointer to null after deleting the original head.
</Warning>
