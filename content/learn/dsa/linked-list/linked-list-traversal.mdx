# Theory & Concepts
**Traversal** is the most basic yet crucial operation you can perform on a linked list. It refers to the process of visiting each node exactly once. Because there is no random access like in an array, you rely solely on traversal to find values, compute lengths, or seek specific insertion points.

### The Role of Traversal in Insertion
When you need to insert a node at a specific position k or after a certain value, you must safely traverse the list until you reach the target node. During this traversal, maintaining a correct reference to the current node is critical. 

### Why not arrays?
Array insertion requires shifting all subsequent elements, causing an O(N) penalty. Linked lists, once traversed to the correct insertion spot, allow for an O(1) pointer adjustment, making them theoretically more efficient for volatile lists with high insertion and deletion volumes.

# Common Pitfalls
<Warning>
- **Updating the head incorrectly:** Always use a temporary variable (like curr) to traverse. If you reassign the head to traverse, you will lose the entire first portion of the linked list.
- **Index Out Of Bounds equivalent:** Traversing past the end of the list and attempting to access the next property causes a crash.
</Warning>
