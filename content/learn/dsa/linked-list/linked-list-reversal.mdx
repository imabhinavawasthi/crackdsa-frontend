# Theory & Concepts
**Reversing a Linked List** is arguably the most fundamental and frequently tested Linked List pattern. It serves as a building block for dozens of harder algorithmic problems (like palindromes, reversing in K-groups, and reordering lists).

Unlike an array where you can iterate backwards using an index, a singly linked list's nodes only point strictly forward. To reverse the list, we must systematically flip the direction of every `next` pointer in-place. 

**The Mechanics:**
At any given node, to point it backwards, we need to know the `previous` node. However, the moment we overwrite `curr.next = prev`, we lose the reference to the rest of the list! To prevent this, we must always save a temporary reference to `curr.next` before flipping the pointer.

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* curr = head;
        
        while (curr != nullptr) {
            ListNode* nextTemp = curr->next; // Save the future
            curr->next = prev;               // Flip the pointer backwards
            prev = curr;                     // Move prev forward
            curr = nextTemp;                 // Move curr forward
        }
        
        return prev; // prev is the new head
    }
};"

# Common Pitfalls
<Warning>
- **Returning the wrong head:** A very common mistake is `return head` or `return curr`. When the while loop finishes, `curr` is `null`, and `head` is now the very last node. `prev` will point to the true new head of the reversed list.
- **Cycle Creation:** If you forget to initialize `prev = null`, the original head's next pointer will contain garbage (or point to itself), creating an infinite loop.
</Warning>
