# Theory & Concepts
In a **Multilevel Doubly Linked List**, nodes can optionally point to a separate `child` doubly linked list, creating a multi-tiered hierarchy. The challenge is to flatten this structure so all nodes reside on a single, one-dimensional level. 

The flattening process dictates that a child list must be entirely integrated into the parent list directly *after* the node that spawned it, but *before* that parent node's original `next` node.

This is effectively a **Depth-First Search (DFS)**. While you can solve it recursively or with a Stack, there is an elegant $O(1)$ space iterative solution. Whenever you encounter a node with a child, you splice the entire child list between the current node and the `next` node. You achieve this by traversing down to find the child list's tail, connecting it to `next`, and then continuing your main iteration.

    Node* flatten(Node* head) {
        if (!head) return nullptr;
        
        Node* curr = head;
        while (curr) {
            // If the node has a child, we must flatten it
            if (curr->child) {
                Node* next = curr->next;
                Node* child = curr->child;
                
                // Connect current to child
                curr->next = child;
                child->prev = curr;
                curr->child = nullptr; // Don't forget to nullify the child pointer
                
                // Traverse to the tail of the child sublist
                Node* tail = child;
                while (tail->next) {
                    tail = tail->next;
                }
                
                // Connect the child's tail to the original next node
                tail->next = next;
                if (next) {
                    next->prev = tail;
                }
            }
            // Move on to the next node
            curr = curr->next;
        }
        
        return head;
    }
};"

# Common Pitfalls
<Warning>
- **Forgetting to nullify `curr.child`:** The problem specifically requires the resulting list to be a standard doubly linked list. If you forget to set `curr.child = null`, the autograder will fail.
- **Handling `next == null`:** The parent node might not have a `next` node (e.g., it's the tail of its current level). Attempting to access `next.prev` in this case will trigger a Null Pointer Exception. Always check `if (next != null)`.
</Warning>
