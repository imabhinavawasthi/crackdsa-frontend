# Theory & Concepts
Cycle Detection is a classic problem that asks whether a linked list contains a cycle. A cycle occurs if there is some node in the list that can be reached again by continuously following the `next` pointer.

### Floyd's Tortoise and Hare
The most optimal way to detect a cycle is to use two pointers moving at different speeds. 
- The **Slow Pointer (Tortoise)** moves one step at a time.
- The **Fast Pointer (Hare)** moves two steps at a time.

If there is no cycle, the fast pointer will simply reach the end of the list. If there is a cycle, the fast pointer will eventually \"lap\" the slow pointer and they will point to the exact same node.

# Common Pitfalls
<Warning>
- **Null Pointer Exceptions:** Ensure you check `fast` and `fast.next` for null before attempting to access `fast.next.next`.
- **Initialization:** Both pointers should typically start at the `head`, though starting `fast` at `head.next` is also valid if you adjust the loop condition appropriately.
</Warning>
