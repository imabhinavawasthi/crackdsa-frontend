# Theory & Concepts
In a standard Linked List clone problem, you simply iterate through the original list and spawn new nodes. However, **Copy List with Random Pointer** adds a twist: each node possesses a `random` pointer that can point to absolutely any node in the list, or be null.

If you blindly copy the list in a single pass, when you encounter a `random` pointer linking forward, that target node might not exist yet!

There are two dominant solutions:
1. **Hash Map (O(N) Space):** Map each original node to its clone. In a second pass, map the cloned node's `next` and `random` references using the dictionary.
2. **Interwoven List (O(1) Space):** Clone nodes and insert them immediately *after* their original counterpart. `A -> A' -> B -> B'`. Then resolve random pointers, and finally unweave the two lists. We will focus on this brilliant O(1) space solution.

                clone->next = clone->next->next;

            curr = curr->next;

# Common Pitfalls
<Warning>
- **Mutating the Original List:** Do not return the cloned list while leaving the original list in a permanently damaged state. Ensure the `unweave` step fully restores the original input's next pointers.
- **Null Random Pointers:** A node's random pointer can be null. Always check `if (curr.random)` before attempting to access `curr.random.next`.
</Warning>
