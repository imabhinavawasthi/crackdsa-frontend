# Theory & Concepts
Merging two sorted linked lists is a foundational problem that tests your ability to safely manipulate pointers while traversing two lists simultaneously. The goal is to weave the two existing lists together to form a single, sorted list.

### Dummy Node Pattern
The most robust way to build a new linked list is by using a **Dummy Node**. A dummy node serves as a pseudo-head. We attach our sorted nodes to it one by one using a `tail` pointer. This elegantly handles the edge case of initializing the head of the merged list without writing messy conditional logic.

Once one of the lists is fully traversed, we simply attach the remainder of the other list directly to our `tail` pointer, since the remaining list is already sorted.

# Common Pitfalls
<Warning>
- **Allocating New Nodes:** A common mistake is creating `new ListNode(val)` for every element. The prompt usually requires you to splice the existing nodes to achieve O(1) space.
- **Forgetting the Remainder:** Failing to append the rest of `list1` or `list2` after the `while` loop finishes.
</Warning>
