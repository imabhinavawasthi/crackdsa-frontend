# Theory & Concepts
**Remove Nth Node From End of List** requires us to delete a node given its position relative to the tail, rather than the head.

### The Two-Pointer Approach
A naive solution involves a two-pass algorithm: traverse once to find the total length L, and then traverse again to delete the node at position L - N + 1.

The optimal **one-pass** solution employs two pointers, fast and slow, and a Dummy Node.
1. The fast pointer is advanced N + 1 steps ahead of slow.
2. Both pointers are then moved one step at a time.
3. When fast reaches the end of the list, slow will be pointing precisely to the node immediately preceding the target node.
4. From there, modifying the next pointer of the slow node effectively removes the Nth node.

# Common Pitfalls
<Warning>
- **Removing the Head:** Without a dummy node, if the target node is the first node (e.g., removing the 2nd node from the end in a length 2 list), it creates nasty edge cases where the slow pointer cannot stand before the head.
- **Incorrect Gap Distance:** You must advance the fast pointer N + 1 steps so slow stops exactly one node before the target, rather than on the target itself.
</Warning>
