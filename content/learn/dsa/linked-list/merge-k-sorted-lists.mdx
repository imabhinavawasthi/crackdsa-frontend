# Theory & Concepts
The **Merge k Sorted Lists** problem is a classic hard-level challenge that tests your ability to synthesize Linked Lists with other advanced data structures, specifically a Priority Queue (Min-Heap) or Divide and Conquer strategies.

Given $k$ linked lists, each sorted in ascending order, the goal is to merge them into one single sorted linked list.
A naive approach would be to collect all elements, sort them, and rebuild a new list. However, this is inefficient and ignores the fact that our input lists are *already* locally sorted.

**Optimal Strategy: Priority Queue (Min-Heap)**
By inserting the head of each of the $k$ lists into a min-heap, we can effortlessly extract the smallest global node in $O(\log k)$ time. Whenever we extract a node and append it to our result list, we simply push its `next` node into the heap.

            pq.pop();

                pq.push(tail->next);
            }
        }

# Common Pitfalls
<Warning>
- **Null List Inputs:** Lists might be empty, or contain null references. Always verify `if (l != null)` before adding a list's head to your heap.
- **Tie-Breaking in Python:** Python's `heapq` will throw a `TypeError` if there is a duplicate value and the secondary comparison falls back onto the `ListNode` objects (which don't natively support `<`). You must either override `__lt__` on the class, or push a tuple containing an incrementing unique ID like `(val, id, node)`.
</Warning>
