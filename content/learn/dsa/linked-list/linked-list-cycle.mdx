# Theory & Concepts
Detecting a cycle in a linked list and finding the starting node of that cycle is a classic interview question. It introduces the powerful "Fast and Slow Pointers" technique, also known as Floyd's Tortoise and Hare algorithm.

### Floyd's Cycle Detection
We use two pointers: a `slow` pointer that moves one step at a time, and a `fast` pointer that moves two steps at a time. If there is a cycle, the fast pointer will eventually overlap with the slow pointer inside the cycle.

### Finding the Start of the Cycle
Once a cycle is detected, we can find the node where the cycle begins. We reset the `slow` pointer to the `head` of the list, and move both `slow` and `fast` pointers one step at a time. The point at which they meet again is the starting node of the cycle.

# Common Pitfalls
<Warning>
- **Null Reference Errors:** Not checking if `fast` and `fast.next` are non-null before advancing the `fast` pointer by two steps.
- **Incorrect Math:** Trying to calculate cycle lengths unnecessarily when finding the start node only requires moving the pointers at the same speed.
</Warning>
