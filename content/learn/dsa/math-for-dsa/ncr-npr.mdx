# Theory & Concepts

Combinatorics is the mathematics of counting. In interview problems, you're frequently asked to find "the number of ways" to do something.

### 1. Permutations ($nPr$)
A permutation is the number of ways to arrange $r$ items out of $n$ available items, where **order matters**.
- **Formula**: $nPr = \frac{n!}{(n - r)!}$
- Example: Arranging 3 people into 2 specific chairs (President, Vice-President). $3P2 = 3! / 1! = 6$.

### 2. Combinations ($nCr$)
A combination is the number of ways to choose $r$ items out of $n$ available items, where **order does NOT matter**.
- **Formula**: $nCr = \frac{n!}{r! (n - r)!}$
- Example: Choosing a team of 2 members from a group of 3 people. $3C2 = 3! / (2! \times 1!) = 3$.

### Computing $nCr$ in Code
There are two primary ways to compute $nCr$ depending on the constraints of the problem:

**Approach 1: Pascal's Triangle (DP)**
If $N$ and $R$ are small (e.g., $N \le 1000$), we can use dynamic programming based on the relation: 
$nCr = (n-1)C(r-1) + (n-1)Cr$. 
This avoids factorials entirely and prevents overflow.

**Approach 2: Factorials with Modular Inverse**
If $N$ is up to $10^5$, Pascal's triangle takes $O(N^2)$ space and time, which is too slow. Instead, we precompute factorials. However, since the numbers are huge, we must return the answer modulo $M$ (e.g., $10^9 + 7$). 
Because the formula involves division by $r! \times (n-r)!$, we **must** use the Modular Multiplicative Inverse to divide!

# Code Implementation

Let's implement the highly efficient $O(N)$ precomputation approach using Modular Inverse.

<CodeBlock
  cpp="// C++ Implementation (O(N) Factorial Precomputation)
#include <iostream>
#include <vector>
using namespace std;

const int M = 1e9 + 7;
const int MAX = 1e5 + 5;
long long fact[MAX];

// Precompute factorials
void precompute() {
    fact[0] = 1;
    for (int i = 1; i < MAX; i++) {
        fact[i] = (fact[i - 1] * i) % M;
    }
}

// Binary Exponentiation
long long power(long long base, long long exp) {
    long long res = 1;
    base %= M;
    while (exp > 0) {
        if (exp % 2 == 1) res = (res * base) % M;
        base = (base * base) % M;
        exp /= 2;
    }
    return res;
}

// Fermat's Little Theorem for Inverse
long long modInverse(long long n) {
    return power(n, M - 2);
}

// nCr % M
long long nCr(int n, int r) {
    if (r < 0 || r > n) return 0;
    
    // nCr = n! * (r!)^-1 * ((n-r)!)^-1 % M
    long long num = fact[n];
    long long den = (modInverse(fact[r]) * modInverse(fact[n - r])) % M;
    
    return (num * den) % M;
}"

M = 10**9 + 7
MAX = 100005

fact = [1] * MAX

    fact[i] = (fact[i - 1] * i) % M

def nCr(n, r):
    if r < 0 or r > n:

    inv_r = pow(fact[r], -1, M)

# Common Pitfalls

<Warning>
- **Out of Bounds**: Always add a base condition `if (r < 0 || r > n) return 0;`. You cannot choose 5 items from a pool of 3.
- **Forgetting Modulo on Denominator**: When computing `den = inv_r * inv_nr`, you MUST apply modulo to the multiplication of the two inverses before multiplying it with the numerator!
</Warning>
