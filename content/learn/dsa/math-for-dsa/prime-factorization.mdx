# Theory & Concepts

The **Fundamental Theorem of Arithmetic** states that every integer greater than 1 can be represented uniquely as a product of prime numbers.
For example:
- $12 = 2 \times 2 \times 3 = 2^2 \times 3^1$
- $30 = 2 \times 3 \times 5$
- $17 = 17^1$ (Since 17 is prime)

Many algorithmic problems involving divisors, GCD, and LCM secretly require you to find the prime factorization of numbers.

### The O(√N) Approach
Just like the primality test, we don't need to check all numbers up to $N$ to find its factors.
We can iterate from $i = 2$ up to $\sqrt{N}$. If $i$ evenly divides $N$, we continuously divide $N$ by $i$ and record $i$ as a prime factor. 

By the time the loop finishes, if the remaining $N$ is still greater than 1, it means the remaining $N$ itself is a prime number (and in fact, the largest prime factor).

# Code Implementation

Here is the standard algorithm to extract all prime factors of $N$:

<CodeBlock
  cpp="// C++ Implementation
#include <iostream>
#include <vector>
using namespace std;

vector<int> primeFactors(int n) {
    vector<int> factors;
    
    // Check for factor 2 explicitly (optional optimization)
    // for (int i = 2; i * i <= n; i++) works perfectly fine
    
    for (int i = 2; i * i <= n; i++) {
        // While i divides n, divide n and add i to factors
        while (n % i == 0) {
            factors.push_back(i);
            n = n / i;
        }
    }
    
    // If n is still greater than 1, then the remaining n is a prime factor
    if (n > 1) {
        factors.push_back(n);
    }
    
    return factors;
}"
  java="// Java Implementation
import java.util.ArrayList;
import java.util.List;

class MathUtils {
    public static List<Integer> primeFactors(int n) {
        List<Integer> factors = new ArrayList<>();
        
        for (int i = 2; i * i <= n; i++) {
            while (n % i == 0) {
                factors.add(i);
                n = n / i;
            }
        }
        
        if (n > 1) {
            factors.add(n);
        }
        
        return factors;
    }
}"

def prime_factors(n):
    factors = []

    while i * i <= n:
        while n % i == 0:
            factors.append(i)
            n = n // i
        i += 1

        factors.append(n)

# Common Pitfalls

<Warning>
- **Forgetting the Remaining Prime**: The most common mistake in this algorithm is forgetting the `if (n > 1)` check at the very end. If $N = 10$, the loop extracts `2`, making $N = 5$. Since $i$ goes up to $\sqrt{5}$ (which is 2), the loop terminates, completely forgetting to add the remaining `5` to the factors list!
</Warning>
