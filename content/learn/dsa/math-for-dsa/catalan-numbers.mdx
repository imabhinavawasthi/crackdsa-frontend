# Theory & Concepts

The **Catalan Numbers** are a sequence of natural numbers that occur in various counting problems, often involving recursively defined objects.

The first few Catalan numbers for $N = 0, 1, 2, 3, 4, 5 \dots$ are:
**1, 1, 2, 5, 14, 42, 132...**

### Applications in DSA
If an interview problem asks you to count the number of ways to do something, and the answer for $N=1,2,3,4$ matches $1, 2, 5, 14$, you are almost certainly looking at a Catalan number problem!

Common applications include:
1. **Valid Parentheses**: The number of valid expressions containing $N$ pairs of parentheses is the $N$-th Catalan number. (e.g., For $N=3$, there are 5 ways: `((())), ()(()), ()()(), (())(), (()())`).
2. **Binary Search Trees**: The number of structurally unique BSTs that can be formed using $N$ distinct nodes.
3. **Mountain Valleys**: The number of paths a mountain climber can take to return to sea level using $N$ upstrokes and $N$ downstrokes without ever dipping below sea level.
4. **Polygon Triangulation**: The number of ways to cut a convex polygon with $N+2$ sides into triangles.

### The Formula
The $N$-th Catalan number $C_n$ can be expressed directly using combinations:

$C_n = \frac{1}{n+1} \binom{2n}{n}$

Alternatively, it can be defined recursively (which is how DP solutions approach it):
$C_{n+1} = \sum_{i=0}^{n} C_i \cdot C_{n-i}$

# Code Implementation

We can compute the $N$-th Catalan number in $O(N)$ time using the direct formula and dynamic programming.

<CodeBlock
  cpp="// C++ Implementation (Dynamic Programming Approach)
#include <iostream>
#include <vector>
using namespace std;

// Calculates the Nth Catalan Number using O(N^2) DP
unsigned long long catalanDP(int n) {
    if (n <= 1) return 1;
    
    vector<unsigned long long> catalan(n + 1, 0);
    catalan[0] = catalan[1] = 1;
    
    for (int i = 2; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            catalan[i] += catalan[j] * catalan[i - j - 1];
        }
    }
    
    return catalan[n];
}"
  java="// Java Implementation
class Catalan {
    // Calculates the Nth Catalan Number using O(N) Binomial Coefficient
    public static long binomialCoeff(int n, int k) {
        long res = 1;
        if (k > n - k) k = n - k;
        
        for (int i = 0; i < k; ++i) {
            res *= (n - i);
            res /= (i + 1);
        }
        return res;
    }

    public static long catalanFormula(int n) {
        // C_n = (2n C n) / (n + 1)
        long c = binomialCoeff(2 * n, n);
        return c / (n + 1);
    }
}"
  python="# Python Implementation
def catalan_formula(n):
    # Using the O(N) binomial coefficient formula
    import math
    
    # math.comb(n, k) computes nCr
    ncr = math.comb(2 * n, n)
    return ncr // (n + 1)

def catalan_dp(n):
    if n <= 1:
        return 1
        
    dp = [0] * (n + 1)
    dp[0] = dp[1] = 1
    
    for i in range(2, n + 1):
        for j in range(i):
            dp[i] += dp[j] * dp[i - j - 1]
            
    return dp[n]"

# Common Pitfalls

<Warning>
- **Massive Integer Overflow**: Catalan numbers grow exponentially! $C_{10} = 16,796$, but $C_{20} = 6,564,120,420$, which already overflows a standard 32-bit integer. Always use 64-bit integers (`long long`), or apply modulo arithmetic if the problem requests it.
</Warning>
