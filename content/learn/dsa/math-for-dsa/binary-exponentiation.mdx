# Theory & Concepts

How do you calculate $A^B$? 
The naive approach is to multiply $A$ by itself $B$ times. If we want the answer modulo $M$, we apply `% M` at each step.
However, if $B = 10^9$, this approach will take $10^9$ operations and result in a Time Limit Exceeded (TLE) error.

We can optimize this significantly using **Binary Exponentiation** (also known as Fast Exponentiation).

### The Core Idea
Instead of calculating $A^B$ step by step, we can break it down based on whether $B$ is even or odd:
- **If B is even**: $A^B = (A^{B/2})^2$
- **If B is odd**: $A^B = A \times (A^{\lfloor B/2 \rfloor})^2$

For example, to calculate $3^{10}$:
1. $3^{10} = (3^5)^2$
2. $3^5 = 3 \times (3^2)^2$
3. $3^2 = (3^1)^2$
4. $3^1 = 3 \times 3^0$

By continually halving the exponent, we reach $B = 0$ in just $\log_2(B)$ steps!

### The Bitwise Iterative Approach
We can write this elegantly using bitwise operators. We look at the binary representation of $B$. If the current least significant bit is `1` (i.e., $B$ is odd), we multiply our result by $A$. Then, we square $A$ and right-shift $B$ by 1 (which halves $B$).

# Code Implementation

Here is the highly optimized $O(\log B)$ iterative implementation:

<CodeBlock
  cpp="// C++ Implementation
#include <iostream>
using namespace std;

// Calculates (base^exp) % mod
long long binaryExponentiation(long long base, long long exp, long long mod) {
    long long res = 1;
    base = base % mod; // Initial modulo just in case base > mod
    
    while (exp > 0) {
        // If exp is odd, multiply base with the result
        if (exp % 2 == 1) {
            res = (res * base) % mod;
        }
        
        // Square the base and halve the exponent
        base = (base * base) % mod;
        exp = exp / 2;
    }
    
    return res;
}"
  java="// Java Implementation
class MathUtils {
    public static long binaryExponentiation(long base, long exp, long mod) {
        long res = 1;
        base = base % mod;
        
        while (exp > 0) {
            // Using bitwise AND to check if odd is slightly faster
            if ((exp & 1) == 1) {
                res = (res * base) % mod;
            }
            
            base = (base * base) % mod;
            exp >>= 1; // Bitwise right shift to divide by 2
        }
        
        return res;
    }
}"
  python="# Python Implementation
def binary_exponentiation(base, exp, mod):
    # Note: Python actually has this built-in: pow(base, exp, mod)
    res = 1
    base = base % mod
    
    while exp > 0:
        if exp % 2 == 1:
            res = (res * base) % mod
            
        base = (base * base) % mod
        exp //= 2
        
    return res"
/>

# Common Pitfalls

<Warning>
- **Overflow During Squaring**: Just like in basic modular multiplication, `base * base` can exceed a 32-bit integer if `mod` is large (e.g., $10^9+7$). Always ensure that `base` and `res` are declared as 64-bit integers (`long long` in C++, `long` in Java).
- **Negative Exponents**: This algorithm only handles positive exponents. If $B$ can be negative, you must calculate $(A^{-B})^{-1}$, which requires computing the Modular Multiplicative Inverse.
</Warning>
