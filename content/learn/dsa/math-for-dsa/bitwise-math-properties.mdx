# Theory & Concepts
Bitwise operations directly manipulate the fundamental bits of data. They are extremely fast and form the core of many advanced mathematical and algorithmic optimizations.

### The Core Operators
- **AND (`&`)**: Returns `1` if both bits are `1`, otherwise `0`. Useful for masking.
- **OR (`|`)**: Returns `1` if at least one bit is `1`. Useful for setting bits.
- **XOR (`^`)**: Returns `1` if bits are different. This is the most powerful operator in DSA due to its properties:
  - `x ^ x = 0` (Self-inverse)
  - `x ^ 0 = x` (Identity)
  - Commutative and associative.
- **NOT (`~`)**: Inverts all bits. Note that in languages using Two's Complement for negative numbers, `~x = -x - 1`.
- **Left Shift (`<<`)**: Shifts bits to the left, effectively multiplying by $2^k$. `x << k` equals $x \times 2^k$.
- **Right Shift (`>>`)**: Shifts bits to the right, effectively dividing by $2^k$. `x >> k` equals $\lfloor x / 2^k \rfloor$.

### Essential Properties
1. **Check if odd/even:** `(x & 1) == 1` means `x` is odd.
2. **Check if power of 2:** `(x & (x - 1)) == 0` (for `x > 0`).
3. **Drop the lowest set bit:** `x = x & (x - 1)`.

# Common Pitfalls
<Warning>
- **Operator Precedence:** Bitwise operators often have lower precedence than arithmetic and equality operators. Always use parentheses! e.g., write `if ((n & 1) == 0)` instead of `if (n & 1 == 0)`.
- **Negative Numbers Shift:** In C++ and Java, right-shifting negative integers (`>>`) preserves the sign bit (Arithmetic Shift), which can lead to infinite loops. Use `>>>` in Java for Logical Shift. Python handles arbitrarily large integers, so shift behaves differently for negatives.
</Warning>
