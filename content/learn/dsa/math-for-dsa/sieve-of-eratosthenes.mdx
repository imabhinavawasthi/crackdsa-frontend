# Theory & Concepts

In the previous lesson, we learned how to check if a single number $N$ is prime in $O(\sqrt{N})$ time. But what if an interview problem asks you to answer $10^5$ queries, or asks you to find **all** prime numbers strictly less than $N$ (where $N \le 10^7$)?

Calling the $O(\sqrt{N})$ test $N$ times would take $O(N\sqrt{N})$ time, which will result in a Time Limit Exceeded (TLE) error.

### Enter the Sieve of Eratosthenes
The **Sieve of Eratosthenes** is an ancient and elegant algorithm that precomputes all prime numbers up to $N$.

**The Algorithm:**
1. Create a boolean array `isPrime` of size $N+1$ and initialize all entries to `true`.
2. Mark `isPrime[0]` and `isPrime[1]` as `false`.
3. Start iterating from $i = 2$. If `isPrime[i]` is `true`, then $i$ is a prime number.
4. If $i$ is prime, mark all of its multiples ($2i, 3i, 4i \dots$) as `false`.
5. Move to the next number and repeat until you've processed up to $\sqrt{N}$.

# Code Implementation

Let's implement the Sieve. Notice how we start marking multiples from $i \times i$ instead of $2i$, because all smaller multiples (like $i \times 2$, $i \times 3$) would have already been marked by smaller primes!

<CodeBlock
  cpp="// C++ Implementation
#include <iostream>
#include <vector>
using namespace std;

vector<bool> sieve(int n) {
    // Initialize array of size n+1 to true
    vector<bool> isPrime(n + 1, true);
    isPrime[0] = isPrime[1] = false;
    
    // We only need to process up to sqrt(N)
    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            // Mark all multiples of i starting from i*i
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }
    
    return isPrime;
}"

# Common Pitfalls

<Warning>
- **Memory Limits**: The Sieve uses $O(N)$ space. You can easily allocate an array of $10^7$ booleans ($\approx 10$ MB), but allocating an array for $N = 10^9$ will require $1$ GB of contiguous memory and will crash your program.
- **Inner Loop Start Point**: Always start the inner loop at `j = i * i`. Starting at `j = 2 * i` is redundant and makes your code slightly slower. (Beware of integer overflow if $i \approx 10^5$; use `(long long)i * i`).
</Warning>
