# Theory & Concepts

In the previous lesson, we saw that the naive approach to finding $GCD(A, B)$ takes $O(\min(A, B))$ time. The **Euclidean Algorithm** is an ancient method that computes the GCD in logarithmic time.

### The Core Idea
The Euclidean Algorithm is based on a simple mathematical principle:
**The GCD of two numbers also divides their difference.**
Thus, $GCD(A, B) = GCD(A - B, B)$ assuming $A > B$.

Instead of repeatedly subtracting $B$ from $A$ (which could take a long time if $A$ is massive and $B$ is tiny), we can use the modulo operator `%` to get the remainder of $A$ divided by $B$. 

The optimized formula is:
$GCD(A, B) = GCD(B, A \% B)$

We continue this process recursively or iteratively until the remainder ($A \% B$) becomes $0$. When $B$ becomes $0$, the non-zero number $A$ is our GCD!

# Code Implementation

The Euclidean algorithm is famous for being incredibly concise. It is usually written recursively.

<CodeBlock
  cpp="// C++ Implementation
#include <iostream>
using namespace std;

// Recursive Euclidean Algorithm
int gcd(int a, int b) {
    if (b == 0) {
        return a;
    }
    return gcd(b, a % b);
}

// Iterative Euclidean Algorithm
int gcdIterative(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}"
  java="// Java Implementation
class MathUtils {
    // Recursive Euclidean Algorithm
    public static int gcd(int a, int b) {
        if (b == 0) {

        }

    }
    
    // Iterative Euclidean Algorithm
    public static int gcdIterative(int a, int b) {

            a = temp;
        }

def gcd(a, b):
    if b == 0:
        return a
    return gcd(b, a % b)

def gcd_iterative(a, b):
    while b != 0:
        a, b = b, a % b

# Common Pitfalls

<Warning>
- **Swapping A and B**: You do *not* need to ensure that $A > B$ before calling `gcd(A, B)`. If $A < B$, the first recursive call `gcd(B, A % B)` will naturally swap them because $A \% B$ will just be $A$!
- **Negative Numbers**: The GCD of negative numbers is mathematically positive. If inputs can be negative, take their absolute values before calling the `gcd` function: `gcd(abs(a), abs(b))`.
</Warning>
