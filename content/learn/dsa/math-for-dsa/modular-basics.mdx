# Theory & Concepts

In Competitive Programming and advanced DSA, you will frequently encounter problems that ask you to "return the answer modulo $10^9 + 7$".

Why? Because the answer could be incredibly large (e.g., $100!$ or $2^{100}$), which cannot fit inside a standard 32-bit or even 64-bit integer. By applying a modulo operation at each step, we keep the numbers small enough to fit in standard data types while preserving mathematical correctness.

### The Modulo Operator (%)
The modulo operator returns the remainder of a division. For example, $17 \pmod 5 = 2$.

### Core Properties

To prevent overflow, we apply the modulo operator during intermediate calculations, not just at the very end. The following mathematical properties allow us to do this safely:

Let $M = 10^9 + 7$.

1. **Modular Addition**:
   $(A + B) \pmod M = ((A \pmod M) + (B \pmod M)) \pmod M$

2. **Modular Multiplication**:
   $(A \times B) \pmod M = ((A \pmod M) \times (B \pmod M)) \pmod M$

3. **Modular Subtraction**:
   Subtraction is tricky because in many programming languages (like C++ and Java), the `%` operator can return a negative number! For example, `-5 % 3` returns `-2` in C++, but mathematically we want `1`.
   To fix this, we always add $M$ before applying the final modulo:
   $(A - B) \pmod M = ((A \pmod M) - (B \pmod M) + M) \pmod M$

*(Note: There is NO simple property for modular division. We cannot just do $(A / B) \pmod M$. That requires the Modular Multiplicative Inverse, which we will cover soon!)*

# Code Implementation

Here is how you safely implement modular arithmetic operations in code.

<CodeBlock
  cpp="// C++ Implementation
#include <iostream>
using namespace std;

const int M = 1e9 + 7;

long long add(long long a, long long b) {
    return ((a % M) + (b % M)) % M;
}

long long multiply(long long a, long long b) {
    return ((a % M) * (b % M)) % M;
}

long long subtract(long long a, long long b) {
    // Add M to handle negative numbers in C++
    return ((a % M) - (b % M) + M) % M;
}"
  java="// Java Implementation
class MathUtils {
    static final int M = 1000000007;
    
    public static long add(long a, long b) {
        return ((a % M) + (b % M)) % M;
    }
    
    public static long multiply(long a, long b) {
        return ((a % M) * (b % M)) % M;
    }
    
    public static long subtract(long a, long b) {
        // Add M to handle negative numbers in Java
        return ((a % M) - (b % M) + M) % M;
    }
}"
  python="# Python Implementation
# In Python, the % operator always returns a non-negative result!
# Also, Python handles arbitrarily large integers automatically,
# so overflow isn't an issue, but taking modulo keeps things fast.

M = 10**9 + 7

def add(a, b):
    return (a + b) % M

def multiply(a, b):
    return (a * b) % M

def subtract(a, b):
    return (a - b) % M"

# Common Pitfalls

<Warning>
- **Overflow During Multiplication**: Even if you apply modulo, the intermediate step `(a % M) * (b % M)` can still overflow a 32-bit integer if $M = 10^9 + 7$. The maximum value would be $\approx 10^{18}$, which requires a 64-bit integer (`long long` in C++, `long` in Java). Always cast to a 64-bit integer before multiplying!
- **Negative Modulo in C++/Java**: As mentioned, `(-2) % 5` gives `-2` in C++/Java. Always use `(val % M + M) % M` when dealing with subtraction or negative numbers.
</Warning>
