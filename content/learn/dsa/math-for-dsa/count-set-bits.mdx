# Theory & Concepts
Counting the number of set bits (1s) in the binary representation of an integer is a frequent sub-problem in algorithmic challenges. The naive way to do this is to continuously shift the number to the right and check if the least significant bit is 1. That takes $O(\log n)$ operations, where $\log n$ is the number of bits.

### Brian Kernighan's Algorithm
Brian Kernighan's Algorithm offers a brilliant optimization. It relies on a simple yet powerful bitwise observation:
**Subtracting $1$ from a binary number flips all the bits after the rightmost set bit, including the rightmost set bit itself.**

Therefore, if we evaluate `n & (n - 1)`, it effectively **turns off the rightmost set bit** of `n`.
By doing this repeatedly in a loop and counting how many times we can do it before `n` becomes $0$, we get the exact number of set bits.

# Code Implementation
<CodeBlock
  cpp={`// C++ implementation for Brian Kernighan's Algorithm
class Solution {
public:
    int countSetBits(int n) {
        int count = 0;
        while (n != 0) {
            n = n & (n - 1); // Turn off rightmost set bit
            count++;
        }
        return count;
    }
};`}

# Common Pitfalls
<Warning>
- **Negative Numbers:** In languages like Java or C++, negative integers are stored in Two's Complement. If `n` is negative, a simple right-shift might loop infinitely unless using logical shift. Brian Kernighan's algorithm handles negative numbers gracefully as long as you loop until `n == 0`.
- **Python's Infinite Precision:** Python integers have arbitrary precision. If you are simulating a 32-bit integer, you must explicitly mask the number with `n & 0xFFFFFFFF` before applying the algorithm.
</Warning>
