# Theory & Concepts

As we learned in the Modular Basics lesson, addition, subtraction, and multiplication have simple modular properties. But what about division?

You **CANNOT** simply do: 
$(A / B) \pmod M = ((A \pmod M) / (B \pmod M)) \pmod M$. 
This is mathematically incorrect.

Instead of dividing by $B$, we must multiply by the **Modular Multiplicative Inverse** of $B$. 
The modular inverse of $B$ under modulo $M$ is defined as an integer $B^{-1}$ such that:
$(B \times B^{-1}) \equiv 1 \pmod M$

Once we find $B^{-1}$, we can perform our division like this:
$(A / B) \pmod M = (A \times B^{-1}) \pmod M$

### How do we find the Modular Inverse?
There are two main ways to find it: the Extended Euclidean Algorithm, and Fermat's Little Theorem. In modern competitive programming, Fermat's Little Theorem is far more popular because it is easier to implement.

### Fermat's Little Theorem
Fermat's Little Theorem states that if $M$ is a prime number, and $B$ is not divisible by $M$, then:
$B^{M-1} \equiv 1 \pmod M$

If we divide both sides by $B$, we get:
$B^{M-2} \equiv B^{-1} \pmod M$

This is an incredible revelation! It means that the modular inverse of $B$ is simply $B^{M-2} \pmod M$.
And since we just learned Binary Exponentiation, we can compute $B^{M-2} \pmod M$ in $O(\log M)$ time!

# Code Implementation

Here is how you compute the modular inverse and use it for division.

<CodeBlock
  cpp="// C++ Implementation
#include <iostream>
using namespace std;

// 1. Binary Exponentiation Helper
long long power(long long base, long long exp, long long mod) {
    long long res = 1;
    base = base % mod;
    while (exp > 0) {
        if (exp % 2 == 1) res = (res * base) % mod;
        base = (base * base) % mod;
        exp /= 2;
    }
    return res;
}

// 2. Find Modular Inverse using Fermat's Little Theorem
long long modInverse(long long b, long long m) {
    // Inverse is b^(m-2) % m
    return power(b, m - 2, m);
}

// 3. Modular Division: (A / B) % M
long long modDivide(long long a, long long b, long long m) {
    long long inverse = modInverse(b, m);
    return ((a % m) * inverse) % m;
}"

# Common Pitfalls

<Warning>
- **Prime Modulo Requirement**: Fermat's Little Theorem *only* works if the modulo $M$ is a prime number (like $10^9 + 7$). If $M$ is not prime, you MUST use the Extended Euclidean Algorithm to find the inverse.
- **Divisibility Check**: If $B$ is a multiple of $M$, the modular inverse does not exist! Always ensure $B \% M \neq 0$.
</Warning>
