# Theory & Concepts

The **Pigeonhole Principle** is one of the most intuitive concepts in mathematics, yet it forms the theoretical foundation for many optimal algorithms.

### The Principle
If you have $N$ pigeonholes and $N + 1$ (or more) pigeons, and you want to place all pigeons into the holes, then **at least one hole must contain more than one pigeon**.

More formally: If you distribute $K$ items into $N$ containers, and $K > N$, then at least one container must contain strictly more than one item.

### Generalizing the Principle
If $K$ items are put into $N$ containers, then at least one container must contain at least $\lceil K / N \rceil$ items.

### Applications in DSA
While you won't write an algorithm called "Pigeonhole", you will use this logic to prove that a certain edge-case must exist, allowing you to optimize your search.

1. **Find the Duplicate Number**: Given an array of $N+1$ integers where each integer is in the range $[1, N]$. Since there are $N$ possible distinct numbers (holes) and $N+1$ elements (pigeons), by the Pigeonhole Principle, there **must** exist at least one duplicate number!
2. **Subarray Sum Divisible by K**: Given an array of $N$ elements, there always exists a contiguous subarray whose sum is divisible by $N$. Why? Because if you compute the prefix sums modulo $N$, there are $N$ possible remainders (from $0$ to $N-1$). If you compute $N+1$ prefix sums (including the empty prefix), at least two prefix sums must have the same remainder. When two prefix sums have the same remainder, the subarray between them is divisible by $N$!

# Code Implementation

Let's look at the "Find the Duplicate Number" problem. Because we mathematically proved a duplicate *must* exist, we can use Floyd's Cycle Detection (Tortoise and Hare) algorithm to find it without modifying the array!

<CodeBlock
  cpp="// C++ Implementation (Find the Duplicate Number)
#include <iostream>
#include <vector>
using namespace std;

// Because of the Pigeonhole Principle, a duplicate is guaranteed.
int findDuplicate(vector<int>& nums) {
    int slow = nums[0];
    int fast = nums[nums[0]];
    
    // Phase 1: Find the intersection point
    while (slow != fast) {
        slow = nums[slow];
        fast = nums[nums[fast]];
    }
    
    // Phase 2: Find the entrance to the cycle (the duplicate)
    slow = 0;
    while (slow != fast) {
        slow = nums[slow];
        fast = nums[fast];
    }
    
    return slow;
}"

# Common Pitfalls

<Warning>
- **Misidentifying the Range**: The Pigeonhole Principle only applies if the range of distinct possible items (holes) is strictly less than the total number of items (pigeons). If the array has $N$ elements in the range $[1, N]$, a duplicate is NOT guaranteed.
</Warning>
