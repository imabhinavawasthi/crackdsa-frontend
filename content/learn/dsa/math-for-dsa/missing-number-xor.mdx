# Theory & Concepts
The "Missing Number" problem is a classic algorithmic interview question. You are given an array containing $n$ distinct numbers taken from $0, 1, 2, \dots, n$. One number is missing. Your task is to find it.

While this can be solved using the math formula for the sum of the first $n$ natural numbers ($S = \frac{n(n+1)}{2}$), that approach is susceptible to **integer overflow** if $n$ is very large. 

### The XOR Approach
A more robust and elegant approach uses the **XOR** operator. Recall two fundamental properties of XOR (`^`):
1. **Self-Inverse:** $x \oplus x = 0$ (Any number XORed with itself is 0).
2. **Identity:** $x \oplus 0 = x$ (Any number XORed with 0 remains unchanged).

If we XOR all numbers from $0$ to $n$, and then XOR that result with all the elements present in the array, every number that appears in both the array and the full range $[0, n]$ will be XORed with itself, cancelling out to $0$. The only number left will be the missing one!

# Code Implementation
<CodeBlock
  cpp={`// C++ implementation for Find Missing Number (XOR)
#include <vector>
using namespace std;

class Solution {
public:
    int missingNumber(vector<int>& nums) {
        int missing = nums.size(); // Start with n
        for (int i = 0; i < nums.size(); i++) {
            missing ^= i ^ nums[i]; // XOR index and value
        }
        return missing;
    }
};`}
  java={`// Java implementation for Find Missing Number (XOR)
class Solution {
    public int missingNumber(int[] nums) {
        int missing = nums.length; // Start with n
        for (int i = 0; i < nums.length; i++) {
            missing ^= i ^ nums[i]; // XOR index and value
        }
        return missing;
    }
}`}
  python={`# Python implementation for Find Missing Number (XOR)
from typing import List

class Solution:
    def missingNumber(self, nums: List[int]) -> int:
        missing = len(nums) # Start with n
        for i, num in enumerate(nums):
            missing ^= i ^ num # XOR index and value
        return missing`}

# Common Pitfalls
<Warning>
- **Initialization:** Remember to initialize the `missing` variable with n (the length of the array), because the loop indices only go up to n-1.
- **Off-by-One Errors:** Misunderstanding the range boundaries. The numbers are in the range [0, n], which means there are n+1 possible numbers, but the array length is n.
</Warning>
