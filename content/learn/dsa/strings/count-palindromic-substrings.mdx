# Theory & Concepts
Welcome to the lesson on **Palindromic Substrings (Count)**. This topic is a cornerstone of the Strings module. Strings are essentially arrays of characters, but their immutability in many languages (like Java and Python) introduces unique performance challenges that interviewers love to test.

### Core Intuition
The primary goal is to perform operations without creating unnecessary intermediate strings. By using character frequency arrays (size 26), two-pointer techniques, or string builder classes, we can optimize space and time drastically.

# Common Pitfalls
<Warning>
- **String Concatenation in Loops:** Doing `s += "a"` inside a loop in Java or Python creates a new string every time, leading to O(N^2) time complexity. Use `StringBuilder` (Java) or `.join()` (Python).
- **Index Out of Bounds:** Forgetting to check `i < s.length()` when peeking at the next character.
</Warning>
