# Theory & Concepts
Manipulating strings frequently requires basic operations like taking substrings, concatenation, and splitting strings by a delimiter. While these functions are heavily abstracted by standard libraries, understanding their computational costs is vital.

**Substring:**
Creating a substring involves copying a section of the characters into a new string. Thus, if you extract a substring of length $K$, the operation takes $O(K)$ time and $O(K)$ space. Repeatedly creating substrings in a loop can easily push your algorithm into $O(N^2)$ or $O(N^3)$ complexity. A standard optimization is to avoid substrings entirely and simply pass indices (e.g., a `start` and `end` pointer) through your helper functions.

**Concatenation:**
Combining two strings $S_1$ and $S_2$ takes $O(|S_1| + |S_2|)$ time because both sets of characters must be copied to a new memory block (except when appending to a mutable string with enough capacity). 

**Splitting:**
Splitting a string by a delimiter requires iterating through the entire string to identify delimiters and subsequently copying each token into an array. This is an $O(N)$ operation in both time and space.

# Common Pitfalls
<Warning>
- Extracting substrings inside a recursive function or loop, significantly degrading performance. Pass index pointers (`int start`, `int end`) instead.
- Using `.split()` on very large strings when you only need to process tokens sequentially. Consider using a scanner or iterating character by character.
</Warning>
