# Theory & Concepts
The problem of finding the **First Unique Character** in a string requires us to identify the first character in a sequence that appears exactly once, and return its index. If no such character exists, return `-1`.

Since we must know the total frequency of each character before making our final determination, a single pass over the string is insufficient. 

**Two-Pass Array Approach:**
1. **Pass 1:** Iterate through the string and count the frequency of each character using an array of size 26 (since inputs are typically lowercase English letters).
2. **Pass 2:** Iterate through the string a second time. The first character you encounter that has a frequency of 1 in the array is your answer.

This guarantees an $O(N)$ time complexity and an $O(1)$ space requirement.

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    int firstUniqChar(string s) {
        vector<int> counts(26, 0);
        
        // Pass 1: count frequencies
        for (char c : s) {
            counts[c - 'a']++;
        }
        
        // Pass 2: find first character with frequency 1
        for (int i = 0; i < s.length(); i++) {
            if (counts[s[i] - 'a'] == 1) {
                return i;
            }
        }
        
        return -1;
    }
};"
  java="class Solution {
    public int firstUniqChar(String s) {
        int[] counts = new int[26];

        for (int i = 0; i < s.length(); i++) {
            counts[s.charAt(i) - 'a']++;
        }

        for (int i = 0; i < s.length(); i++) {
            if (counts[s.charAt(i) - 'a'] == 1) {
                return i;
            }
        }
        
        return -1;
    }
}"
  python="class Solution:
    def firstUniqChar(self, s: str) -> int:
        counts = [0] * 26
        
        # Pass 1: count frequencies
        for char in s:
            counts[ord(char) - ord('a')] += 1
            
        # Pass 2: find first character with frequency 1
        for i in range(len(s)):
            if counts[ord(s[i]) - ord('a')] == 1:

# Common Pitfalls
<Warning>
- Returning the *character* instead of its *index*. Pay close attention to the return type required by the problem statement.
- Iterating through the Hash Map or frequency array in the second pass instead of the string. You must iterate through the original string to maintain the original sequence of characters!
</Warning>
