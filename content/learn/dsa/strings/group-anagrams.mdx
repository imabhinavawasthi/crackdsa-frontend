# Theory & Concepts
The **Group Anagrams** problem asks you to take an array of strings and group the anagrams together. For example, given `["eat","tea","tan","ate","nat","bat"]`, the output should be groups like `[["bat"],["nat","tan"],["ate","eat","tea"]]`.

**The Intuition:**
We need a way to uniquely identify any group of anagrams. A unique identifier (or key) is required for each group so we can cluster strings together using a Hash Map. 

**Approach 1: Sorted String as Key**
If we sort each string, all anagrams evaluate to the exact same sorted string. For example, "eat", "tea", and "ate" all sort to "aet". We can use "aet" as a key in our Hash Map, pointing to a list of original strings.
Time complexity: $O(N \cdot K \log K)$ where $N$ is the number of strings and $K$ is the max length of a string.

**Approach 2: Frequency Array as Key (Optimal)**
Instead of sorting, we can generate a character count array of size 26 for each string, convert this array into a string representation (e.g., "1#0#0..."), and use that as our Hash Map key.
Time complexity: $O(N \cdot K)$.

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> map;
        for (const string& s : strs) {
            string key = s;
            sort(key.begin(), key.end());
            map[key].push_back(s);
        }
        
        vector<vector<string>> result;
        for (auto& pair : map) {
            result.push_back(pair.second);
        }
        return result;
    }
};"
  java="class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            char[] chars = s.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);
            
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}"
  python="from collections import defaultdict

class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        anagram_map = defaultdict(list)
        for s in strs:
            # Optimal O(N*K) approach using tuple of counts as key
            counts = [0] * 26
            for char in s:
                counts[ord(char) - ord('a')] += 1
            anagram_map[tuple(counts)].append(s)
            
        return list(anagram_map.values())"

# Common Pitfalls
<Warning>
- Using array objects directly as dictionary keys. Arrays/lists are usually mutable and unhashable; you must convert them to an immutable form (like a `String` in Java or a `tuple` in Python).
- Concatenating frequency counts without delimiters (e.g., `11` could mean 1 'a' and 1 'b', or 11 'a's). Always use a delimiter if building a string key manually.
</Warning>
