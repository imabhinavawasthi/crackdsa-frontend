# Theory & Concepts
An **anagram** is a word or phrase formed by rearranging the letters of a different word or phrase, using all the original letters exactly once. For example, "listen" and "silent" are anagrams.

To determine if two strings $S$ and $T$ are anagrams, they must satisfy two conditions:
1. They must be of the same length.
2. The frequency of each character must be identical in both strings.

**Approach 1: Sorting**
If we sort the characters in both strings, identical anagrams will result in exactly the same string. This takes $O(N \log N)$ time and typically $O(N)$ or $O(1)$ space depending on the language's sorting implementation.

**Approach 2: Character Frequency Array (Optimal)**
Since English letters only span 26 characters, we can use an integer array of size 26 to count the occurrences of each letter. We increment the count for letters in $S$ and decrement for letters in $T$. Finally, we check if all elements in the frequency array are zero. This achieves optimal $O(N)$ time and $O(1)$ space complexity.

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    bool isAnagram(string s, string t) {
        if (s.length() != t.length()) return false;
        
        vector<int> counts(26, 0);
        for (int i = 0; i < s.length(); i++) {
            counts[s[i] - 'a']++;
            counts[t[i] - 'a']--;
        }
        
        for (int count : counts) {
            if (count != 0) return false;
        }
        
        return true;
    }
};"

    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t): return False
        
        counts = [0] * 26
        for i in range(len(s)):
            counts[ord(s[i]) - ord('a')] += 1
            counts[ord(t[i]) - ord('a')] -= 1
            
        for count in counts:
            if count != 0: return False

# Common Pitfalls
<Warning>
- Using a Hash Map instead of an array. While mathematically $O(1)$ space, Hash Maps carry a larger memory and hashing overhead compared to a primitive array.
- Forgetting to check if the string lengths match at the very beginning—an easy edge case to catch early.
</Warning>
