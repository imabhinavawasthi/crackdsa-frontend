# Theory & Concepts
The **Knuth-Morris-Pratt (KMP)** algorithm is a powerful string searching algorithm that achieves linear time complexity $O(N + M)$ for pattern matching. Unlike the naive approach which re-evaluates characters upon a mismatch, KMP leverages a precomputed array to skip unnecessary comparisons.

The core of KMP is the **LPS (Longest Proper Prefix which is also Suffix)** array. This array tells us how much of the pattern we have already matched, allowing us to safely skip backwards when a mismatch occurs without retreating our main text pointer.

For example, if we are searching for `"ABABCABAB"` and a mismatch happens at the last `'B'`, the LPS array tells us that the prefix `"ABAB"` is already matched as a suffix, so we can shift our pattern pointer to the end of `"ABAB"` instead of going all the way back to the beginning.

# Common Pitfalls
<Warning>
- **LPS Construction Mismatch:** The logic `len = lps[len - 1]` inside the LPS construction loop is tricky. Novices often reset `len` to 0, which breaks the algorithm. Remember that we want to fall back to the previous longest valid prefix.
- **Pointer Management:** Ensure the text pointer `i` never moves backwards during the search phase. This is the entire point of the KMP algorithm.
</Warning>
