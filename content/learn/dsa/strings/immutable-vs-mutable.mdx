# Theory & Concepts
The distinction between mutable and immutable strings is one of the most critical concepts for optimizing string algorithms. 

**Immutable Strings** (e.g., Python, Java, JavaScript, C#):
When a string is immutable, it cannot be changed once it is created in memory. Any operation that modifies the string—such as appending a character, changing a substring, or converting cases—creates a completely new string object. This means an operation like `s += "a"` takes $O(N)$ time, where $N$ is the length of the string, because the entire string must be copied.

**Mutable Strings** (e.g., C++, Ruby, Rust's `String`):
Mutable strings are implemented essentially as dynamic arrays of characters. You can modify characters in-place (`s[i] = 'x'`) and append to the end (`s.push_back('a')`) in $O(1)$ amortized time.

To efficiently construct strings in languages where they are immutable, you must use dynamic character arrays or specialized classes (like `StringBuilder` in Java or joining arrays in Python) which allow appending characters in $O(1)$ time and finally building the string in $O(N)$ time.

    string buildString(const vector<string>& words) {
        // C++ strings are mutable. Appending is O(1) amortized.
        string result = \"\";
        for (const string& word : words) {
            result += word; 
        }
        return result;
    }
};"
  java="class Solution {
    public String buildString(String[] words) {
        // Java Strings are immutable. We must use StringBuilder.
        StringBuilder sb = new StringBuilder();
        for (String word : words) {
            sb.append(word);
        }
        return sb.toString(); // O(N) where N is total length
    }
}"
  python="class Solution:
    def build_string(self, words: list[str]) -> str:
        # Python Strings are immutable. Append to list and use join().
        result_list = []
        for word in words:
            result_list.append(word)
        return ''.join(result_list) # O(N) total time"

# Common Pitfalls
<Warning>
- Using `+=` to concatenate strings inside a loop in Java or Python. This leads to accidental $O(N^2)$ time complexity and often results in Time Limit Exceeded (TLE).
- Unnecessary conversions: Continuously flipping between string builders and strings inside loops rather than delaying the `.toString()` call until the very end.
</Warning>
