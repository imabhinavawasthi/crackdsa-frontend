# Theory & Concepts
A **Graph** is a non-linear data structure consisting of **vertices** (or nodes) and **edges** that connect these vertices. Graphs are used to model real-world relationships such as social networks, computer networks, and road maps.

Graphs can be categorized into several types:
- **Directed Graph (Digraph):** Edges have a direction, meaning the relationship is one-way.
- **Undirected Graph:** Edges do not have a direction, meaning the relationship is two-way.
- **Weighted Graph:** Edges have weights or costs associated with them.
- **Unweighted Graph:** Edges do not have weights.

Two primary ways to represent a graph in memory are:
1. **Adjacency Matrix:** A 2D array where `matrix[i][j]` is 1 if there is an edge from vertex `i` to vertex `j`, and 0 otherwise.
2. **Adjacency List:** An array of lists where `adj[i]` contains a list of all vertices adjacent to vertex `i`.

# Common Pitfalls
<Warning>
- Confusing 0-indexed and 1-indexed nodes when building the graph, leading to out-of-bounds exceptions.
- Forgetting to add the reverse edge `v -> u` for an undirected graph.
- Assuming an adjacency matrix is always optimal. For sparse graphs, it wastes `O(V^2)` memory.
</Warning>
