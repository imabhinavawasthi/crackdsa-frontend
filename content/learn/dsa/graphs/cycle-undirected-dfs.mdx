# Theory & Concepts
Just like with BFS, detecting a cycle in an undirected graph can be achieved cleanly using Depth First Search (DFS).

The logic remains identical: if we visit a node and encounter an adjacent node that is **already visited**, and that adjacent node is **not the parent** of the current node, then a cycle exists.

### Why DFS?
Many candidates find the DFS implementation much shorter and slightly easier to write than BFS because it utilizes the call stack implicitly rather than requiring an explicit Queue to store `(node, parent)` pairs. We simply pass the `parent` as an argument to our recursive function.

# Common Pitfalls
<Warning>
- Forgetting to return `true` immediately when the recursive call returns `true`. If you forget the `if (detectCycleDFS(...)) return true;` check, the cycle will be ignored.
- Accidentally checking for cycles in Directed graphs using this logic. Directed graphs require tracking the recursion stack, not just the parent.
</Warning>
