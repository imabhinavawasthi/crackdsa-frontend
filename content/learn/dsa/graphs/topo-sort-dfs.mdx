# Theory & Concepts
While Kahn's Algorithm uses BFS to find a **Topological Sort**, we can also achieve this elegantly using **Depth First Search (DFS)**. 

A Topological Sort is a linear ordering of vertices in a Directed Acyclic Graph (DAG) such that for every directed edge `u -> v`, vertex `u` comes before `v` in the ordering. 

### Core Intuition
The DFS approach to topological sorting hinges on the concept of finishing times. When we run a DFS from a node `u`, we only finish the DFS call for `u` (i.e., return from the recursive function) **after** all of `u`'s descendants have been completely processed.
- This means that when a node is finished processing, all nodes that depend on it (or can be reached from it) have already been processed.
- Therefore, if we push a node onto a **stack** exactly when its DFS call finishes, the node at the top of the stack will be the one with the fewest dependencies.
- Popping all elements from the stack gives us a valid topological sort.

# Common Pitfalls
<Warning>
- **Pushing too early:** A classic mistake is pushing the node into the stack *before* visiting its neighbors. It MUST be pushed *after* the `for` loop completes.
- **Handling components:** Remember to use a loop over all vertices to initiate the DFS, as the graph might have multiple disconnected components.
</Warning>
