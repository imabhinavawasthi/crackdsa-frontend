# Theory & Concepts
An **Adjacency Matrix** is a 2D array of size `V x V` (where `V` is the number of vertices) used to represent a finite graph. 

- `matrix[i][j] = 1` indicates an edge exists from vertex `i` to vertex `j`.
- `matrix[i][j] = 0` indicates no edge exists.
- In a weighted graph, `matrix[i][j] = weight` if an edge exists, and a special value (like `infinity` or `0`) otherwise.

### Pros and Cons
**Pros:**
- Checking if an edge exists between two vertices `u` and `v` is `O(1)`.
- Easy to implement and understand.
- Useful for dense graphs where `E` is close to `V^2`.

**Cons:**
- Consumes `O(V^2)` space, which is highly inefficient for sparse graphs.
- Iterating over all neighbors of a vertex takes `O(V)` time.

# Common Pitfalls
<Warning>
- Using an adjacency matrix for very large graphs (e.g., `V > 10000`). This will cause a Memory Limit Exceeded (MLE) error since `10^8` integers take ~400MB of RAM.
- Forgetting to handle `u == v` (self-loops) correctly if they are not allowed.
</Warning>
