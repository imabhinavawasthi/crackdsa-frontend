# Theory & Concepts
Depth First Search (DFS) is a fundamental graph traversal algorithm that explores as far as possible along each branch before backtracking. It dives deep into a graph, reaching the "leaves" or dead ends before exploring siblings.

DFS can be implemented iteratively using a **Stack** or recursively using the **call stack**. The recursive approach is universally preferred due to its elegance and simplicity.

### The Core Recursive Mechanics
1. Mark the current node `u` as visited.
2. For each unvisited neighbor `v` of `u`:
    - Recursively call DFS on `v`.

Because DFS explores paths until they exhaust, it's the perfect algorithm for detecting cycles, finding connected components, and solving mazes.

# Common Pitfalls
<Warning>
- **Stack Overflow:** On graphs with massive depths (e.g., a straight line of 100,000 nodes), recursion can exceed the maximum call stack limit. Iterative DFS might be necessary.
- Forgetting to handle disconnected graphs by using a loop to initiate DFS on any unvisited node.
</Warning>
