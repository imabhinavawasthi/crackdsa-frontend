# Theory & Concepts
Finding the shortest path in a weighted Directed Acyclic Graph (DAG) can be done efficiently in **`O(V + E)`** time, which is significantly faster than Dijkstra's algorithm `O((V + E) log V)`.

The secret weapon here is **Topological Sorting**. Because the graph is a DAG, we can linearly order the vertices such that for every directed edge `u -> v`, `u` appears before `v`.

### Core Intuition
- If we process nodes in Topological Order, we are guaranteed that by the time we process a node, all possible paths to it have already been evaluated.
- Step 1: Perform a DFS to find the Topological Sort of the graph and store it in a stack.
- Step 2: Initialize a `dist` array with infinity, and set the distance of the source node to `0`.
- Step 3: Pop nodes one by one from the stack. For each node, if it has been reached (`dist[node] != infinity`), iterate through its adjacent edges and relax them: `if (dist[node] + weight < dist[adjNode])` then `dist[adjNode] = dist[node] + weight`.

# Common Pitfalls
<Warning>
- **Graph Type:** This algorithm ONLY works if the graph is a Directed Acyclic Graph (DAG). Do not use this if cycles might be present.
- **Handling Unreachable Nodes:** Ensure you only relax edges of nodes that have already been reached (`dist[node] != infinity`), otherwise you might compute paths relative to infinity.
</Warning>
