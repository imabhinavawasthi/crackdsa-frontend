# Theory & Concepts
Kahn's Algorithm is primarily used to find the **Topological Sorting** of a Directed Acyclic Graph (DAG). However, it has an incredibly powerful side effect: **it can detect cycles in a directed graph**.

The fundamental property of a valid Topological Sort is that it can only exist if the graph is a DAG (Directed Acyclic Graph). This means if the graph contains even a single cycle, a complete topological sort is impossible.

### Core Intuition
- In Kahn's Algorithm, we process nodes that have an in-degree of `0` (no incoming edges).
- When a node is processed, we remove its outgoing edges, which reduces the in-degree of its neighbors.
- If a cycle exists, the nodes forming the cycle will never reach an in-degree of `0` because they constantly depend on each other.
- Therefore, they will never be pushed into the queue and will never be added to our topological sort array.
- **The check is simple:** If the number of elements in our generated topological sort array is strictly less than the total number of vertices `V`, then a cycle must exist!

# Common Pitfalls
<Warning>
- **Wrong Return Condition:** Ensure you return `count != V` for detecting a cycle. If `count == V`, it means a valid topo sort was found and there is NO cycle.
- **Forgetting to count:** It is easier to maintain a `count` variable rather than building the entire array and checking its length, saving a bit of memory overhead.
</Warning>
