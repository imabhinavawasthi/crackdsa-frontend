# Theory & Concepts
**Topological Sorting** is a linear ordering of vertices in a Directed Acyclic Graph (DAG) such that for every directed edge `u -> v`, vertex `u` comes before `v` in the ordering. This is widely used in scheduling tasks, resolving dependencies, and course prerequisites.

**Kahn's Algorithm** is a Breadth-First Search (BFS) approach to finding the topological sort of a DAG. It relies heavily on the concept of **In-Degree**. The in-degree of a node is the number of edges coming into it.

### Core Intuition
- If a node has an in-degree of `0`, it has no prerequisites (no edges pointing to it). It can be safely processed first.
- We start by computing the in-degree for all vertices.
- Push all vertices with an in-degree of `0` into a queue.
- Pop a node from the queue, add it to the topological sort result.
- Reduce the in-degree of all its adjacent nodes by `1` (simulating the removal of the processed node and its outgoing edges).
- If the in-degree of any adjacent node becomes `0`, push it into the queue.
- Repeat until the queue is empty.

# Common Pitfalls
<Warning>
- **Graph with Cycles:** Kahn's algorithm will fail to produce a complete topological sort if the graph contains a cycle. The algorithm will terminate before processing all nodes (the output list size will be less than V).
- **Ignoring Indegrees:** Not calculating indegrees correctly initially will break the entire algorithm.
</Warning>
