# Common Pitfalls
<Warning>
- **Visited Array:** Forgetting to mark a node as visited can lead to infinite loops.
- **Disconnected Graphs:** Failing to wrap your traversal in an outer loop that checks all components (e.g., `for i in range(V): if not visited[i]: traverse(i)`).
</Warning>
