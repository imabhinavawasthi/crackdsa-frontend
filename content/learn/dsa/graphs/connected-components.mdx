# Theory & Concepts
A **Connected Component** in an undirected graph is a subgraph in which every two vertices are connected to each other by paths, and which is connected to no additional vertices in the supergraph.

The problem "Number of Provinces" asks us to count the total number of connected components in a given graph.

### The Algorithm
The strategy is simple:
1. Maintain a `visited` array initialized to `false` for all vertices.
2. Iterate through every vertex `i` from `0` to `V-1`.
3. If vertex `i` is not `visited`, it means we have found a new, unexplored component. We increment our `provinces` counter.
4. We then call DFS or BFS starting from `i` to mark all other vertices in this component as `visited`.

# Common Pitfalls
<Warning>
- In LeetCode (e.g. Problem 547: Number of Provinces), the input is often given as an Adjacency Matrix rather than an Adjacency List. You must either convert it or modify the DFS to traverse an Adjacency Matrix (`if matrix[u][v] == 1 and not visited[v]`).
- Forgetting to pass the `visited` array by reference in C++, leading to infinite loops or incorrect province counts.
</Warning>
