# Theory & Concepts
Breadth First Search (BFS) is a fundamental graph traversal algorithm. It starts exploring from a designated source node and visits all its immediate neighbors first (Layer 1), then explores all neighbors of those nodes (Layer 2), and so on. It spreads outward in concentric wave-like structures.

### The Core FIFO Queue Mechanics
To implement BFS, we use a FIFO Queue to track which nodes are waiting to be explored, along with a `visited` boolean set to ensure we never process a single graph node twice:

1.  Enqueue the source node and mark it as visited.
2.  While the Queue is not empty:
    - Dequeue the front node `u`.
    - For each unvisited neighbor `v` of `u`:
        - Mark `v` as visited.
        - Enqueue `v` into the queue.

Queue: [ 3, 4 ]      -> Dequeue 3. Has no unvisited neighbors.

from collections import deque

def bfs_traversal(start_node, adj_list):
    visited = [False] * len(adj_list)
    queue = deque([start_node])
    visited[start_node] = True
    
    bfs_order = []
    while queue:
        u = queue.popleft() # Dequeue front
        bfs_order.append(u)
        
        for v in adj_list[u]:
            if not visited[v]:
                visited[v] = True
                queue.append(v)
    return bfs_order

# Common Pitfalls
<Warning>
- Forgetting to mark a node as visited at the exact moment it is enqueued. If you mark it visited only when dequeued, the same node will be enqueued multiple times!
- Using BFS for weighted shortest paths. BFS only guarantees shortest path when all edges have an identical weight of 1.
</Warning>
