# Theory & Concepts
The Unbounded Knapsack problem is a variation of the traditional 0/1 Knapsack. The setup is identical: you have `N` items with weights and values, and a knapsack of capacity `W`. However, you are allowed to select each item an unlimited number of times.

### Core Intuition
Since an item can be picked multiple times, after deciding to include an item, we **do not** move to the next item immediately. We stay on the same item, allowing it to be chosen again. 
The recurrence relation reflects this:
- **Include**: `val[i] + dp(i, W - wt[i])` (notice we don't do `i-1` here)
- **Exclude**: `dp(i-1, W)`

When traversing for the 1D space optimized DP, you iterate forwards in the inner loop, rather than backwards as in 0/1 Knapsack. This naturally allows previous selections of the current item to influence subsequent capacities in the same row.

# Code Implementation
<CodeBlock
  cpp="class Solution {
public:
    int unboundedKnapsack(int W, vector<int>& wt, vector<int>& val, int n) {
        vector<int> dp(W + 1, 0);
        
        for (int i = 0; i < n; i++) {
            for (int w = wt[i]; w <= W; w++) {
                dp[w] = max(dp[w], dp[w - wt[i]] + val[i]);
            }
        }
        return dp[W];
    }
};"

# Common Pitfalls
<Warning>
- Traversing the weight array backwards when using 1D DP. Backwards traversal is for 0/1 Knapsack to avoid reusing items; forward traversal is required here!
- Forgetting to handle items whose weight is greater than the total capacity.
</Warning>
