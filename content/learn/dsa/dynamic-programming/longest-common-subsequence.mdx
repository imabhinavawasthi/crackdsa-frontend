# Theory & Concepts
The **Longest Common Subsequence (LCS)** problem requires finding the longest subsequence common to two sequences. A subsequence is a sequence that can be derived from another sequence by deleting some or no elements without changing the order of the remaining elements.

### Core Intuition
We compare the two strings character by character, typically starting from the end or beginning.
Let our strings be `text1` of length `n` and `text2` of length `m`.
- **Match**: If `text1[i] == text2[j]`, then this character must be part of the LCS. We add 1 to the result of the remaining strings: `1 + dp(i-1, j-1)`.
- **Mismatch**: If they don't match, the longest common subsequence could either skip the character in `text1` or skip the character in `text2`. We take the maximum of these two paths: `max(dp(i-1, j), dp(i, j-1))`.

This natural overlapping of subproblems points to a 2D dynamic programming solution.

public:
    int longestCommonSubsequence(string text1, string text2) {
        int n = text1.length(), m = text2.length();
        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
        
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (text1[i - 1] == text2[j - 1]) {
                    dp[i][j] = 1 + dp[i - 1][j - 1];
                } else {
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[n][m];
    }
};"

# Common Pitfalls
<Warning>
- Using 0-indexed DP array leading to bounds checking nightmares. Stick to 1-indexed DP matrices where `dp[0][j]` and `dp[i][0]` naturally represent empty strings.
- Confusing substring with subsequence. Substrings must be contiguous, subsequences don't have to be.
</Warning>
