# Theory & Concepts
Welcome to **Unique Paths I & II**. If you've solved Minimum Path Sum or Climbing Stairs, you already know the underlying math for this problem. This is a classic grid traversal problem that tests your ability to map combinatorics to 2D dynamic programming.

### Unique Paths I
You are a robot situated at the top-left corner of an `m x n` grid. You can only move either down or right at any point in time. How many possible unique paths are there to reach the bottom-right corner?

**Intuition:**
To reach cell `(r, c)`, you must have come from either `(r-1, c)` or `(r, c-1)`. By the Rule of Sum, the total unique paths to `(r, c)` is the sum of paths to the cell above it and the cell to its left.
**Recurrence:** `dp[r][c] = dp[r-1][c] + dp[r][c-1]`

### Unique Paths II (With Obstacles)
The grid now contains obstacles, represented by `1`s (empty spaces are `0`s). You cannot pass through an obstacle.

**Intuition:**
The logic remains perfectly identical, with one simple rule: If `grid[r][c] == 1` (it's an obstacle), the number of paths to reach it is `0`. We simply set `dp[r][c] = 0` and move on!

# Code Implementation
Let's implement the robust $O(N)$ space solution for **Unique Paths II**, as it covers all the logic needed for Unique Paths I, while demonstrating superior memory management.

<CodeBlock
  cpp="class Solution {
public:
    int uniquePathsWithObstacles(vector<vector<int>>& obstacleGrid) {
        int m = obstacleGrid.size();
        int n = obstacleGrid[0].size();
        
        // If the start or end is blocked, no paths exist
        if (obstacleGrid[0][0] == 1 || obstacleGrid[m-1][n-1] == 1) return 0;
        
        // Use a 1D DP array for O(N) space optimization
        vector<int> dp(n, 0);
        dp[0] = 1; // Base case
        
        for (int r = 0; r < m; r++) {
            for (int c = 0; c < n; c++) {
                if (obstacleGrid[r][c] == 1) {
                    dp[c] = 0; // Blocked
                } else if (c > 0) {
                    // dp[c] currently holds the value from the row above
                    // dp[c-1] holds the value from the current row, left cell
                    dp[c] += dp[c-1];
                }
            }
        }
        
        return dp[n-1];
    }
};"

# Common Pitfalls
<Warning>
- **Initial Obstacles:** Forgetting to check if the very first cell `(0, 0)` is an obstacle. If it is, the answer is instantly 0.
- **Top Row Blocking:** In a 2D array approach, if there is an obstacle in the top row, all cells to the right of it in that row cannot be reached, so their paths remain 0.
</Warning>
