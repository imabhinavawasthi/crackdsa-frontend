# Theory & Concepts
The **Longest Palindromic Subsequence (LPS)** problem asks you to find the length of the longest palindromic subsequence in a given string.

### Core Intuition
A brilliant hack to solve this problem is to use our existing knowledge of the **Longest Common Subsequence (LCS)** pattern. 
A palindrome reads the same forwards and backwards. Therefore, if we reverse the input string and find the longest common subsequence between the original string and the reversed string, we will magically find the longest palindromic subsequence!

Alternatively, you can solve it with interval DP (like MCM). Check the outer characters of an interval `(i, j)`:
- If `s[i] == s[j]`: The length increases by 2. `2 + dp(i+1, j-1)`.
- If `s[i] != s[j]`: We shrink the interval from either side and take the max. `max(dp(i+1, j), dp(i, j-1))`.

Below, we show the classic LCS-reversal approach as it's easier to code.

        string text2 = s;

        vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0));

                } else {

# Common Pitfalls
<Warning>
- Confusing Substring with Subsequence. A Longest Palindromic *Substring* problem requires expanding around centers or Manacher's algorithm, whereas *Subsequence* uses 2D DP.
</Warning>
