# Theory & Concepts
Welcome to the lesson on **Longest Palindromic Subsequence**. This topic is a core pillar of the Dynamic Programming module. Dynamic Programming is notorious for being the most intimidating topic in coding interviews, but mastering this pattern will make it formulaic and predictable.

### Core Intuition
The essence of Dynamic Programming lies in recognizing overlapping subproblems and optimal substructure. Instead of calculating the same state multiple times via naive recursion, we cache (memoize) the results or iteratively build them up (tabulate).

### The Recurrence Relation
Before writing code, always define the DP state: `dp(i) = ...`
Then, determine the base cases and the transitions.

# Common Pitfalls
<Warning>
- **Array Out of Bounds:** Forgetting to handle base cases like `i < 0` or `j < 0` resulting in array index errors.
- **Top-Down Stack Overflow:** Using pure recursion without a memoization cache on large inputs.
</Warning>
