# Theory & Concepts
The Target Sum problem asks you to assign a `+` or `-` sign to every integer in an array such that they evaluate to a specific `target`.

### Core Intuition
While this looks like a purely mathematical back-tracking problem, it can be cleverly transformed into a classic **Subset Sum** (and therefore **0/1 Knapsack**) problem.
Let `S1` be the sum of numbers assigned a `+` sign.
Let `S2` be the sum of numbers assigned a `-` sign.
We know:
`S1 - S2 = target`
`S1 + S2 = totalSum`

Adding these two equations:
`2 * S1 = target + totalSum`
`S1 = (target + totalSum) / 2`

This means we just need to find the number of subsets that sum to `(target + totalSum) / 2`. If `target + totalSum` is odd or if `target > totalSum` (in absolute value), the answer is 0.

# Code Implementation

  cpp="class Solution {
public:
    int findTargetSumWays(vector<int>& nums, int target) {
        int sum = 0;
        for (int x : nums) sum += x;
        if (abs(target) > sum || (sum + target) % 2 != 0) return 0;
        
        int s1 = (sum + target) / 2;
        vector<int> dp(s1 + 1, 0);
        dp[0] = 1;
        
        for (int num : nums) {
            for (int j = s1; j >= num; j--) {
                dp[j] += dp[j - num];
            }
        }
        return dp[s1];
    }
};"

# Common Pitfalls
<Warning>
- Forgetting to handle the edge case where `target + sum` is an odd number.
- Ignoring cases where the absolute value of `target` is greater than the total sum.
- Initializing `dp[0]` incorrectly. It should be `1` because there's one way to make a sum of zero (picking an empty subset).
</Warning>
